# 犬猫常见眼科疾病速查

> 执业兽医师临床决策工具 | 眼科检查、常见疾病、急诊处理 | 更新日期：2026年9月15日


## 眼科检查基础

### 眼科检查流程

| 步骤 | 内容 |
|------|------|
| 1 | 视诊（眼睑、结膜、角膜、瞳孔） |
| 2 | 泪液测试（Schirmer泪液试验） |
| 3 | 荧光素染色（角膜溃疡） |
| 4 | 眼压测量（TONOVET） |
| 5 | 裂隙灯检查 |
| 6 | 眼底检查 |
| 7 | 眼部B超 |

### 正常参考值

| 项目 | 犬 | 猫 |
|------|-------|-------|
| 眼压 | 10-20 mmHg | 10-20 mmHg |
| Schirmer泪液试验 | 大于15 mm/min | 大于10 mm/min |
| 瞳孔大小 | 中等 | 中等 |

## 结膜或角膜疾病

### 结膜炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌、病毒、过敏 |
| 临床表现 | 结膜充血、分泌物、眼睑痉挛 |
| 诊断 | 细胞学、培养 |
| 治疗 | 抗生素、抗病毒、抗过敏 |
| 预后 | 多数预后良好 |

### 干眼症

| 项目 | 内容 |
|------|------|
| 病因 | 免疫介导、药物、神经性 |
| 临床表现 | 黏液性分泌物、角膜色素沉着、新生血管 |
| 诊断 | Schirmer泪液试验（小于15 mm/min） |
| 治疗 | 环孢素、他克莫司、人工泪液 |
| 预后 | 需要长期管理 |

### 角膜溃疡

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、感染、干眼症 |
| 临床表现 | 眼睑痉挛、畏光、角膜水肿、荧光素染色阳性 |
| 诊断 | 荧光素染色、细胞学 |
| 治疗 | 抗生素、止痛、角膜保护剂 |
| 预后 | 浅表溃疡预后良好，深层溃疡需手术 |

### 角膜穿孔

| 项目 | 内容 |
|------|------|
| 病因 | 深层溃疡进展、外伤 |
| 临床表现 | 角膜缺损、房水流出、虹膜脱出 |
| 诊断 | 荧光素染色、裂隙灯 |
| 治疗 | 紧急手术（角膜瓣、结膜瓣） |
| 预后 | 及时手术预后较好，延误可致失明 |


## 葡萄膜疾病

### 葡萄膜炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染、免疫、肿瘤 |
| 临床表现 | 眼红、瞳孔缩小、前房浮游物、低眼压 |
| 诊断 | 裂隙灯、眼压 |
| 治疗 | 糖皮质激素、散瞳、治疗原发病 |
| 预后 | 取决于原发病 |

|------|------|

| 临床表现 | 前房血液、视力下降 |
| 诊断 | 裂隙灯、眼压 |
| 治疗 | 治疗原发病、止血 |
| 预后 | 取决于原发病 |

## 青光眼

| 项目 | 内容 |
|------|------|
| 病因 | 房水排出受阻 |
| 临床表现 | 角膜水肿、瞳孔散大、眼压升高、疼痛 |
| 诊断 | 眼压测量（大于25-30 mmHg） |
| 治疗 | 甘露醇、多佐胺、噻吗洛尔、手术 |
| 预后 | 需要长期管理，晚期预后较差 |


## 眼底疾病

### 高血压性视网膜病变

| 项目 | 内容 |
|------|------|
| 病因 | 高血压（肾病、甲亢） |
| 临床表现 | 视力下降、瞳孔散大、视网膜出血、脱离 |
| 诊断 | 血压测量、眼底镜 |
| 治疗 | 降压（氨氯地平）、治疗原发病 |
| 预后 | 及时治疗部分可恢复 |

### 进行性视网膜萎缩（PRA）

| 项目 | 内容 |
|------|------|
| 病因 | 遗传 |
| 临床表现 | 夜盲、瞳孔散大、眼底毯状反光增强 |
| 诊断 | 眼底镜、ERG |
| 治疗 | 无特效治疗 |
| 预后 | 不可逆，最终失明 |

| 情况 | 处理 |

## 眼科疾病诊疗流程

眼部症状
    |
    ▼
眼科检查（视诊、泪液、荧光素、眼压）
    |
    ▼
根据结果分诊
    ├── 眼睑 -> 内翻、外翻、睫毛异常
    ├── 结膜或角膜 -> 结膜炎、干眼症、溃疡
    ├── 葡萄膜 -> 葡萄膜炎、前房积血
    ├── 晶状体 -> 白内障、脱位
    ├── 青光眼 -> 眼压升高
    └── 眼底 -> 高血压视网膜病变、PRA


## 客户沟通要点

### 解释眼科疾病时
- 眼科疾病诊断需要专业设备，如裂隙灯、眼压计。
- 部分眼科疾病需要长期管理，不能根治。
- 眼科急诊（角膜穿孔、青光眼）需要立即处理。

### 出院指导
- 按医嘱用药，不要随意停药。
- 戴伊丽莎白圈，防止抓挠。
- 定期复查，监测病情变化。
- 如果出现疼痛加重、视力下降或分泌物增多，立即复诊。
