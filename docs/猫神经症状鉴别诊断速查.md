# 猫神经症状鉴别诊断速查

> 执业兽医师临床决策工具 | 神经定位、鉴别诊断、急诊处理 | 更新日期：2026年9月22日


## 急诊评估原则

| 原则 | 说明 |
|------|------|
| 先稳定生命体征 | 气道、呼吸、循环优先 |
| 避免应激 | 神经症状猫易应激，操作轻柔 |
| 快速神经学检查 | 意识、瞳孔、姿势、步态、反射 |
| 低血糖排查 | 立即测血糖 |
| 血压排查 | 高血压常见于猫脑病 |
| 体温 | 高热或低体温均可致神经症状 |
| 记录 | 发作时间、频率、持续时间 |


## 神经定位与常见病因

| 定位 | 常见症状 | 猫常见病因 |
|------|---------|-----------|
| 前脑 | 抽搐、转圈、行为改变、对侧偏盲 | FIP、弓形虫、肿瘤、高血压、肝性脑病、中毒 |
| 脑干 | 意识改变、瞳孔异常、多颅神经缺损 | FIP、肿瘤、脑炎、创伤、血管 |
| 小脑 | 共济失调、意向性震颤、宽基步态 | 发育异常、FIP、肿瘤、中毒 |
| 前庭 | 斜头、眼球震颤、转圈、跌倒 | 特发性前庭综合征、中耳炎/内耳炎、FIP、肿瘤 |
| C1-C5 | 四肢轻瘫、颈部疼痛 | 椎间盘疾病、骨折、FIP、肿瘤 |
| C6-T2 | 前肢瘫、后肢轻瘫 | 椎间盘疾病、骨折、肿瘤 |
| T3-L3 | 后肢瘫、尿失禁 | 椎间盘疾病、骨折、FCE、肿瘤 |
| L4-S3 | 后肢瘫、会阴反射异常 | 椎间盘疾病、骨折、肿瘤 |
| 外周神经/神经肌肉 | 四肢无力、反射减弱、肌肉萎缩 | 重症肌无力、多发性神经病、中毒 |


## 按病因分类

### 感染性/炎症性

| 疾病 | 关键线索 | 诊断 | 治疗 |
|------|---------|------|------|
| 神经型FIP | 高热、葡萄膜炎、共济失调、抽搐、白球比小于0.8 | 脑脊液RT-PCR、MRI、白球比 | GS-441524 8-10 mg/kg SC SID |
| 弓形虫病 | 抽搐、共济失调、视网膜脉络膜炎、发热 | 血清学、PCR、脑脊液 | 克林霉素 10-12.5 mg/kg PO BID |
| 隐球菌性脑膜炎 | 鼻分泌物、抽搐、行为改变 | 脑脊液细胞学、抗原检测 | 氟康唑、伊曲康唑 |
| 细菌性脑膜炎 | 发热、颈强直、抽搐 | 脑脊液分析、培养 | 抗生素 |
| 猫瘟（FPV） | 幼猫、呕吐腹泻、抽搐（晚期） | 抗原检测 | 支持治疗 |
| 狂犬病 | 行为改变、吞咽困难、瘫痪、流涎 | 病史、尸检 | 无有效治疗，公共卫生 |

### 代谢/中毒性

| 疾病 | 关键线索 | 诊断 | 治疗 |
|------|---------|------|------|
| 肝性脑病 | 流涎、抽搐、行为改变、黄疸 | 血氨、胆汁酸 | 乳果糖、低蛋白饮食、抗生素 |
| 低血糖 | 虚弱、抽搐、昏迷 | 血糖小于60 mg/dL | 50%葡萄糖稀释后静注 |
| 硫胺素缺乏 | 转圈、共济失调、瞳孔散大 | 病史（喂生鱼） | 维生素B1 10-20 mg/猫 IM/PO SID |
| 高血压脑病 | 抽搐、失明、转圈 | 血压大于160 mmHg | 氨氯地平 0.125-0.25 mg/kg PO SID |
| 尿毒症 | 抽搐、口腔溃疡、多饮多尿 | BUN/Crea升高 | 补液、透析 |
| 菊酯类中毒 | 流涎、震颤、抽搐（猫敏感） | 接触史 | 温水洗去、控制抽搐 |
| 有机磷中毒 | 流涎、缩瞳、肌肉震颤 | 接触史 | 阿托品、解磷定 |
| 乙二醇中毒 | 醉酒状、少尿、抽搐 | 渗透压间隙、尿检 | 4-甲基吡唑、乙醇、透析 |
| 铅中毒 | 抽搐、行为改变、贫血 | 血铅 | EDTA |

### 肿瘤性

| 肿瘤 | 关键线索 | 诊断 | 治疗 |
|------|---------|------|------|
| 淋巴瘤 | 行为改变、抽搐、多灶性神经症状 | MRI、脑脊液、活检 | 化疗 |
| 脑膜瘤 | 老年猫、慢性进行性症状 | MRI、CT | 手术、放疗 |
| 垂体瘤 | 行为改变、内分泌异常 | MRI、激素检测 | 手术、放疗 |

### 血管性

| 疾病 | 关键线索 | 诊断 | 治疗 |
|------|---------|------|------|
| 缺血性脑病 | 突发神经症状、高血压 | MRI、血压 | 控制血压、支持 |
| 脑出血 | 突发、意识改变 | MRI、CT | 支持、止血 |

### 创伤性

| 疾病 | 关键线索 | 诊断 | 治疗 |
|------|---------|------|------|
| 颅脑损伤 | 外伤史、意识改变、瞳孔异常 | CT、MRI | 甘露醇、支持 |
| 脊柱骨折 | 外伤史、瘫痪、疼痛 | X光、CT | 固定、手术 |

### 特发性/退行性

| 疾病 | 关键线索 | 诊断 | 治疗 |
|------|---------|------|------|
| 特发性癫痫 | 反复抽搐、发作间期正常 | 排除其他病因 | 苯巴比妥、左乙拉西坦 |
| 特发性前庭综合征 | 突发斜头、眼球震颤、转圈 | 排除中耳炎、FIP | 支持治疗，多数自愈 |
| 认知功能障碍 | 老年猫、夜间嚎叫、定向障碍 | 排除其他 | 司来吉兰、环境管理 |


## 常见神经症状鉴别

### 抽搐

| 可能病因 | 关键鉴别点 |
|---------|-----------|
| 特发性癫痫 | 反复发作、发作间期正常、年龄1-5岁 |
| 神经型FIP | 高热、葡萄膜炎、白球比低 |
| 弓形虫病 | 视网膜脉络膜炎、血清学阳性 |
| 肝性脑病 | 流涎、黄疸、血氨升高 |
| 低血糖 | 血糖低、补糖后迅速改善 |
| 高血压脑病 | 血压高、失明 |
| 中毒 | 接触史、其他症状 |
| 脑肿瘤 | 慢性进行性、老年猫 |

### 斜头/转圈/眼球震颤

| 可能病因 | 关键鉴别点 |
|---------|-----------|
| 外周性前庭综合征 | 水平眼球震颤、无意识改变、中耳炎 |
| 中枢性前庭综合征 | 垂直眼球震颤、意识改变、FIP、肿瘤 |
| 特发性前庭综合征 | 突发、无其他神经症状、多数自愈 |
| 中耳炎/内耳炎 | 耳道分泌物、疼痛、X光异常 |

### 瘫痪/共济失调

| 可能病因 | 关键鉴别点 |
|---------|-----------|
| 椎间盘疾病 | 疼痛、X光/MRI可见 |
| 动脉血栓栓塞 | 后肢瘫痪、疼痛、发绀、心超可见HCM |
| 神经型FIP | 高热、白球比低 |
| 脊柱骨折 | 外伤史、X光可见 |
| 多发性神经病 | 四肢无力、反射减弱 |

### 行为改变

| 可能病因 | 关键鉴别点 |
|---------|-----------|
| 前脑病变 | 转圈、对侧偏盲 |
| 肝性脑病 | 流涎、黄疸、血氨高 |
| 高血压脑病 | 血压高、失明 |
| 神经型FIP | 高热、葡萄膜炎 |
| 脑肿瘤 | 慢性进行性、老年猫 |


## 诊断检查

| 检查 | 目的 |
|------|------|
| 血糖 | 排除低血糖 |
| 血压 | 排除高血压 |
| 血常规、生化 | 评估肝肾功能、电解质 |
| T4 | 排除甲亢继发高血压 |
| FeLV/FIV | 排除免疫抑制 |
| 弓形虫血清学/PCR | 排除弓形虫病 |
| FIP相关检查 | 白球比、脑脊液RT-PCR、MRI |
| MRI/CT | 首选神经影像 |
| 脑脊液分析 | 炎症、感染、肿瘤 |
| X光 | 脊柱骨折、中耳炎 |


## 急诊处理

| 情况 | 处理 |
|------|------|
| 抽搐持续状态 | 地西泮 0.5-1 mg/kg IV，必要时苯巴比妥 |
| 颅内压升高 | 甘露醇 1-2 g/kg IV 15-20分钟，q6-8h |
| 低血糖 | 50%葡萄糖 0.5-1 mL/kg 稀释后静注 |
| 高血压 | 氨氯地平 0.125-0.25 mg/kg PO SID |
| 肝性脑病 | 乳果糖 0.5-1 mL/kg PO BID-TID |
| 疑似FIP | GS-441524 8-10 mg/kg SC SID |
| 弓形虫病 | 克林霉素 10-12.5 mg/kg PO BID |
| 中毒 | 停用毒物、洗去、对症 |

## 客户沟通要点

### 解释神经症状时
- 猫神经症状病因很多，需要结合神经学检查、血液检查和影像学综合判断。
- MRI是神经疾病最重要的检查，可能需要转诊。
- 部分神经疾病可以治疗，部分需要长期管理。

### 告知风险时
- 抽搐持续状态可能危及生命，需要立即处理。
- 神经型FIP治疗周期长，费用较高。
- 高血压脑病需要长期控制血压。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查，监测病情变化。
- 如果出现抽搐加重、精神变差或瘫痪，立即复诊。
- 减少应激，保持环境安静。
