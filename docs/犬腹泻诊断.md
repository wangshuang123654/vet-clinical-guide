# 🐶 犬腹泻鉴别诊断 · 临床思维导图

## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 急性胃肠炎 | 粪检、基本生化 | 腹部X光 |
| 异物梗阻 | 腹部X光（正侧位） | B超、钡餐 |
| 胰腺炎 | 胰腺特异性脂肪酶（cPL） | 腹部B超、淀粉酶/脂肪酶 |
| 炎性肠病（IBD） | 腹部B超（肠壁厚度） | 活检、叶酸/B12 |
| 细小病毒 | 病毒抗原检测（CPV Ag） | 血常规、生化 |
| 寄生虫 | 粪便漂浮/直接镜检 | 广谱驱虫药试验 |
| 肾衰竭 | 生化（BUN/Crea）、SDMA | 尿检、血压、B超 |
| 糖尿病 | 血糖、果糖胺 | 尿酮体、电解质 |
| 阿迪森 | 电解质（血钾↑血钠↓） | ACTH刺激试验 |
| 肝病 | 生化（ALT/AST/胆红素） | B超、胆汁酸 |
| 细菌性肠炎 | 粪便培养+药敏 | 血常规 |
| 灭鼠药中毒 | 凝血功能检测 | 详细问诊（食入史） |

## 🐾 客户沟通要点

### 接诊时
- "狗狗腹泻多久了？一天拉几次？是水样还是带血/带黏液？"
- "最近有没有换粮、吃异物、或者吃过人的食物？"
- "精神状态怎么样？还主动喝水吃东西吗？"
- "疫苗都打齐了吗？有没有按时驱虫？"

### 解释检查时
- "如果怀疑是细小病毒，需要做个抗原检测，结果很快就能出来。"
- "我们建议查个粪便，看看有没有寄生虫感染。"

### 告知风险时
- "细小病毒感染在幼犬中死亡率较高，但只要及时住院治疗，治愈率还是很高的。"
- "如果是异物堵住了肠道，需要尽快取出，否则肠道会坏死。"

### 出院指导
- "回去先喂容易消化的食物，少食多餐，暂时别喂零食。"
- "按时驱虫，定期疫苗，避免接触不明来源的粪便。"
- "如果再次腹泻、精神变差或出现呕吐，随时联系我们。"

## 📌 用药参考（犬）

| 药物 | 剂量 | 用途 |
|------|------|------|
| 蒙脱石散 | 1-2 g/犬 PO BID-TID | 止泻 |
| 益生菌 | 按产品说明 | 调节肠道菌群 |
| 马罗匹坦 | 1 mg/kg IV/SC SID | 止吐 |
| 头孢类抗生素 | 按具体品种剂量 | 细菌感染 |
| 甲硝唑 | 10-15 mg/kg PO BID | 厌氧菌/原虫 |
| 驱虫药 | 按具体品种剂量 | 寄生虫感染 |

> ⚠️ 用药前请结合患犬具体体重、肝肾功能及有无用药禁忌再执行。
