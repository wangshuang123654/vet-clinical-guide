# 犬猫常见行为学问题速查

> 执业兽医师临床决策工具 | 行为评估、常见问题、药物与行为矫正 | 更新日期：2026年9月15日


## 行为学评估基础

### 行为学评估流程

| 步骤 | 内容 |
|------|------|
| 1 | 病史采集（行为问题发生时间、频率、诱因） |
| 2 | 环境评估（居住环境、日常作息、家庭成员） |
| 3 | 行为观察（诊室观察、视频记录） |
| 4 | 排除医学原因（疼痛、内分泌、神经疾病） |
| 5 | 行为诊断 |
| 6 | 制定行为矫正计划 |
| 7 | 评估是否需要药物辅助 |

### 行为问题常见医学原因

| 医学原因 | 行为表现 |
|---------|---------|
| 疼痛 | 攻击性、易激惹、不愿被触碰 |
| 甲亢（猫） | 焦虑、易激惹、过度活跃 |
| 甲减（犬） | 嗜睡、抑郁、攻击性 |
| 库欣 | 焦虑、喘息、食欲异常 |
| 认知功能障碍 | 定向障碍、夜间嚎叫、随地排泄 |
| 癫痫 | 发作性行为异常 |
| 感官退化 | 听力下降、视力下降导致惊吓反应 |


## 犬常见行为学问题

### 分离焦虑

| 项目 | 内容 |
|------|------|
| 病因 | 过度依恋、环境变化、创伤 |
| 临床表现 | 主人离开后嚎叫、破坏、随地排泄、逃跑 |
| 诊断 | 病史、视频记录、排除医学原因 |
| 治疗 | 行为矫正（脱敏、反条件化）、药物（氟西汀、氯米帕明） |
| 预后 | 需要长期管理，部分可改善 |

### 攻击行为

| 类型 | 病因 | 临床表现 | 治疗 |
|------|------|---------|------|
| 恐惧性攻击 | 恐惧、缺乏社交 | 退缩、龇牙、咬人 | 脱敏、反条件化、药物 |
| 领地性攻击 | 领地意识 | 陌生人进入领地时攻击 | 行为矫正、环境管理 |
| 资源保护 | 保护食物或玩具 | 靠近时攻击 | 行为矫正、药物 |
| 捕猎性攻击 | 捕猎本能 | 追逐、咬小动物 | 行为矫正、环境管理 |
| 疼痛性攻击 | 疼痛 | 被触碰时攻击 | 止痛、行为矫正 |

### 破坏行为

| 项目 | 内容 |
|------|------|
| 病因 | 分离焦虑、无聊、缺乏运动、探索 |
| 临床表现 | 破坏家具、门窗、物品 |
| 诊断 | 病史、视频记录 |
| 治疗 | 增加运动、环境丰富、行为矫正、药物 |
| 预后 | 多数可改善 |

### 随地排泄

| 项目 | 内容 |
|------|------|
| 病因 | 未训练、分离焦虑、标记、医学原因 |
| 临床表现 | 室内排泄 |
| 诊断 | 病史、尿检、排除医学原因 |
| 治疗 | 行为训练、环境管理、药物（标记行为） |
| 预后 | 多数可改善 |

### 恐惧与恐惧症

| 项目 | 内容 |
|------|------|
| 病因 | 缺乏社交、创伤、遗传 |
| 临床表现 | 发抖、躲藏、攻击、逃跑 |
| 诊断 | 病史、排除医学原因 |
| 治疗 | 脱敏、反条件化、药物（氟西汀、阿普唑仑） |
| 预后 | 需要长期管理 |

### 认知功能障碍（犬）

| 项目 | 内容 |
|------|------|
| 病因 | 年龄相关神经退行性变 |
| 临床表现 | 定向障碍、夜间嚎叫、随地排泄、互动减少 |
| 诊断 | 病史、排除其他疾病 |
| 治疗 | 司来吉兰、抗氧化剂、环境丰富 |
| 预后 | 可延缓进展，不能治愈 |


## 猫常见行为学问题

### 随地排泄

| 项目 | 内容 |
|------|------|
| 病因 | 猫砂盆问题、应激、医学原因、标记 |
| 临床表现 | 室内排泄（排尿或排便） |
| 诊断 | 病史、尿检、排除医学原因 |
| 治疗 | 猫砂盆管理、环境管理、药物（氟西汀） |
| 预后 | 多数可改善 |

### 攻击行为

| 类型 | 病因 | 临床表现 | 治疗 |
|------|------|---------|------|
| 恐惧性攻击 | 恐惧、缺乏社交 | 退缩、嘶吼、攻击 | 脱敏、反条件化、药物 |
| 领地性攻击 | 领地意识 | 陌生人或动物进入领地时攻击 | 行为矫正、环境管理 |
| 抚摸诱导性攻击 | 过度刺激 | 被抚摸时攻击 | 行为矫正、识别早期信号 |
| 转向性攻击 | 看到窗外猫无法攻击 | 转向攻击附近的人或动物 | 环境管理、药物 |

### 过度理毛

| 项目 | 内容 |
|------|------|
| 病因 | 应激、焦虑、过敏、疼痛 |
| 临床表现 | 局部或全身脱毛、皮肤破损 |
| 诊断 | 病史、排除医学原因 |
| 治疗 | 环境管理、药物（氟西汀、阿米替林） |
| 预后 | 需要长期管理 |

### 夜间活动

| 诊断 | 病史、排除医学原因 |
| 治疗 | 白天增加活动、环境丰富、药物 |
| 预后 | 多数可改善 |

| 诊断 | 病史、排除其他疾病 |

## 客户沟通要点

### 解释行为问题时
- 行为问题不是动物不听话，而是需要科学管理的行为医学问题。
- 行为矫正需要时间和耐心，不能指望一次见效。
- 药物只是辅助，行为矫正和环境管理才是核心。

### 出院指导
- 按医嘱用药，不要随意停药。
- 坚持行为矫正训练，保持一致性。
- 环境管理是行为问题管理的重要部分。
- 如果出现攻击行为加重或新行为问题，及时复诊。
