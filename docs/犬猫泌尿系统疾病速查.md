# 犬猫泌尿系统疾病速查

> 执业兽医师临床决策工具 | 肾脏、输尿管、膀胱、尿道疾病 | 更新日期：2026年9月15日


## 泌尿系统解剖与功能

| 部位 | 主要功能 | 常见疾病 |
|------|---------|---------|
| 肾脏 | 过滤血液、调节电解质、产生尿液 | 急慢性肾衰、肾炎、肾结石 |
| 输尿管 | 输送尿液至膀胱 | 输尿管结石、狭窄 |
| 膀胱 | 储存尿液 | 膀胱炎、结石、肿瘤 |
| 尿道 | 排出尿液 | 尿道梗阻、尿道炎、狭窄 |


## 肾脏疾病

### 急性肾损伤（AKI）

| 项目 | 内容 |
|------|------|
| 病因 | 缺血（低血压、休克）、中毒（百合花、葡萄、NSAIDs）、感染 |
| 临床表现 | 少尿或无尿、呕吐、精神沉郁、脱水 |
| 诊断 | 生化（BUN或Crea升高）、尿检（尿比重下降）、SDMA |
| 治疗 | 补液、利尿、纠正电解质紊乱、治疗原发病 |
| 预后 | 及时治疗预后较好，严重者需透析 |

### 慢性肾病（CKD）

| 项目 | 内容 |
|------|------|
| 病因 | 年龄、遗传、感染、免疫介导 |
| 临床表现 | 多饮多尿、体重下降、食欲减退、口腔溃疡 |
| 诊断 | 生化（BUN或Crea升高）、SDMA、尿检、B超 |
| 治疗 | 肾脏处方粮、补液、控制血压、磷结合剂、EPO |
| 预后 | 不可逆，需长期管理 |

### CKD分级（IRIS）

| 分级 | 血肌酐（mg/dL） | 临床意义 |
|------|----------------|---------|
| 1级 | 小于1.6 | 肾功能正常，但有肾损伤证据 |
| 2级 | 1.6-2.8 | 轻度肾功能下降 |
| 3级 | 2.9-5.0 | 中度肾功能下降 |
| 4级 | 大于5.0 | 重度肾功能下降 |

### 肾结石

| 项目 | 内容 |
|------|------|
| 病因 | 代谢异常、感染、饮食 |
| 临床表现 | 血尿、排尿困难、腹痛 |
| 诊断 | X光、B超 |
| 治疗 | 手术取石、饮食管理、溶石（部分类型） |
| 预后 | 取决于结石类型和位置 |


## 输尿管疾病

### 输尿管结石

| 项目 | 内容 |
|------|------|
| 病因 | 结石从肾脏掉落至输尿管 |
| 临床表现 | 腹痛、血尿、少尿、肾盂积水 |
| 诊断 | X光、B超 |
| 治疗 | 手术取石、输尿管支架、SUB系统 |
| 预后 | 及时治疗预后较好 |

### 输尿管狭窄

| 项目 | 内容 |
|------|------|
| 病因 | 先天性、外伤、手术并发症 |
| 临床表现 | 肾盂积水、肾功能下降 |
| 诊断 | B超、CT |
| 治疗 | 手术重建、支架放置 |
| 预后 | 取决于狭窄程度和肾功能 |


## 膀胱疾病

### 膀胱炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌感染、结石、应激、肿瘤 |
| 临床表现 | 尿频、尿急、血尿、排尿困难 |
| 诊断 | 尿检、尿培养、B超 |
| 治疗 | 抗生素（根据药敏）、增加饮水、止痛 |
| 预后 | 感染性预后良好 |

### 膀胱结石

| 项目 | 内容 |
|------|------|
| 病因 | 代谢异常、感染、饮食 |
| 临床表现 | 血尿、排尿困难、尿频 |
| 诊断 | X光、B超 |
| 治疗 | 手术取石、饮食管理、溶石 |
| 预后 | 取决于结石类型 |

### 膀胱肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 原发性（移行细胞癌）或转移性 |
| 临床表现 | 血尿、排尿困难、尿频 |
| 诊断 | B超、膀胱镜、活检 |
| 治疗 | 手术切除、化疗、NSAIDs（部分有效） |
| 预后 | 取决于肿瘤类型和分期 |


## 尿道疾病

### 尿道梗阻

| 项目 | 内容 |
|------|------|
| 病因 | 结石、栓子、肿瘤、狭窄 |
| 临床表现 | 排尿困难、嚎叫、膀胱充盈、呕吐、休克 |
| 诊断 | 触诊、X光、B超 |
| 治疗 | 导尿、冲洗、手术 |
| 预后 | 及时解除梗阻预后较好，延误可致死亡 |

### 尿道炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染、结石、创伤 |
| 临床表现 | 排尿疼痛、血尿、尿道分泌物 |
| 诊断 | 尿检、尿培养、尿道镜 |
| 治疗 | 抗生素、止痛、增加饮水 |
| 预后 | 多数预后良好 |

### 尿道狭窄

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、手术、感染 |
| 临床表现 | 排尿困难、尿线细 |
| 诊断 | 尿道造影、尿道镜 |
| 治疗 | 手术重建、支架放置 |
| 预后 | 取决于狭窄程度 |


## 泌尿系统疾病诊疗流程

排尿异常
    |
    ▼
病史和体检
    |
    ▼
基础检查（血常规、生化、尿检）
    |
    ▼
影像学检查（X光、B超）
    |
    ▼
根据结果分诊
    ├── 肾脏 -> 生化、SDMA、尿检
    ├── 输尿管 -> B超、CT
    ├── 膀胱 -> 尿检、尿培养、B超
    └── 尿道 -> 导尿、尿道造影


## 泌尿系统紧急处理

| 情况 | 处理 |
|------|------|
| 尿道梗阻 | 立即导尿，解除梗阻 |
| 急性肾损伤 | 补液、利尿、纠正电解质 |
| 高血钾 | 补钙、胰岛素加葡萄糖、利尿 |
| 膀胱破裂 | 紧急手术修复 |
| 肾盂积水 | 解除梗阻，保护肾功能 |


## 客户沟通要点

### 解释泌尿系统疾病时
- 泌尿系统疾病很多与饮水、饮食有关，增加饮水是重要的辅助治疗。
- 慢性肾病需要长期管理，不能指望一次治愈。
- 如果出现排尿困难、血尿或精神变差，需要立即就诊。

### 出院指导
- 按医嘱用药，不要随意停药。
- 增加饮水（湿粮、流动水、多个水碗）。
- 定期复查肾功能和尿检。
- 如果出现排尿困难、少尿或无尿，立即复诊。
