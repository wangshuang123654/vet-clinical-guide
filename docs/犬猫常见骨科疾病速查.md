# 犬猫常见骨科疾病速查

> 执业兽医师临床决策工具 | 骨折、脱位、关节炎、韧带损伤 | 更新日期：2026年9月15日


## 骨科检查基础

### 骨科检查流程

| 步骤 | 内容 |
|------|------|
| 1 | 病史采集（外伤、跛行时间、运动情况） |
| 2 | 视诊（姿势、步态、肌肉萎缩） |
| 3 | 触诊（关节、骨骼、肌肉） |
| 4 | 关节活动度检查 |
| 5 | 神经学检查 |
| 6 | 影像学检查（X光、CT、MRI） |

### 跛行分级

| 分级 | 表现 |
|------|------|
| 0级 | 正常步态 |
| 1级 | 轻微跛行，几乎不可见 |
| 2级 | 轻度跛行，可见但不影响活动 |
| 3级 | 中度跛行，明显影响活动 |
| 4级 | 重度跛行，负重困难 |
| 5级 | 不能负重，患肢抬起 |


## 骨折

### 骨折类型

| 类型 | 特点 | 治疗原则 |
|------|------|---------|
| 闭合性骨折 | 皮肤完整 | 保守或手术 |
| 开放性骨折 | 皮肤破损，骨折端暴露 | 紧急手术，抗生素 |
| 完全骨折 | 骨折线贯穿骨干 | 手术固定 |
| 不完全骨折 | 骨折线未贯穿 | 保守或手术 |
| 粉碎性骨折 | 骨折块多于2块 | 手术固定 |
| 青枝骨折 | 幼年动物，骨皮质弯曲 | 保守或手术 |

### 常见骨折部位

| 部位 | 常见原因 | 治疗 |
|------|---------|------|
| 股骨骨折 | 车祸、高处坠落 | 髓内针、钢板 |
| 胫骨骨折 | 车祸、运动损伤 | 钢板、外固定 |
| 肱骨骨折 | 车祸、咬伤 | 钢板、髓内针 |
| 桡尺骨骨折 | 高处坠落 | 钢板、外固定 |
| 骨盆骨折 | 车祸 | 保守或手术 |
| 下颌骨骨折 | 咬伤、坠落 | 钢丝、钢板 |

### 骨折急救处理

| 步骤 | 操作 |
|------|------|
| 1 | 止血（压迫、止血带） |
| 2 | 固定（夹板、绷带） |
| 3 | 止痛（阿片类） |
| 4 | 抗生素（开放性骨折） |
| 5 | 影像学检查 |
| 6 | 手术或保守治疗 |


## 关节疾病

### 髋关节发育不良

| 项目 | 内容 |
|------|------|
| 病因 | 遗传、快速生长、肥胖 |
| 临床表现 | 后肢跛行、起立困难、臀部肌肉萎缩 |
| 诊断 | X光（髋关节松弛、关节退变） |
| 治疗 | 体重管理、物理治疗、手术（年轻犬） |
| 预后 | 取决于严重程度，多数可控制 |

### 膝关节十字韧带断裂

| 项目 | 内容 |
|------|------|
| 病因 | 退行性、外伤、肥胖 |
| 临床表现 | 突发后肢跛行、膝关节肿胀、抽屉试验阳性 |
| 诊断 | 抽屉试验、X光、关节镜 |
| 治疗 | TPLO、TTA、关节囊缝合 |
| 预后 | 手术预后良好，保守治疗易继发关节炎 |

### 髌骨脱位

| 项目 | 内容 |
|------|------|
| 病因 | 先天性（小型犬）、外伤 |
| 临床表现 | 间歇性跛行、跳跃步态、后肢伸展 |
| 诊断 | 触诊、X光 |
| 治疗 | 保守（I-II级）、手术（III-IV级） |
| 预后 | 手术预后良好 |

### 股骨头坏死

| 项目 | 内容 |
|------|------|
| 病因 | 股骨头血供中断 |
| 临床表现 | 幼犬（4-12月龄）、后肢跛行、髋关节疼痛 |
| 诊断 | X光（股骨头变形、扁平） |
| 治疗 | 股骨头切除术、全髋置换 |
| 预后 | 手术预后良好 |

### 骨关节炎

| 项目 | 内容 |
|------|------|
| 病因 | 年龄、肥胖、关节疾病、外伤 |
| 临床表现 | 晨僵、运动不耐受、跛行 |
| 诊断 | X光（关节间隙狭窄、骨赘） |
| 治疗 | 体重管理、NSAIDs、关节保健、物理治疗 |
| 预后 | 需要长期管理 |


## 肌肉疾病

### 肌肉拉伤

| 项目 | 内容 |
|------|------|
| 病因 | 运动过度、外伤 |
| 临床表现 | 局部疼痛、肿胀、跛行 |
| 诊断 | 触诊、B超 |
| 治疗 | 休息、冷敷、NSAIDs |
| 预后 | 多数1-2周恢复 |

### 肌肉撕裂

| 项目 | 内容 |
|------|------|
| 病因 | 剧烈运动、外伤 |
| 临床表现 | 突发跛行、肌肉凹陷、疼痛 |
| 诊断 | B超、MRI |
| 治疗 | 手术修复、休息 |
| 预后 | 取决于撕裂程度 |

### 肌炎

| 项目 | 内容 |
|------|------|
| 病因 | 免疫介导、感染、中毒 |
| 临床表现 | 肌肉疼痛、僵硬、跛行 |
| 诊断 | 肌酶升高、肌电图、活检 |
| 治疗 | 免疫抑制、休息 |
| 预后 | 多数可控制 |


## 骨科影像学检查

### X光检查

| 部位 | 拍摄位置 | 用途 |
|------|---------|------|
| 髋关节 | 腹背位、侧位 | 评估髋关节发育不良、脱位 |
| 膝关节 | 侧位、正位 | 评估十字韧带、髌骨 |
| 肘关节 | 侧位、正位 | 评估肘关节发育不良 |
| 脊柱 | 侧位、正位 | 评估椎间盘、骨折 |
| 骨盆 | 腹背位、侧位 | 评估骨折、脱位 |

### 其他影像学检查

| 方法 | 用途 |
|------|------|
| CT | 复杂骨折、脊柱疾病 |
| MRI | 软组织、脊髓、关节 |
| B超 | 肌肉、肌腱、关节积液 |
| 关节镜 | 关节内病变 |


## 骨科治疗原则

### 保守治疗

| 适用情况 | 方法 |
|---------|------|
| 不完全骨折 | 外固定、休息 |
| 轻度髌骨脱位 | 体重管理、物理治疗 |
| 骨关节炎 | NSAIDs、关节保健、物理治疗 |
| 肌肉拉伤 | 休息、冷敷、NSAIDs |

### 手术治疗

| 适用情况 | 方法 |
|---------|------|
| 完全骨折 | 髓内针、钢板、外固定 |
| 十字韧带断裂 | TPLO、TTA |
| 严重髌骨脱位 | 胫骨结节移位、滑车沟加深 |
| 股骨头坏死 | 股骨头切除、全髋置换 |
| 髋关节发育不良 | 骨盆三联截骨、全髋置换 |


## 骨科急诊处理

| 情况 | 处理 |
|------|------|
| 开放性骨折 | 止血、抗生素、紧急手术 |
| 大出血 | 压迫止血、输血 |
| 脊柱骨折 | 固定、手术 |
| 关节脱位 | 复位、固定 |
| 肌肉撕裂 | 手术修复 |


## 客户沟通要点

### 解释骨科疾病时
- 骨科疾病诊断需要X光或其他影像学检查。
- 骨折需要手术固定，术后需要限制活动。
- 骨关节炎是慢性病，需要长期管理，不能根治。

### 出院指导
- 术后严格限制活动，按医嘱复查。
- 按医嘱用药，不要随意停药。
- 体重管理是骨科疾病管理的重要部分。
- 如果出现跛行加重、疼痛或肿胀，及时复诊。
