## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 消化系统疾病 | 腹部X光（正侧位） | B超、钡餐造影 |
| 胰腺炎 | 胰腺特异性脂肪酶（cPL） | 腹部B超、淀粉酶/脂肪酶 |
| 异物梗阻 | 腹部X光（正侧位） | B超、钡餐或CT |
| GDV | 右侧位X光（胃部扩张） | 心电图、血气 |
| 肾衰竭 | 生化（BUN/Crea）、SDMA | 尿检、血压、B超 |
| 糖尿病 | 血糖、果糖胺 | 尿酮体、电解质 |
| 中毒 | 详细问诊（食入史） | 血常规、凝血功能 |
| 细小病毒 | 病毒抗原检测（CPV Ag） | 血常规、生化 |

## 🐾 客户沟通要点

### 接诊时
- “狗狗今天呕吐了几次？吐出来的是食物还是黄水/白沫？”
- “最近两天有没有换粮、吃异物、或者吃过人的食物？”
- “精神状态怎么样？还愿意吃东西吗？”

### 解释检查时
- “我们建议拍个X光，先排除有没有吃到骨头或玩具堵住。”
- “如果怀疑胰腺炎，需要抽血查一个特异性指标，这样更准确。”

### 告知风险时
- “GDV这个病非常凶险，需要立刻手术，拖不得。”
- “细小病毒治愈率不低，但需要住院输液，病程一般5-7天。”

### 出院指导
- “回去先喂清淡的、容易消化的食物，少量多餐。”
- “如果再次呕吐、精神变差、或者不吃东西，随时联系我们。”
