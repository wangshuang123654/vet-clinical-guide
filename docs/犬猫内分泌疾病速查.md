# 犬猫内分泌疾病速查

> 执业兽医师临床决策工具 | 常见内分泌疾病的诊断与治疗 | 更新日期：2026年9月15日


## 内分泌系统概述

| 腺体 | 主要激素 | 常见疾病 |
|------|---------|---------|
| 甲状腺 | T3、T4 | 甲减（犬）、甲亢（猫） |
| 肾上腺 | 皮质醇、醛固酮 | 库欣综合征、阿迪森病 |
| 胰腺 | 胰岛素、胰高血糖素 | 糖尿病、胰岛素瘤 |
| 垂体 | ACTH、ADH、GH | 垂体瘤、尿崩症、肢端肥大症 |
| 甲状旁腺 | PTH | 甲旁亢、甲旁减 |
| 性腺 | 雌激素、睾酮 | 性腺功能异常 |


## 甲状腺疾病

### 甲状腺功能减退（犬）

| 项目 | 内容 |
|------|------|
| 病因 | 自身免疫性甲状腺炎、特发性萎缩 |
| 临床表现 | 嗜睡、体重增加、脱毛、皮肤色素沉着、怕冷 |
| 诊断 | T4降低、TSH升高、fT4降低 |
| 治疗 | 左甲状腺素 0.01-0.02 mg/kg PO BID |
| 监测 | 用药后4-6周复查T4 |
| 预后 | 需要终身服药，预后良好 |

### 甲状腺功能亢进（猫）

| 项目 | 内容 |
|------|------|
| 病因 | 甲状腺腺瘤（多数良性） |
| 临床表现 | 多饮多尿、食欲亢进但体重下降、心悸、呕吐 |
| 诊断 | T4升高、fT4升高 |
| 治疗 | 甲巯咪唑、放射性碘治疗、手术 |
| 监测 | 用药后2-4周复查T4 |
| 预后 | 多数可控制，放射性碘可治愈 |

### 甲状腺肿瘤（犬）

| 项目 | 内容 |
|------|------|
| 病因 | 甲状腺癌（多数恶性） |
| 临床表现 | 颈部肿块、吞咽困难、声音改变 |
| 诊断 | 细针穿刺、活检、T4 |
| 治疗 | 手术切除、放疗、化疗 |
| 预后 | 取决于肿瘤类型和分期 |


## 肾上腺疾病

### 库欣综合征（肾上腺皮质功能亢进）

| 项目 | 内容 |
|------|------|
| 病因 | 垂体瘤（多数）、肾上腺肿瘤 |
| 临床表现 | 多饮多尿、腹部膨大、脱毛对称、皮肤变薄、喘息 |
| 诊断 | ACTH刺激试验、低剂量地塞米松抑制试验 |
| 治疗 | 曲洛斯坦、米托坦、手术（肾上腺肿瘤） |
| 监测 | 定期复查ACTH刺激试验 |
| 预后 | 需要长期管理，多数可控制 |

### 阿迪森病（肾上腺皮质功能减退）

| 项目 | 内容 |
|------|------|
| 病因 | 自身免疫性肾上腺皮质破坏 |
| 临床表现 | 虚弱、呕吐、腹泻、体重下降、血钾升高、血钠降低 |
| 诊断 | ACTH刺激试验（皮质醇不升高） |
| 治疗 | 泼尼松龙、氟氢可的松、补液 |
| 监测 | 定期复查电解质和皮质醇 |
| 预后 | 需要终身补充激素，预后良好 |

### 肾上腺肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 良性或恶性 |
| 临床表现 | 取决于肿瘤类型（库欣或阿迪森样表现） |
| 诊断 | B超、CT、激素检测 |
| 治疗 | 手术切除、药物控制 |
| 预后 | 取决于肿瘤类型和分期 |


## 胰腺内分泌疾病

### 糖尿病（犬猫）

| 项目 | 内容 |
|------|------|
| 病因 | 胰岛素缺乏或抵抗 |
| 临床表现 | 多饮多尿、体重下降但食欲亢进、白内障（犬） |
| 诊断 | 血糖升高、果糖胺升高、尿糖 |
| 治疗 | 胰岛素、饮食管理、运动 |
| 监测 | 血糖曲线、果糖胺 |
| 预后 | 需要终身管理，多数可控制 |

### 胰岛素瘤

| 项目 | 内容 |
|------|------|
| 病因 | 胰腺β细胞肿瘤 |
| 临床表现 | 低血糖、虚弱、抽搐、共济失调 |
| 诊断 | 低血糖、胰岛素升高、胰岛素与血糖比值升高 |
| 治疗 | 手术切除、饮食管理、药物（泼尼松、二氮嗪） |
| 预后 | 手术可治愈，恶性者预后较差 |


## 垂体疾病

### 尿崩症

| 项目 | 内容 |
|------|------|
| 病因 | 中枢性（ADH缺乏）、肾性（肾对ADH不敏感） |
| 临床表现 | 多饮多尿、尿比重低 |
| 诊断 | 禁水试验、ADH刺激试验 |
| 治疗 | 去氨加压素（中枢性）、噻嗪类利尿剂（肾性） |
| 预后 | 需要长期管理 |

### 肢端肥大症

| 项目 | 内容 |
|------|------|
| 病因 | 垂体GH分泌过多 |
| 临床表现 | 面部增大、四肢粗大、呼吸困难、糖尿病 |
| 诊断 | GH升高、IGF-1升高 |
| 治疗 | 手术、放疗、药物（奥曲肽） |
| 预后 | 需要长期管理 |


## 甲状旁腺疾病

### 甲状旁腺功能亢进

| 项目 | 内容 |
|------|------|
| 病因 | 原发性（腺瘤）、继发性（肾衰） |
| 临床表现 | 高钙血症、多饮多尿、结石、骨痛 |
| 诊断 | 血钙升高、PTH升高 |
| 治疗 | 手术切除、补液、降钙素 |
| 预后 | 取决于原发病 |

### 甲状旁腺功能减退

| 项目 | 内容 |
|------|------|
| 病因 | 手术损伤、自身免疫 |
| 临床表现 | 低钙血症、抽搐、肌肉震颤 |
| 诊断 | 血钙降低、PTH降低 |
| 治疗 | 补钙、维生素D |
| 预后 | 需要长期管理 |


## 内分泌疾病诊疗流程

疑似内分泌疾病
    |
    ▼
病史和体检
    |
    ▼
基础检查（血常规、生化、尿检）
    |
    ▼
激素检测
    |
    ▼
根据结果分诊
    ├── 甲状腺 -> T4、TSH、fT4
    ├── 肾上腺 -> ACTH刺激试验、地塞米松抑制试验
    ├── 胰腺 -> 血糖、果糖胺、胰岛素
    └── 垂体 -> ADH、GH、IGF-1


## 内分泌疾病紧急处理

| 情况 | 处理 |
|------|------|
| 阿迪森危象 | 补液、泼尼松、氟氢可的松 |
| 糖尿病酮症酸中毒 | 补液、胰岛素、纠正电解质 |
| 高钙血症危象 | 补液、利尿、降钙素 |
| 低血糖危象 | 静脉补糖 |
| 甲亢危象 | 甲巯咪唑、β受体阻滞剂、支持治疗 |


## 客户沟通要点

### 解释内分泌疾病时
- 内分泌疾病通常需要长期管理，不能指望一次治愈。
- 需要定期复查激素水平，调整用药剂量。
- 如果出现症状加重或新症状，需要及时复诊。

### 出院指导
- 按医嘱用药，不要随意停药或调整剂量。
- 定期复查激素水平和生化指标。
- 记录饮水量、尿量、体重变化。
- 如果出现呕吐、腹泻、精神变差，立即复诊。
