# 犬猫预防保健速查

## 疫苗接种程序

### 犬核心疫苗

| 疫苗 | 首免年龄 | 加强免疫 | 后续加强 |
|------|---------|---------|---------|
| 犬瘟热（CDV） | 6-8周龄 | 每3-4周一次，至16周龄 | 1年后，之后每1-3年 |
| 犬细小病毒（CPV） | 6-8周龄 | 每3-4周一次，至16周龄 | 1年后，之后每1-3年 |
| 犬传染性肝炎（CAV） | 6-8周龄 | 每3-4周一次，至16周龄 | 1年后，之后每1-3年 |
| 狂犬病 | 12-16周龄 | 1年后 | 之后每1-3年（依法） |

### 犬非核心疫苗

| 疫苗 | 适用情况 | 加强免疫 |
|------|---------|---------|
| 犬副流感（CPIV） | 群养犬、寄养犬 | 每年 |
| 博德特氏菌 | 群养犬、寄养犬 | 每年 |
| 钩端螺旋体 | 高危犬（接触疫水） | 每年 |
| 犬冠状病毒 | 不推荐常规接种 | - |

### 猫核心疫苗

| 疫苗 | 首免年龄 | 加强免疫 | 后续加强 |
|------|---------|---------|---------|
| 猫瘟（FPV） | 6-8周龄 | 每3-4周一次，至16周龄 | 1年后，之后每1-3年 |
| 猫疱疹病毒（FHV-1） | 6-8周龄 | 每3-4周一次，至16周龄 | 1年后，之后每1-3年 |
| 猫杯状病毒（FCV） | 6-8周龄 | 每3-4周一次，至16周龄 | 1年后，之后每1-3年 |
| 狂犬病 | 12-16周龄 | 1年后 | 之后每1-3年（依法） |

### 猫非核心疫苗

| 疫苗 | 适用情况 | 加强免疫 |
|------|---------|---------|
| 猫白血病（FeLV） | 高危猫（户外、群养） | 每年 |
| 猫衣原体 | 高危猫 | 每年 |
| 猫免疫缺陷病毒（FIV） | 无有效疫苗 | - |

### 疫苗接种注意事项

| 项目 | 说明 |
|------|------|
| 健康状况 | 仅健康动物接种 |
| 驱虫 | 接种前完成驱虫 |
| 母源抗体 | 可能干扰疫苗效果 |
| 不良反应 | 观察30分钟，记录不良反应 |
| 接种部位 | 犬：右肩胛；猫：右后肢（便于追踪注射部位肉瘤） |


## 驱虫计划

### 犬驱虫计划

| 寄生虫 | 药物 | 频率 |
|--------|------|------|
| 蛔虫、钩虫 | 芬苯达唑、吡喹酮 | 幼犬每2周一次至12周龄，之后每3个月 |
| 鞭虫 | 芬苯达唑 | 每3个月 |
| 心丝虫 | 塞拉菌素、伊维菌素 | 每月一次（流行区） |
| 跳蚤、蜱虫 | 氟雷拉纳、塞拉菌素 | 每月或每3个月 |
| 贾第虫 | 芬苯达唑、甲硝唑 | 有症状时治疗 |

## 绝育时机

| 动物 | 推荐绝育年龄 | 说明 |
|------|-------------|------|
| 犬（小型） | 6-9月龄 | 首次发情前 |
| 犬（大型） | 12-18月龄 | 骨骼发育完成后 |
| 猫 | 6-8月龄 | 首次发情前 |
| 特殊情况 | 根据个体情况 | 隐睾、子宫蓄脓等需提前 |

### 绝育的益处与风险

| 益处 | 风险 |
|------|------|
| 预防子宫蓄脓 | 肥胖风险增加 |
| 预防卵巢或睾丸肿瘤 | 某些肿瘤风险变化 |
| 降低乳腺肿瘤风险 | 尿失禁风险（母犬） |
| 减少行为问题 | 甲状腺功能减退风险 |

## 营养管理

### 不同生命阶段营养需求

| 阶段 | 营养重点 | 注意事项 |
|------|---------|---------|
| 幼年 | 高蛋白、高能量、钙磷平衡 | 少食多餐，控制生长速度 |
| 成年 | 维持能量、均衡营养 | 控制体重，避免肥胖 |
| 老年 | 易消化蛋白、关节保健 | 控制磷摄入，补充抗氧化剂 |
| 怀孕或哺乳 | 高能量、高蛋白 | 少量多餐，充足饮水 |
| 疾病 | 处方粮（肾病、肝病、糖尿病等） | 根据病情个体化 |

### 体重管理

| 体况评分（BCS） | 状态 | 处理 |
|----------------|------|------|
| 1-3 | 偏瘦 | 增加营养 |
| 4-5 | 理想 | 维持 |
| 6-7 | 超重 | 减重 |
| 8-9 | 肥胖 | 积极减重 |


## 预防保健沟通要点

### 解释疫苗时
- 疫苗是预防传染病最有效的方法。
- 幼犬幼猫需要按时完成疫苗程序。
- 成年后需要定期加强免疫。

### 解释驱虫时
- 驱虫不仅保护宠物，也保护家人。
- 即使不出门的猫也需要驱虫。
- 心丝虫预防需要每月用药。

### 解释绝育时
- 绝育可以预防多种生殖系统疾病。
- 绝育时机需要根据品种和个体情况决定。
- 绝育后需要注意体重管理。

### 解释老年筛查时
- 老年动物需要每年体检，早期发现疾病。
- 很多疾病早期没有明显症状。
- 定期筛查可以延长寿命，提高生活质量。
