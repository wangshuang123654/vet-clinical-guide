# 🐱 猫呼吸急促鉴别诊断 · 临床思维导图

> 执业兽医师临床急诊决策工具 | 分秒必争，先稳定再诊断 | 更新日期：2026年9月6日


## 🚨 急诊评估（接诊5分钟内完成）

### 稳定性评估

| 体征 | 分级 | 立即行动 |
|------|------|----------|
| 张口呼吸、舌色发绀 | 危重 | 立即吸氧，禁止一切应激操作 |
| 呼吸频率 > 60次/分钟 | 紧急 | 吸氧，限制操作 |
| 呼吸频率 > 80次/分钟 | 极危 | 准备插管/呼吸机 |
| 一碰就发绀 | 极危 | 禁止翻动，面罩吸氧，准备镇静插管 |
| SpO₂ < 90%（吸氧下） | 极危 | 立即插管 |

> 核心原则：先稳定，再诊断！不要为了检查让猫应激，应激可能导致立即死亡。


## 病因分类（按致死率排序）

> 高致死率 + 进展快 → 急诊优先排除


### 第一类：心源性（最常见的急性死亡原因）

| 病因 | 关键线索 | 确诊手段 |
|------|---------|----------|
| 肥厚型心肌病（HCM） | 10岁猫高发、心杂音、X光心影增大 | 心超（金标准） |
| 心源性肺水肿 | 夜咳、运动不耐受、X光肺水肿征 | NT-proBNP↑、心超 |
| 心包积液 | 心音遥远、X光"球形心影" | 心超、心包穿刺 |

**急诊行动：**
1. 吸氧（40-60%）
2. 呋塞米 1-2 mg/kg IV（心衰首选）
3. 心超确诊（或NT-proBNP快速检测）


### 第二类：猫传染性腹膜炎（FIP）

| 类型 | 关键线索 | 确诊手段 |
|------|---------|----------|
| 湿性FIP | 胸腔/腹腔积液、高热、X光积液征 | 积液RT-PCR（金标准） |
| 干性FIP | 高热、肉芽肿、淋巴结肿大、X光可正常 | 白球比、超声、FNA |

**临床线索（符合越多越可疑）：**
- 高热（>39.5℃）顽固不退
- 淋巴细胞↓（<1.0）常见
- 白球比≤0.8（高度怀疑），<0.6（高度提示）
- SAA/CRP显著升高
- 冠状病毒PCR可阴性（FIP是突变株）

**急诊行动：**
1. 吸氧、对症支持
2. 查白球比+球蛋白精确值
3. 胸腹超声（髓质环征、淋巴结肿大、积液）
4. 若高度怀疑：GS-441524立即启动


### 第三类：ARDS/重症肺炎

| 病因 | 关键线索 | 确诊手段 |
|------|---------|----------|
| 细菌性肺炎 | 发热、WBC↑/↓、X光浸润 | X光、血培养、BALF |
| 吸入性肺炎 | 有呕吐史、进食呛咳史 | X光 |
| 间质性肺炎 | X光早期可正常 | CT（金标准） |

**临床线索：**
- 呼吸极快、SpO₂↓、吸氧无效
- X光：间质型→肺泡型浸润
- 炎症指标：SAA/CRP↑↑

**急诊行动：**
1. 吸氧（面罩→插管→呼吸机）
2. 若SpO₂持续<92% → 准备插管
3. 抗生素覆盖


### 第四类：胸腔积液/气胸

| 病因 | 关键线索 | 确诊/治疗 |
|------|---------|----------|
| 胸腔积液 | 心音遥远、叩诊浊音、X光胸腔密度↑ | X光+胸腔穿刺 |
| 气胸 | 突发呼吸困难 | X光+穿刺排气 |

**急诊行动：**
1. 胸腔穿刺：诊断性+治疗性引流
2. 若大量积液，缓慢抽液（≤20 mL/kg）


### 第五类：哮喘/过敏

| 病因 | 关键线索 | 确诊/治疗 |
|------|---------|----------|
| 猫哮喘 | 阵发性干咳、呼气困难、X光支气管征 | 类固醇+支气管扩张剂试验治疗 |

**急诊行动：**
1. 吸氧
2. 支气管扩张剂（沙丁胺醇）吸入
3. 地塞米松 0.1-0.5 mg/kg IV


### 第六类：上呼吸道梗阻

| 病因 | 关键线索 | 确诊/治疗 |
|------|---------|----------|
| 鼻咽部异物/息肉 | 打喷嚏、鼻分泌物、吸气困难 | X光/CT + 内镜 |
| 喉部麻痹 | 老年猫、喘鸣音 | 喉镜 |

**急诊行动：**
1. 保持气道通畅
2. 吸氧
3. 若完全梗阻→紧急插管/气管切开


### 第七类：全身性疾病相关的呼吸急促

| 病因 | 关键线索 | 确诊/治疗 |
|------|---------|----------|
| 胰腺炎 | 腹痛、弓背、呕吐、fPL↑ | fPL检测+腹部超声 |
| 败血症/SIRS | 高热/低温、虚弱、血压↓ | 血培养+原发灶排查 |
| 代谢性酸中毒 | 糖尿病酮症/肾衰 | 血气分析+电解质 |
| 热射病 | 高温环境、T>41℃ | 病史+降温 |
| 贫血 | 黏膜苍白、HCT↓ | 血常规、排查原发病 |


## 急诊快速诊断流程图

**第一步：稳定生命体征（5分钟内完成）**
- 呼吸 > 60/min → 吸氧（面罩/氧舱）
- 呼吸 > 80/min → 准备插管
- 舌色发绀 → 立即吸氧！禁止翻动！
- 体温 > 39.5℃ → 物理降温+药物

**第二步：病史 + 基础检查**
- 品种（暹罗/缅因/波斯？）→ 心肌病风险
- 年龄（老年→心源/FIP/肿瘤）
- 发病速度（突然→气胸/心衰；慢性→哮喘）
- 听诊（心杂音→心源；湿啰音→心衰/肺炎）
- X光 → 最重要的一步

**第三步：X光解读**
- 肺水肿/心影大 → 心源性 → 心超/NT-proBNP
- 胸腔积液 → 穿刺 → 鉴别（FIP/乳糜/脓胸）
- 肺浸润 → 肺炎（细菌性/吸入性/间质性）
- 气胸 → 穿刺排气
- X光正常 + 高热 + 吸氧无效 → FIP/间质性肺炎
- X光正常 + 呼吸急促 + 疼痛 → 胰腺炎

**第四步：优先排查项目（按致死率排序）**

最优先（24小时内死亡风险高）：
- 心源性 → 心超/NT-proBNP + 呋塞米试验
- FIP → 白球比/超声/积液PCR + GS-441524
- ARDS/重症肺炎 → CT + 血培养 + 呼吸机支持
- 胸腔积液/气胸 → 胸腔穿刺

第二优先：
- 哮喘 → 类固醇+支气管扩张剂试验
- 上呼吸道梗阻 → 内镜/CT
- 胰腺炎 → fPL+腹部超声


## 死亡风险预警信号

| 信号 | 临床意义 | 行动 |
|------|---------|------|
| SpO₂ < 90%（吸氧下） | 氧合功能障碍 | 准备插管 |
| 呼吸频率 > 80/min | 呼吸肌疲劳 | 考虑镇静/插管 |
| 一碰就发绀 | 氧储备耗尽 | 禁止操作，先稳定 |
| 意识变差/眼睛发直 | 脑缺氧 | 立即插管 |
| 顽固性高热 | SIRS失控 | 物理降温+药物 |
| 体温下降 | 临终征兆 | 准备CPR |
| 吸氧一夜无好转 | 不是单纯缺氧 | 需要确诊 |


## 客户沟通要点

### 接诊时
- 这种情况多久了？是突然还是慢慢出现的？
- 猫之前有没有确诊过心脏问题？
- 最近有没有呕吐、腹泻、不吃东西？
- 疫苗都打齐了吗？

### 告知风险时
- 目前情况很危险，随时可能呼吸停止，需要做好心理准备。
- 我们会尽全力，但您需要做好心理准备。


## 急诊思维5字口诀

**稳 → 氧 → 片 → 心 → 线**

| 步骤 | 操作 |
|------|------|
| 稳 | 稳定生命体征（不操作 > 操作） |
| 氧 | 吸氧（氧舱/面罩/插管） |
| 片 | X光（最快、最核心的诊断工具） |
| 心 | 排查心源性（猫呼吸急促最常见的致死病因） |
| 线 | 疗效曲线（治疗无效→重新评估方向） |
