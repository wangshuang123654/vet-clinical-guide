# 犬猫常见肿瘤速查

> 执业兽医师临床决策工具 | 常见肿瘤的诊断、分期与治疗 | 更新日期：2026年9月15日


## 肿瘤诊断基础

### 肿瘤诊断流程

| 步骤 | 内容 |
|------|------|
| 1 | 病史和体检 |
| 2 | 细针穿刺细胞学 |
| 3 | 活检（组织病理） |
| 4 | 影像学分期（X光、B超、CT） |
| 5 | 血液学检查（血常规、生化） |
| 6 | 分期（TNM） |
| 7 | 制定治疗方案 |

### 肿瘤分期（TNM）

| 项目 | 含义 |
|------|------|
| T | 原发肿瘤大小和范围 |
| N | 区域淋巴结转移 |
| M | 远处转移 |

### 肿瘤治疗方式

| 方式 | 适用情况 | 说明 |
|------|---------|------|
| 手术 | 实体瘤、局部病变 | 首选治疗，完整切除 |
| 化疗 | 全身性肿瘤、转移 | 淋巴瘤、白血病 |
| 放疗 | 局部肿瘤、不能手术 | 鼻腔肿瘤、脑肿瘤 |
| 免疫治疗 | 某些肿瘤 | 黑色素瘤疫苗 |
| 靶向治疗 | 特定突变 | 肥大细胞瘤（托西尼布） |
| 姑息治疗 | 晚期、不能治愈 | 止痛、营养支持 |


## 犬常见肿瘤

### 肥大细胞瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 皮肤、脾脏、肝脏 |
| 临床表现 | 皮肤结节、可能瘙痒、红斑 |
| 诊断 | 细针穿刺、活检 |
| 分期 | 皮肤（I-III级）、内脏（IV级） |
| 治疗 | 手术切除、化疗（长春新碱、洛莫司汀）、靶向（托西尼布） |
| 预后 | 取决于分级和分期，低级别预后良好 |

### 淋巴瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 淋巴结、脾脏、肝脏、骨髓 |
| 临床表现 | 淋巴结肿大、消瘦、发热、食欲下降 |
| 诊断 | 细针穿刺、活检、流式细胞术 |
| 分期 | I-V期 |
| 治疗 | CHOP方案（环磷酰胺、多柔比星、长春新碱、泼尼松） |
| 预后 | 及时治疗可缓解，中位生存期6-12个月 |

### 骨肉瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 长骨（桡骨远端、肱骨近端、股骨远端） |
| 临床表现 | 跛行、局部肿胀、疼痛 |
| 诊断 | X光、活检 |
| 分期 | I-III期 |
| 治疗 | 截肢加化疗（卡铂、多柔比星） |
| 预后 | 不治疗预后差，截肢加化疗中位生存期10-12个月 |

### 血管肉瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 脾脏、心脏、皮肤 |
| 临床表现 | 虚弱、腹部膨大、心包积液 |
| 诊断 | B超、CT、活检 |
| 分期 | I-III期 |
| 治疗 | 手术切除、化疗（多柔比星） |
| 预后 | 预后较差，中位生存期3-6个月 |

### 乳腺肿瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 乳腺 |
| 临床表现 | 乳腺肿块、可能溃疡 |
| 诊断 | 细针穿刺、活检 |
| 分期 | I-V期 |
| 治疗 | 手术切除（乳腺切除）、化疗 |
| 预后 | 良性预后良好，恶性取决于分期 |

### 软组织肉瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 皮下、肌肉 |
| 临床表现 | 逐渐增大的肿块 |
| 诊断 | 细针穿刺、活检、CT或MRI |
| 分期 | I-III期 |
| 治疗 | 手术切除（广泛切除）、放疗 |
| 预后 | 取决于切除是否完整 |


## 猫常见肿瘤

### 淋巴瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 消化道、纵隔、淋巴结 |
| 临床表现 | 体重下降、呕吐、腹泻、呼吸困难 |
| 诊断 | 细针穿刺、活检、FeLV或FIV检测 |
| 分期 | I-V期 |
| 治疗 | CHOP方案（猫减量） |
| 预后 | 及时治疗可缓解，中位生存期6-12个月 |

### 鳞状细胞癌

| 项目 | 内容 |
|------|------|
| 好发部位 | 口腔、耳廓、鼻镜 |
| 临床表现 | 溃疡、肿块、流涎 |
| 诊断 | 活检 |
| 分期 | I-IV期 |
| 治疗 | 手术切除、放疗 |
| 预后 | 取决于分期和位置 |

### 乳腺肿瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 乳腺 |
| 临床表现 | 乳腺肿块 |
| 诊断 | 细针穿刺、活检 |
| 分期 | I-IV期 |
| 治疗 | 手术切除（乳腺切除） |
| 预后 | 猫乳腺肿瘤恶性率高，预后较差 |

### 肥大细胞瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 皮肤、脾脏 |
| 临床表现 | 皮肤结节、脾脏肿大 |
| 诊断 | 细针穿刺、活检 |
| 分期 | I-IV期 |
| 治疗 | 手术切除、化疗 |
| 预后 | 皮肤型预后较好，内脏型预后较差 |

### 注射部位肉瘤

| 项目 | 内容 |
|------|------|
| 好发部位 | 注射部位（肩胛间、后肢） |
| 临床表现 | 注射部位逐渐增大的肿块 |
| 诊断 | 活检 |
| 分期 | I-III期 |
| 治疗 | 广泛手术切除、放疗 |
| 预后 | 取决于切除是否完整 |


## 肿瘤急诊处理

| 情况 | 处理 |
|------|------|
| 肿瘤破裂出血 | 压迫止血、手术 |
| 肿瘤压迫气道 | 吸氧、紧急手术 |
| 肿瘤压迫脊髓 | 止痛、手术 |
| 化疗后骨髓抑制 | 输血、G-CSF |
| 肿瘤溶解综合征 | 补液、利尿、纠正电解质 |
| 高钙血症 | 补液、利尿、降钙素 |


## 化疗药物速查

| 药物 | 剂量（犬） | 剂量（猫） | 主要毒性 |
|------|----------|----------|---------|
| 多柔比星 | 30 mg/m² IV | 1 mg/kg IV | 心脏毒性、骨髓抑制 |
| 长春新碱 | 0.5-0.7 mg/m² IV | 0.5-0.7 mg/m² IV | 神经毒性 |
| 环磷酰胺 | 200-250 mg/m² IV | 200-250 mg/m² IV | 骨髓抑制、膀胱炎 |
| 洛莫司汀 | 60-90 mg/m² PO | 50-60 mg/m² PO | 骨髓抑制、肝毒性 |
| 卡铂 | 300 mg/m² IV | 180-200 mg/m² IV | 骨髓抑制 |
| 顺铂 | 50-70 mg/m² IV | 猫禁用 | 肾毒性 |
| 托西尼布 | 2-3 mg/kg PO | 无 | 肥大细胞瘤 |


## 客户沟通要点

### 解释肿瘤诊断时
- 肿瘤诊断需要细针穿刺或活检，才能确定类型和分期。
- 肿瘤治疗需要综合考虑肿瘤类型、分期、动物年龄和全身状况。
- 肿瘤治疗的目标是延长高质量生活，不一定能完全治愈。

### 告知治疗方案时
- 手术是大多数实体瘤的首选治疗，完整切除是关键。
- 化疗可能有副作用，但大多数可以通过药物管理。
- 定期复查是监测疗效和调整方案的关键。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查，监测肿瘤变化和药物副作用。
- 如果出现精神变差、食欲下降、呕吐或呼吸困难，立即复诊。
