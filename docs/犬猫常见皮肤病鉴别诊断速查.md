# 犬猫常见皮肤病鉴别诊断速查

> 执业兽医师临床决策工具 | 按病变类型快速鉴别 | 更新日期：2026年9月15日


## 皮肤病诊断基础

### 病史采集要点

| 项目 | 关键问题 |
|------|---------|
| 发病时间 | 急性还是慢性 |
| 发病部位 | 局部还是全身 |
| 瘙痒程度 | 无痒、轻痒、剧痒 |
| 季节性 | 季节性还是全年 |
| 饮食 | 最近是否换粮 |
| 环境 | 最近是否搬家、新宠物 |
| 用药史 | 最近用过什么药 |
| 驱虫史 | 是否按时驱虫 |
| 接触史 | 是否接触其他动物 |

### 皮肤检查方法

| 方法 | 目的 |
|------|------|
| 视诊 | 观察病变类型、分布 |
| 触诊 | 评估质地、厚度、温度 |
| 伍德氏灯 | 筛查皮肤癣菌 |
| 皮肤刮片 | 检查螨虫 |
| 细胞学 | 检查细菌、酵母菌 |
| 胶带粘贴 | 检查表面微生物 |
| 真菌培养 | 确诊皮肤癣菌 |
| 活检 | 确诊肿瘤、免疫介导性疾病 |


## 按病变类型鉴别

### 脱毛

| 病因 | 关键线索 | 诊断 |
|------|---------|------|
| 蠕形螨 | 幼犬、脱毛、红斑、不痒或轻痒 | 深刮 |
| 皮肤癣菌 | 圆形脱毛、断毛、轻痒 | 伍德氏灯、培养 |
| 内分泌性 | 对称性脱毛、不痒、皮肤变薄 | T4、ACTH |
| 跳蚤过敏 | 腰背部脱毛、瘙痒 | 梳检 |
| 压力性脱毛 | 局部脱毛、无炎症 | 排除其他 |
| 注射反应 | 注射部位脱毛 | 病史 |

### 丘疹或脓疱

| 病因 | 关键线索 | 诊断 |
|------|---------|------|
| 细菌性脓皮病 | 脓疱、丘疹、表皮环 | 细胞学 |
| 蠕形螨 | 丘疹、脱毛、红斑 | 深刮 |
| 皮肤癣菌 | 丘疹、脱毛、断毛 | 培养 |
| 天疱疮 | 脓疱、糜烂、鼻镜或耳廓 | 活检 |
| 接触性皮炎 | 接触部位、红斑、丘疹 | 病史 |

### 结节或肿块

| 病因 | 关键线索 | 诊断 |
|------|---------|------|
| 肥大细胞瘤 | 结节、可能瘙痒、犬常见 | 细针穿刺 |
| 组织细胞瘤 | 年轻犬、结节、可自行消退 | 细针穿刺 |
| 鳞状细胞癌 | 老年犬、溃疡性结节 | 活检 |
| 皮肤囊肿 | 光滑结节、无痛 | 细针穿刺 |
| 脓肿 | 红肿热痛、波动感 | 穿刺 |

### 皮屑或鳞屑

| 病因 | 关键线索 | 诊断 |
|------|---------|------|
| 皮脂溢 | 大量皮屑、油腻被毛 | 排除其他 |
| 蠕形螨 | 皮屑、脱毛、红斑 | 深刮 |
| 皮肤癣菌 | 皮屑、断毛、圆形脱毛 | 培养 |
| 马拉色菌 | 皮屑、红斑、异味 | 细胞学 |
| 营养性 | 全身皮屑、被毛粗糙 | 饮食史 |

### 色素沉着或苔藓化

| 病因 | 关键线索 | 诊断 |
|------|---------|------|
| 内分泌性 | 对称性、不痒、皮肤增厚 | T4、ACTH |
| 慢性炎症 | 长期瘙痒、苔藓化 | 病史 |
| 跳蚤过敏 | 腰背部、色素沉着 | 梳检 |
| 马拉色菌 | 红斑、色素沉着、异味 | 细胞学 |


## 常见皮肤病速查

### 寄生虫性皮肤病

| 疾病 | 病原 | 关键特征 | 诊断 | 治疗 |
|------|------|---------|------|------|
| 疥螨 | 犬疥螨 | 剧痒、耳廓或肘部结痂 | 浅刮 | 伊维菌素、塞拉菌素 |
| 蠕形螨 | 犬蠕形螨 | 脱毛、红斑、不痒或轻痒 | 深刮 | 伊维菌素、双甲脒、贝卫多 |
| 姬螯螨 | 姬螯螨 | 背侧大量皮屑、轻痒 | 浅刮 | 伊维菌素、塞拉菌素 |
| 跳蚤过敏 | 跳蚤 | 腰背部或尾根瘙痒 | 梳检 | 驱蚤、环境灭蚤 |
| 虱子 | 虱 | 被毛粗糙、可见虱卵 | 视诊 | 拟除虫菊酯 |

### 感染性皮肤病

| 疾病 | 病原 | 关键特征 | 诊断 | 治疗 |
|------|------|---------|------|------|
| 浅表脓皮病 | 葡萄球菌 | 脓疱、丘疹、表皮环 | 细胞学 | 抗生素4-6周 |
| 深层脓皮病 | 葡萄球菌 | 结节、溃疡、窦道 | 细胞学、培养 | 抗生素6-8周 |
| 皮肤癣菌 | 微孢子菌 | 圆形脱毛、断毛 | 伍德氏灯、培养 | 伊曲康唑、特比萘芬 |
| 马拉色菌 | 马拉色菌 | 红斑、皮屑、异味 | 细胞学 | 抗真菌药浴、酮康唑 |

### 过敏性皮肤病

| 疾病 | 病因 | 关键特征 | 诊断 | 治疗 |
|------|------|---------|------|------|
| 跳蚤过敏性皮炎 | 跳蚤唾液 | 腰背部或尾根瘙痒 | 梳检 | 驱蚤、止痒 |
| 食物过敏 | 食物蛋白 | 非季节性、耳炎或足皮炎 | 排除饮食试验 | 低敏粮、水解蛋白 |
| 特应性皮炎 | 环境过敏原 | 季节性或不季节性瘙痒 | 排除其他 | 免疫治疗、止痒 |
| 接触性皮炎 | 接触物 | 接触部位红斑、丘疹 | 病史 | 隔离接触源 |

### 免疫介导性皮肤病

| 疾病 | 病因 | 关键特征 | 诊断 | 治疗 |
|------|------|---------|------|------|
| 天疱疮 | 自身抗体 | 脓疱、糜烂、鼻镜或耳廓 | 活检 | 免疫抑制 |
| 红斑狼疮 | 免疫复合物 | 鼻镜或耳廓脱色、溃疡 | 活检、ANA | 免疫抑制、防晒 |
| 多形性红斑 | 药物或感染 | 靶形红斑、水疱 | 活检 | 停用诱因、免疫抑制 |

### 内分泌性皮肤病

| 疾病 | 病因 | 关键特征 | 诊断 | 治疗 |
|------|------|---------|------|------|
| 甲减 | 甲状腺激素缺乏 | 对称性脱毛、皮肤变薄 | T4、TSH | 左甲状腺素 |
| 库欣 | 皮质醇过多 | 腹部膨大、脱毛、皮肤变薄 | ACTH刺激试验 | 曲洛斯坦 |
| 性激素异常 | 性激素失衡 | 对称性脱毛、色素沉着 | 激素检测 | 绝育、激素治疗 |


## 皮肤病诊断流程

皮肤病
    |
    ▼
病史和体检
    |
    ▼
基础检查（伍德氏灯、刮片、细胞学）
    |
    ▼
根据病变类型分诊
    ├── 脱毛 -> 蠕形螨、皮肤癣菌、内分泌
    ├── 丘疹或脓疱 -> 脓皮病、蠕形螨、天疱疮
    ├── 结节或肿块 -> 肿瘤、囊肿、脓肿
    ├── 皮屑 -> 皮脂溢、蠕形螨、马拉色菌
    └── 色素沉着或苔藓化 -> 内分泌、慢性炎症


## 皮肤病紧急处理

| 情况 | 处理 |
|------|------|
| 急性过敏反应 | 抗组胺药、糖皮质激素 |
| 严重脓皮病 | 抗生素、药浴、支持治疗 |
| 大面积皮肤癣菌 | 口服抗真菌药、药浴、环境消毒 |
| 天疱疮急性发作 | 免疫抑制、支持治疗 |
| 蜂窝织炎 | 抗生素、引流 |


## 客户沟通要点

### 解释皮肤病时
- 皮肤病诊断需要时间，可能需要多次检查才能确诊。
- 很多皮肤病是慢性病，需要长期管理，不能指望一次治愈。
- 外用药和药浴是重要的治疗手段，需要坚持使用。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查，调整治疗方案。
- 环境消毒，特别是螨虫和真菌感染。
- 如果出现症状加重或新病变，及时复诊。
