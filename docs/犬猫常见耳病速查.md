# 犬猫常见耳病速查

> 执业兽医师临床决策工具 | 耳部检查、常见疾病、治疗要点 | 更新日期：2026年9月15日


## 耳部检查基础

### 耳部检查流程

| 步骤 | 内容 |
|------|------|
| 1 | 视诊（耳廓、耳道口） |
| 2 | 触诊（耳廓、耳根） |
| 3 | 耳镜检查（耳道、鼓膜） |
| 4 | 耳道细胞学（细菌、酵母菌、螨虫） |
| 5 | 耳道培养（慢性或复发性） |
| 6 | 影像学检查（X光、CT） |

### 耳道解剖

| 部位 | 特点 | 常见疾病 |
|------|------|---------|
| 耳廓 | 软骨支撑 | 耳廓血肿、耳廓皮炎 |
| 垂直耳道 | 垂直走行 | 外耳炎 |
| 水平耳道 | 水平走行 | 外耳炎、耳道增生 |
| 鼓膜 | 分隔外耳和中耳 | 鼓膜破裂、中耳炎 |
| 中耳 | 听小骨 | 中耳炎、耳道息肉 |
| 内耳 | 前庭、耳蜗 | 内耳炎、前庭综合征 |


## 常见耳病速查

### 外耳炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌、酵母菌、耳螨、过敏、异物、肿瘤 |
| 临床表现 | 耳道红肿、分泌物、异味、摇头、抓耳 |
| 诊断 | 耳镜、细胞学、培养 |
| 治疗 | 清洁耳道、局部用药（抗生素加抗真菌加激素） |
| 预后 | 多数预后良好，慢性者需长期管理 |

### 耳螨

| 项目 | 内容 |
|------|------|
| 病因 | 耳痒螨 |
| 临床表现 | 剧烈瘙痒、耳道内有黑色碎屑（咖啡渣样） |
| 诊断 | 耳镜、细胞学（可见螨虫） |
| 治疗 | 塞拉菌素、伊维菌素、莫西克丁 |
| 预后 | 预后良好，需同时治疗环境 |

### 马拉色菌性耳炎

| 项目 | 内容 |
|------|------|
| 病因 | 马拉色菌过度生长 |
| 临床表现 | 耳道红褐色分泌物、异味、瘙痒 |
| 诊断 | 细胞学（可见酵母菌） |
| 治疗 | 抗真菌药（酮康唑、咪康唑）、清洁耳道 |
| 预后 | 多数预后良好，需治疗原发病 |

### 细菌性耳炎

| 项目 | 内容 |
|------|------|
| 病因 | 葡萄球菌、链球菌、假单胞菌 |
| 临床表现 | 耳道红肿、脓性分泌物、疼痛 |
| 诊断 | 细胞学、培养加药敏 |
| 治疗 | 抗生素（根据药敏）、清洁耳道 |
| 预后 | 及时治疗预后良好，假单胞菌较难治 |

### 耳廓血肿

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、摇头、耳炎 |
| 临床表现 | 耳廓肿胀、波动感、疼痛 |
| 诊断 | 视诊、触诊 |
| 治疗 | 穿刺引流、手术修复 |
| 预后 | 手术预后良好，保守治疗易复发 |

### 中耳炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌、真菌、耳道息肉 |
| 临床表现 | 耳道深部疼痛、头倾斜、面神经麻痹 |
| 诊断 | 耳镜、X光、CT |
| 治疗 | 抗生素、手术（严重时） |
| 预后 | 及时治疗预后较好 |

### 耳道息肉

| 项目 | 内容 |
|------|------|
| 病因 | 炎症、先天性 |
| 临床表现 | 耳道可见肿物、耳道分泌物、摇头 |
| 诊断 | 耳镜、活检 |
| 治疗 | 手术切除 |
| 预后 | 手术预后良好 |

### 耳道肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 良性或恶性 |
| 临床表现 | 耳道肿物、分泌物、疼痛 |
| 诊断 | 耳镜、活检 |
| 治疗 | 手术切除、放疗 |
| 预后 | 取决于肿瘤类型 |


## 耳病治疗要点

### 耳道清洁

| 步骤 | 操作 |
|------|------|
| 1 | 选择合适的耳道清洁液（含干燥剂） |
| 2 | 将清洁液挤入耳道（充满耳道） |
| 3 | 按摩耳根（听到水声） |
| 4 | 让动物摇头（排出液体） |
| 5 | 用棉球擦拭耳廓和耳道口（不要用棉签深入耳道） |

### 局部用药

| 药物类型 | 常用药物 | 用途 |
|---------|---------|------|
| 抗生素 | 妥布霉素、氧氟沙星、恩诺沙星 | 细菌感染 |
| 抗真菌 | 酮康唑、咪康唑、克霉唑 | 马拉色菌 |
| 抗寄生虫 | 塞拉菌素、伊维菌素 | 耳螨 |
| 糖皮质激素 | 地塞米松、倍他米松 | 抗炎、止痒 |
| 复方制剂 | 抗生素加抗真菌加激素 | 混合感染 |

### 全身用药

| 药物 | 剂量（犬） | 剂量（猫） | 用途 |
|------|----------|----------|------|
| 塞拉菌素 | 6-12 mg/kg 外用 | 6-12 mg/kg 外用 | 耳螨 |
| 伊维菌素 | 0.2-0.4 mg/kg SC | 0.2-0.4 mg/kg SC | 耳螨 |
| 莫西克丁 | 2.5 mg/kg PO | 2.5 mg/kg PO | 耳螨 |
| 头孢氨苄 | 22-30 mg/kg PO BID | 22-30 mg/kg PO BID | 细菌感染 |
| 恩诺沙星 | 5-10 mg/kg PO SID | 5 mg/kg PO SID | 假单胞菌 |
| 伊曲康唑 | 5-10 mg/kg PO SID | 5 mg/kg PO SID | 真菌感染 |


## 耳病诊疗流程

耳部症状
    |
    ▼
耳部检查（视诊、耳镜、细胞学）
    |
    ▼
根据结果分诊
    ├── 耳廓 -> 血肿、皮炎
    ├── 外耳道 -> 外耳炎、耳螨、马拉色菌
    ├── 中耳 -> 中耳炎、息肉
    └── 内耳 -> 内耳炎、前庭综合征


## 客户沟通要点

### 解释耳病时
- 耳病诊断需要耳镜和细胞学检查，才能确定病因。
- 耳道清洁是治疗的重要部分，需要每天或隔天进行。
- 慢性耳病需要长期管理，不能指望一次治愈。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期清洁耳道，保持干燥。
- 如果出现摇头、抓耳、异味或分泌物增多，及时复诊。
- 过敏性耳炎需要同时控制过敏。
