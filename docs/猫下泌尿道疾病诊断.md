# 🐱 猫下泌尿道疾病（FLUTD）· 急诊思维导图

> 执业兽医师临床决策工具 | ⚠️ 急症提示：公猫超过24小时不排尿，必须立即就医 | 更新日期：2026年9月3日


## 🚨 急症速查（FLUTD临床决策）

| 情况 | 评估 | 行动 |
|------|------|------|
| 能摸到网球大膀胱 + 猫很沉/低温 | ⚠️ 危重急症 | → 立刻导尿，别等检查 |
| 膀胱像小橘子/核桃 + 猫还精神 | ⚠️ 需要处理 | → B超/X光 + 尿检 + 止痛 + 环境管理 |
| 反复发作/梗阻史 | 慢性管理 | → 长期饮食管理 + 应激控制 + 定期监测尿沉渣/B超 |


## 🩺 分类与诊疗要点

### 💎 尿道梗阻（急症）

> ⚠️ **尿闭超过24小时，可导致肾后性氮质血症和高血钾，直接危及生命！**

**诊断线索**
- 排尿用力、嚎叫、滴血尿
- 膀胱胀大如网球（触诊）
- 昏睡、呕吐、体温偏低（已尿闭超过24小时）
- 生化：BUN/Crea↑、血钾↑

**治疗思路**
1. 立即解除梗阻（尿道插管冲洗）
2. 留置导尿管 24~48 小时
3. 输液纠正脱水/高血钾
4. 稳定后排查原发病（结晶/栓子/解剖结构异常）


### 尿道栓子（黏液栓/结晶/小石子）

**诊断线索**
- 多见于青年公猫
- 结晶尿（鸟粪石/草酸钙）
- 膀胱内散在结晶或小颗粒

**治疗思路**
- 插管冲洗，冲出栓子
- 处方粮（溶结晶/防复发）
- 增加饮水（湿粮/流动水）


### 自发性膀胱炎（FIC）

> ⚠️ **最常见类型，与细菌感染无关，抗菌药无效！**

**诊断线索**
- 血尿、排尿费力，但膀胱不胀
- 有应激史（换粮、搬家、新成员）
- 尿检：无感染、无结晶

**治疗思路**
- 多模式环境改造（增加垂直空间、藏身处）
- 应激管理（信息素、规律作息）
- 止痛（丁丙诺啡/加巴喷丁）
- 鼓励喝水（湿粮）
- **不要轻易使用抗生素**


### 尿石症（鸟粪石/草酸钙）

**诊断线索**
- 反复排尿困难
- X光/B超可见膀胱内结石
- 尿液pH和结晶类型能对上

**治疗思路**
- 鸟粪石 → 处方粮溶解（需持续数月）
- 草酸钙 → 无法溶解，反复发作者需手术取石


### 细菌性膀胱炎/UTI

**诊断线索**
- 多见于＞10岁猫、糖尿病猫或慢性肾病猫
- 脓尿、尿液培养阳性
- 膀胱壁增厚

**治疗思路**
- 尿培养 + 药敏
- 选用敏感抗生素（至少2周）
- 停药后复查尿检，确认是否转阴


## 🩺 易混淆疾病（像泌尿道问题，但实际不是）

| 疾病 | 关键区别 |
|------|---------|
| 便秘/巨结肠 | 使劲蹲但拉的不是尿，腹部X光可见大肠内大量粪便 |
| 慢性肾病 | 多饮多尿、膀胱充盈良好，BUN/Crea明显升高但能排尿 |
| 骨盆骨折后尿道狭窄 | 有外伤史，X光可见骨盆骨折愈后畸形 |


## 🐾 客户沟通要点

### 接诊时
- “猫咪最近有没有排尿困难？尿团比以前小还是完全没有了？”
- “有没有排尿时嚎叫、频繁进出猫砂盆，或者滴血？”
- “最近家里有没有变化？换粮、搬家、来了新宠物或人？”
- “喝水情况怎么样？吃干粮还是湿粮？”

### 告知风险和方案
- “**尿不出来超过24小时，肾衰竭和高血钾就会随之而来，可能直接导致心脏停跳。** ”
- “公猫一旦尿闭，**唯一的办法就是插管导尿**。”
- “导尿管不能一直放，一般留置 48~72 小时，拔管后要看它自己能不能尿。”
- “FIC 不是细菌感染，**吃抗生素没有用**，关键是减少应激、多喝水。”
- “如果是反复梗阻，膀胱切开取石是根治结石最彻底的办法。”

### 出院指导
- **关键就是多喝水**：以湿粮为主，或喂含水量高的食物。
- **减少应激**：多准备猫砂盆，增加攀爬和躲藏空间；考虑使用信息素（如费利威）。
- **随时观察**：排尿是否顺利、尿团大小是否正常。
- **按时复查**：定期监测尿沉渣、B超和肾功能。


## 📌 用药参考（猫）

| 药物 | 剂量 | 用途 |
|------|------|------|
| 丁丙诺啡 | 0.01-0.03 mg/kg IV/SC/BU | 止痛 |
| 加巴喷丁 | 10-20 mg/kg PO BID | 止痛/应激管理 |
| 呋塞米 | 1-2 mg/kg PO/IV SID-BID | 解除梗阻后维持尿量 |
| 阿莫西林克拉维酸钾 | 12.5-15 mg/kg PO BID | 细菌感染（需药敏确认） |
| 恩诺沙星 | 5 mg/kg PO/IV SID | 细菌感染（需药敏确认） |
| 鸟粪石处方粮 | 按产品说明 | 溶解鸟粪石、防复发 |
| 信息素（费利威） | 按产品说明 | 应激管理 |

> ⚠️ 用药前请结合患猫具体体重、肝肾功能及有无用药禁忌再执行。所有抗生素建议在药敏结果指导下使用。
