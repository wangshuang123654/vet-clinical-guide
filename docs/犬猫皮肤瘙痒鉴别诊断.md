# 🐶🐱 犬猫皮肤瘙痒鉴别诊断 · 临床思维导图

> 执业兽医师临床决策工具 | 更新日期：2026年9月3日


## 🔑 瘙痒病因快速定位

| 临床表现 | 首选考虑 |
|---------|---------|
| 剧烈瘙痒 | 跳蚤过敏 > 疥螨 > 食物过敏 |
| 幼犬/免疫抑制 | 蠕形螨（不痒或轻痒） |
| 猫粟粒性皮炎 | 跳蚤过敏 > 食物过敏 |
| 反复/季节性 | 特应性皮炎（环境过敏） |
| 全年/与饮食相关 | 食物不良反应 |
| 足部/耳部为主 | 马拉色菌 > 食物过敏 > 特应性皮炎 |
| 突发/有接触史 | 接触性皮炎 |
| 对称脱毛/不痒 | 内分泌性（甲减/库欣） |


## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 疥螨/蠕形螨/姬螯螨 | 皮肤刮片（深刮/浅刮） | 镜检、PCR |
| 跳蚤过敏 | 梳检（蚤粪）、临床症状 | 诊断性治疗（驱蚤试验） |
| 细菌性脓皮病 | 细胞学（胶带粘贴/压片） | 细菌培养+药敏 |
| 真菌性（皮肤癣菌） | 伍德氏灯、真菌培养 | 毛干镜检、PCR |
| 马拉色菌 | 细胞学（胶带粘贴） | 镜检 |
| 食物过敏 | 排除饮食试验（8-12周） | 饮食挑战试验 |
| 特应性皮炎 | 排除其他病因、季节性 | 血清过敏原检测、皮内试验 |
| 内分泌性（甲减/库欣） | T4、TSH / ACTH刺激试验 | 生化、血常规 |
| 自身免疫性 | 活检（组织病理） | 免疫荧光 |


## 🐾 客户沟通要点

### 接诊时
- "瘙痒多久了？是季节性还是一年四季都有？"
- "主要在哪些部位瘙痒？头部？耳朵？脚？腰背部？"
- "除了瘙痒还有没有脱毛、皮屑、异味、或者皮肤发红？"
- "最近有没有换粮、换环境、或者接触新的东西？"
- "有没有按时驱虫？上一次驱蚤是什么时候？"

### 解释检查和方案
- "皮肤病大多数不是一次就能根治的，需要耐心排查，找到根本原因。"
- "很多皮肤病是过敏引起的——可能是跳蚤、食物或者环境中的东西。"
- "食物过敏最准的方法不是抽血，而是严格的食物排除试验，需要坚持8-12周。"
- "跳蚤过敏不在于身上看到多少跳蚤，一只就足够了。"

### 告知风险和预后
- "特应性皮炎是终身管理，不是根治，治疗目标是让生活质量最大化。"
- "蠕形螨与免疫状态相关，治好之后如果免疫再次低下，有复发的可能。"
- "深层脓皮病需要口服抗生素4-6周，不要提前停药。"

### 出院指导
- "严格按时驱蚤，每月一次，全年不间断。"
- "如果怀疑食物过敏，严格只吃指定的处方粮，不喂任何零食。"
- "定期药浴可以控制继发感染，减少瘙痒。"
- "如果出现瘙痒加重、皮肤破溃或精神状态变差，及时复诊。"
