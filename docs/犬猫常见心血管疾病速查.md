# 犬猫常见心血管疾病速查

> 执业兽医师临床决策工具 | 心脏病分期、常见疾病、急诊处理 | 更新日期：2026年9月15日


## 心血管系统检查基础

### 心血管检查流程

| 步骤 | 内容 |
|------|------|
| 1 | 病史采集（咳嗽、运动不耐受、晕厥） |
| 2 | 视诊（黏膜颜色、颈静脉怒张、腹围） |
| 3 | 听诊（心音、杂音、心律、肺音） |
| 4 | 触诊（脉搏、股动脉、心尖搏动） |
| 5 | 血压测量 |
| 6 | 影像学检查（X光、心超） |
| 7 | 心电图 |
| 8 | 生物标志物（NT-proBNP、cTnI） |

### 心脏病分期（ACVIM）

| 分期 | 描述 | 治疗 |
|------|------|------|
| A期 | 高风险品种，无结构病变 | 监测 |
| B1期 | 有杂音，无心脏增大 | 监测 |
| B2期 | 有杂音，心脏增大 | 开始用药 |
| C期 | 有症状的心衰 | 积极治疗 |
| D期 | 难治性心衰 | 强化治疗 |


## 犬常见心血管疾病

### 退行性二尖瓣病（MMVD）

| 项目 | 内容 |
|------|------|
| 好发品种 | 小型犬（贵宾、博美、骑士查理王） |
| 病因 | 二尖瓣退行性变 |
| 临床表现 | 心尖收缩期杂音、咳嗽、运动不耐受、夜咳 |
| 诊断 | 听诊、X光、心超 |
| 治疗 | 匹莫苯丹、ACEI、利尿剂 |
| 预后 | 早期预后良好，心衰后中位生存期6-12个月 |

### 扩张型心肌病（DCM）

| 项目 | 内容 |
|------|------|
| 好发品种 | 大型犬（杜宾、大丹、拳师） |
| 病因 | 遗传、营养（牛磺酸缺乏） |
| 临床表现 | 心律失常、虚弱、晕厥、腹水 |
| 诊断 | 心超（心室扩张、收缩力下降）、心电图 |
| 治疗 | 匹莫苯丹、ACEI、利尿剂、β受体阻滞剂 |
| 预后 | 预后较差，中位生存期6-12个月 |

### 心包积液

| 项目 | 内容 |
|------|------|
| 病因 | 特发性、肿瘤、心包炎 |
| 临床表现 | 心音遥远、颈静脉怒张、腹水、虚弱 |
| 诊断 | X光（球形心影）、心超 |
| 治疗 | 心包穿刺、心包切除 |
| 预后 | 取决于原发病 |

### 心内膜炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌感染（链球菌、葡萄球菌） |
| 临床表现 | 发热、杂音、虚弱、跛行 |
| 诊断 | 心超（赘生物）、血培养 |
| 治疗 | 抗生素（4-6周）、支持治疗 |
| 预后 | 及时治疗预后较好 |


## 猫常见心血管疾病

### 肥厚型心肌病（HCM）

| 项目 | 内容 |
|------|------|
| 好发品种 | 缅因猫、布偶猫、英短 |
| 病因 | 遗传、甲状腺功能亢进 |
| 临床表现 | 呼吸困难、虚弱、晕厥、后肢瘫痪 |
| 诊断 | 心超（心室壁增厚）、NT-proBNP |
| 治疗 | β受体阻滞剂、钙通道阻滞剂、抗血栓 |
| 预后 | 取决于严重程度，部分可长期稳定 |

### 限制型心肌病（RCM）

| 项目 | 内容 |
|------|------|
| 病因 | 心肌纤维化 |
| 临床表现 | 呼吸困难、心衰 |
| 诊断 | 心超 |
| 治疗 | 利尿剂、ACEI |
| 预后 | 预后较差 |

### 扩张型心肌病（DCM）

| 项目 | 内容 |
|------|------|
| 病因 | 牛磺酸缺乏、遗传 |
| 临床表现 | 心衰、心律失常 |
| 诊断 | 心超（心室扩张） |
| 治疗 | 牛磺酸补充、匹莫苯丹、ACEI |
| 预后 | 补充牛磺酸后部分可恢复 |

### 动脉血栓栓塞

| 项目 | 内容 |
|------|------|
| 病因 | HCM继发左心房增大 |
| 临床表现 | 后肢瘫痪、疼痛、发绀 |
| 诊断 | 心超、多普勒 |
| 治疗 | 止痛、抗凝、溶栓 |
| 预后 | 预后较差，复发率高 |


## 心血管疾病急诊处理

| 情况 | 处理 |
|------|------|
| 急性心衰 | 呋塞米、吸氧、匹莫苯丹 |
| 心包填塞 | 心包穿刺 |
| 动脉血栓栓塞 | 止痛、抗凝 |
| 晕厥 | 评估心律、心超 |
| 肺水肿 | 呋塞米、吸氧、限制输液 |


## 心血管药物速查

| 药物 | 剂量（犬） | 剂量（猫） | 用途 |
|------|----------|----------|------|
| 呋塞米 | 2-4 mg/kg PO或IV BID-TID | 1-2 mg/kg PO或IV SID-BID | 利尿 |
| 匹莫苯丹 | 0.25-0.5 mg/kg PO BID | 0.125-0.25 mg/kg PO BID | 强心 |
| 依那普利 | 0.25-0.5 mg/kg PO SID-BID | 0.25-0.5 mg/kg PO SID | ACEI |

| 阿替洛尔 | 0.2-1 mg/kg PO SID-BID | 0.2-0.5 mg/kg PO SID | β受体阻滞剂 |

## 心血管疾病诊疗流程

    |
    ▼

    |
    ▼

    |

    └── 心包积液 -> 心包穿刺


## 客户沟通要点

### 解释心血管疾病时
- 心脏病是慢性病，需要长期管理，不能根治。
- 定期复查心超和X光，调整用药剂量。
- 如果出现呼吸急促、咳嗽或晕厥，立即复诊。

### 出院指导
- 按医嘱用药，不要随意停药。
- 限制运动，避免剧烈活动。
- 低钠饮食，控制体重。
- 定期复查，监测病情变化。
