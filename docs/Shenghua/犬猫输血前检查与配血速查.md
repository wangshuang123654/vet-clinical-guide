# 犬猫输血前检查与配血速查

> 执业兽医师临床决策工具 | 血型鉴定、交叉配血、输血前检查 | 更新日期：2026年9月15日


## 输血前检查清单

| 项目 | 说明 |
|------|------|
| 血型鉴定 | 供血犬猫和受血犬猫均需检测 |
| 交叉配血 | 主侧+副侧配血 |
| 血常规 | 评估贫血程度 |
| 生化 | 评估肝肾功能 |
| 传染病筛查 | 供血犬猫需筛查 |
| 凝血功能 | 评估出血风险 |
| 血压 | 评估循环状态 |


## 犬血型系统（DEA）

| 血型 | 抗原 | 临床意义 |
|------|------|---------|
| DEA 1.1 | A1抗原 | 最强免疫原性，输血前必须配型 |
| DEA 1.2 | A2抗原 | 较弱免疫原性 |
| DEA 3 | B抗原 | 可产生同种抗体 |
| DEA 4 | C抗原 | 大多数犬为阳性，免疫原性弱 |
| DEA 5 | D抗原 | 可产生同种抗体 |
| DEA 6 | F抗原 | 免疫原性弱 |
| DEA 7 | G抗原 | 可产生同种抗体 |
| DEA 8 | H抗原 | 免疫原性弱 |

### 犬输血原则

| 原则 | 说明 |
|------|------|
| 首次输血 | 必须做DEA 1.1配型 |
| 再次输血 | 必须做交叉配血 |
| 理想供血犬 | DEA 1.1阴性 |
| DEA 1.1阴性犬 | 接受DEA 1.1阳性血后产生抗体 |


## 猫血型系统（AB）

| 血型 | 抗原 | 临床意义 |
|------|------|---------|
| A型 | A抗原 | 最常见（约95%以上） |
| B型 | B抗原 | 较少见，某些品种高发 |
| AB型 | A和B抗原 | 极罕见 |

### 猫输血原则

| 原则 | 说明 |
|------|------|
| A型猫 | 有抗B抗体（弱） |
| B型猫 | 有抗A抗体（强） |
| B型猫接受A型血 | 可致严重溶血反应，甚至致死 |
| 输血前 | 必须做血型鉴定和交叉配血 |
| 首次输血 | 也必须配型 |


## 交叉配血

### 配血方法

| 方法 | 说明 |
|------|------|
| 主侧配血 | 供血红细胞 + 受血血清 |
| 副侧配血 | 受血红细胞 + 供血血清 |
| 结果判读 | 无凝集、无溶血为配血相合 |

### 配血步骤

| 步骤 | 操作 |
|------|------|
| 1 | 采集供血和受血EDTA抗凝血 |
| 2 | 离心，分离红细胞和血清 |
| 3 | 洗涤红细胞（生理盐水） |
| 4 | 制备2-5%红细胞悬液 |
| 5 | 主侧：供血红细胞 + 受血血清 |
| 6 | 副侧：受血红细胞 + 供血血清 |
| 7 | 37℃孵育15-30分钟 |
| 8 | 离心，观察凝集和溶血 |
| 9 | 判读结果 |

### 配血结果判读

| 结果 | 判读 |
|------|------|
| 无凝集、无溶血 | 配血相合，可输血 |
| 凝集 | 配血不合，不可输血 |
| 溶血 | 配血不合，不可输血 |
| 弱凝集 | 需进一步评估 |


## 供血犬猫选择标准

| 项目 | 犬 | 猫 |
|------|-----|-----|
| 体重 | 大于20kg | 大于4kg |
| 年龄 | 1-8岁 | 1-8岁 |
| 健康状况 | 健康，无传染病 | 健康，无传染病 |
| 疫苗接种 | 已完成核心疫苗 | 已完成核心疫苗 |
| 血型 | DEA 1.1阴性 | A型（理想） |
| PCV | 大于40% | 大于30% |
| 献血间隔 | 每3个月 | 每3个月 |
| 献血量 | 10-15 mL/kg | 8-10 mL/kg |

### 供血犬猫传染病筛查

| 项目 | 犬 | 猫 |
|------|-----|-----|
| 心丝虫 | 抗原检测 | 抗原检测 |
| 巴贝斯虫 | 血涂片、PCR | - |
| 埃立克体 | 抗体检测 | - |
| 莱姆病 | 抗体检测 | - |
| 猫白血病 | - | FeLV抗原 |
| 猫免疫缺陷 | - | FIV抗体 |
| 猫瘟 | - | 抗原检测 |

    |
    ▼

    |
    ▼
血型鉴定（供血+受血）
    |
    ▼

    |

    |

## 输血指征

| 情况 | 输血指征 |
|------|---------|
| 急性失血 | PCV小于20% |
| 溶血性贫血 | PCV小于15% |
| 血小板减少 | 血小板小于10×10³/μL |
| 凝血障碍 | PT或APTT延长 |
| 低蛋白血症 | 白蛋白小于1.5 g/dL |


## 输血反应识别

| 类型 | 表现 | 处理 |
|------|------|------|
| 溶血反应 | 发热、血红蛋白尿、低血压 | 停止输血、输液、利尿 |
| 过敏反应 | 荨麻疹、水肿、呼吸困难 | 停止输血、抗组胺药 |
| 发热反应 | 体温升高、寒战 | 停止输血、退热 |
| 细菌污染 | 高热、休克 | 停止输血、抗生素 |
| 循环过负荷 | 呼吸急促、肺水肿 | 停止输血、利尿 |


## 输血操作规范

| 步骤 | 操作 |
|------|------|
| 1 | 确认血型鉴定和交叉配血结果 |
| 2 | 检查血袋（有无溶血、凝块、变色） |
| 3 | 准备输血器（带滤网） |
| 4 | 建立静脉通路 |
| 5 | 准备抢救药物 |
| 6 | 前15分钟缓慢输注 |
| 7 | 监测生命体征 |
| 8 | 逐步加快至维持速度 |
| 9 | 输血完成后复查PCV |


## 客户沟通要点

### 解释输血前检查时
- 输血前必须做血型鉴定和交叉配血，确保输血安全。
- 供血犬猫需要经过严格筛查，确保健康。
- 输血有风险，但正规血源经过筛查，风险很低。

### 出院指导
- 输血后24小时内避免剧烈运动。
- 如果出现发热、黄疸、精神变差或呼吸困难，立即复诊。
- 输血后1周复查血常规，评估治疗效果。
