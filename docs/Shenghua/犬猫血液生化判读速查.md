# 犬猫血液生化判读速查

> 执业兽医师临床决策工具 | 肝肾功能、血糖、蛋白、酶学判读 | 更新日期：2026年9月15日


## 生化判读核心原则

| 原则 | 说明 |
|------|------|
| 结合临床 | 生化不能单独诊断，需结合病史和体检 |
| 动态监测 | 单次值不如趋势有价值 |
| 器官关联 | 多个指标联合判读 |
| 排除干扰 | 脱水、溶血、脂血影响结果 |
| 参考范围 | 不同实验室参考值有差异 |


## 肾功能指标

### BUN（尿素氮）

| 项目 | 说明 |
|------|------|
| 犬参考 | 7-27 mg/dL |
| 猫参考 | 16-36 mg/dL |
| 升高原因 | 肾前性（脱水、心衰）、肾性（肾衰）、肾后性（尿道梗阻） |
| 降低原因 | 肝病、低蛋白饮食、多饮多尿 |
| 临床意义 | 受饮食和脱水影响大 |

### CREA（肌酐）

| 项目 | 说明 |
|------|------|
| 犬参考 | 0.5-1.5 mg/dL |
| 猫参考 | 0.6-2.4 mg/dL |
| 升高原因 | 肾性（肾衰）、肾后性（尿道梗阻） |
| 降低原因 | 肌肉萎缩、肝病 |
| 临床意义 | 比BUN更特异，但肾损伤超过75%才升高 |

### SDMA

| 项目 | 说明 |
|------|------|
| 参考 | 0-14 μg/dL |
| 升高原因 | 肾功能下降（比CREA更敏感） |
| 临床意义 | 早期肾损伤标志物，肾损伤40%即可升高 |

### 肾功能判读

| BUN | CREA | SDMA | 可能原因 |
|-----|------|------|---------|
| ↑ | ↑ | ↑ | 肾性肾衰 |
| ↑ | 正常 | 正常 | 肾前性（脱水） |
| 正常 | ↑ | ↑ | 早期肾衰 |
| ↑ | ↑ | ↑ | 肾后性（尿道梗阻） |


## 肝功能指标

### ALT（丙氨酸氨基转移酶）

| 项目 | 说明 |
|------|------|
| 犬参考 | 18-86 U/L |
| 猫参考 | 28-100 U/L |
| 升高原因 | 肝细胞损伤（肝炎、中毒、缺氧） |
| 临床意义 | 肝细胞损伤的敏感指标 |

### AST（天冬氨酸氨基转移酶）

| 项目 | 说明 |
|------|------|
| 犬参考 | 15-45 U/L |
| 猫参考 | 13-50 U/L |
| 升高原因 | 肝细胞损伤、肌肉损伤 |
| 临床意义 | 不如ALT特异 |

### ALP（碱性磷酸酶）

| 项目 | 说明 |
|------|------|
| 犬参考 | 20-150 U/L |
| 猫参考 | 25-100 U/L |
| 升高原因 | 胆汁淤积、激素（库欣）、骨病 |
| 临床意义 | 犬ALP升高提示胆汁淤积或库欣 |

### GGT（γ-谷氨酰转移酶）

| 项目 | 说明 |
|------|------|
| 犬参考 | 0-7 U/L |
| 猫参考 | 0-5 U/L |
| 升高原因 | 胆汁淤积 |
| 临床意义 | 比ALP更特异 |

### 总胆红素

| 项目 | 说明 |
|------|------|
| 犬参考 | 0.1-0.5 mg/dL |
| 猫参考 | 0.1-0.5 mg/dL |
| 升高原因 | 肝前性（溶血）、肝性（肝炎）、肝后性（胆道梗阻） |
| 临床意义 | 黄疸的指标 |

### 肝功能判读

| ALT | ALP | GGT | 胆红素 | 可能原因 |
|-----|-----|-----|--------|---------|
| ↑ | 正常 | 正常 | 正常 | 肝细胞损伤 |
| 正常 | ↑ | ↑ | ↑ | 胆汁淤积 |
| ↑ | ↑ | ↑ | ↑ | 肝炎+胆汁淤积 |
| 正常 | ↑ | 正常 | 正常 | 库欣、激素 |

## 客户沟通要点

### 解释生化时
- 生化检查可以评估肝肾功能、血糖和电解质。
- 生化异常需要结合血常规、影像学和临床症状综合判断。
- 有些指标需要动态监测，单次结果不能说明全部。

### 出院指导
- 按医嘱复查生化，监测病情变化。
- 如果出现精神变差、食欲下降或黄疸，立即复诊。
