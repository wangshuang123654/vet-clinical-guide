## 皮肤细胞学采样方法

| 方法 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 胶带粘贴 | 表面微生物、螨虫 | 简单、无创 | 仅表层 |
| 皮肤刮片 | 螨虫、深层感染 | 可深达毛囊 | 可能出血 |
| 压片 | 脓疱、溃疡、渗出 | 简单、快速 | 仅表面 |
| 细针穿刺 | 结节、肿块、囊肿 | 可深部采样 | 需技术 |
| 拭子 | 耳道、瘘管 | 简单 | 细胞量少 |

### 采样注意事项

| 项目 | 说明 |
|------|------|
| 无菌 | 严格无菌操作 |
| 部位 | 选择病变活动边缘 |
| 深度 | 根据病变深度选择 |
| 涂片 | 薄涂，单层细胞 |
| 干燥 | 自然风干 |
| 染色 | Diff-Quik或瑞氏染色 |


## 皮肤细胞学判读

### 正常皮肤细胞学

| 细胞 | 正常表现 |
|------|---------|
| 角质细胞 | 少量 |
| 鳞状上皮细胞 | 少量 |
| 中性粒细胞 | 偶见 |
| 细菌 | 少量（非致病） |
| 酵母菌 | 偶见 |


### 感染性皮肤病

| 表现 | 可能原因 |
|------|---------|
| 球菌（大量） | 脓皮病 |
| 杆菌（大量） | 假单胞菌感染 |
| 酵母菌（大量） | 马拉色菌性皮炎 |
| 真菌菌丝 | 皮肤癣菌 |
| 中性粒细胞+细菌 | 化脓性感染 |
| 巨噬细胞+细菌 | 肉芽肿性感染 |


### 寄生虫性皮肤病

| 表现 | 可能原因 |
|------|---------|
| 螨虫（成虫/幼虫/卵） | 疥螨、蠕形螨、姬螯螨 |
| 嗜酸性粒细胞 | 过敏、寄生虫 |
| 跳蚤粪便 | 跳蚤过敏 |
| 虱卵 | 虱子感染 |


### 肿瘤性皮肤病

| 表现 | 可能原因 |
|------|---------|
| 肥大细胞（紫色颗粒） | 肥大细胞瘤 |
| 圆形细胞（淋巴样） | 淋巴瘤 |
| 组织细胞 | 组织细胞瘤 |
| 纺锤形细胞 | 纤维肉瘤、软组织肉瘤 |
| 上皮细胞成团 | 腺瘤、腺癌 |
| 角化细胞 | 鳞状细胞癌 |


### 免疫介导性皮肤病

| 表现 | 可能原因 |
|------|---------|
| 棘层松解细胞 | 天疱疮 |
| 中性粒细胞+棘层松解 | 天疱疮 |
| 淋巴细胞+浆细胞 | 红斑狼疮 |
| 界面皮炎 | 红斑狼疮 |

## 皮肤/耳道细胞学判读流程

采样
    |
    ▼
涂片、染色
    |
    ▼
低倍镜（评估细胞量、分布）
    |
    ▼
油镜（100×）观察
    |
    ▼
分类
    ├── 感染 -> 细菌、真菌、寄生虫
    ├── 炎症 -> 中性粒细胞、巨噬细胞、嗜酸性粒细胞
    ├── 肿瘤 -> 圆形细胞、上皮性、间质性
    └── 免疫介导 -> 棘层松解、界面皮炎
    |
    ▼
综合判读，结合临床

## 客户沟通要点

### 解释皮肤/耳道细胞学时
- 细胞学是快速筛查手段，可以在几分钟内得到初步结果。
- 细胞学不能完全替代活检，有时需要进一步检查。
- 细胞学结果需要结合临床和其他检查综合判断。

### 出院指导
- 如果细胞学提示感染，需要根据培养和药敏选择抗生素。
- 如果细胞学提示肿瘤，可能需要进一步活检和分期。
- 定期复查，监测病情变化。
