# 犬猫电解质紊乱速查

> 执业兽医师临床决策工具 | 钠、钾、钙、磷、氯异常处理 | 更新日期：2026年9月15日


## 电解质正常参考值

| 电解质 | 犬 | 猫 | 单位 |
|--------|-----|-----|------|
| 钠（Na⁺） | 139-154 | 145-158 | mEq/L |
| 钾（K⁺） | 3.6-5.6 | 3.5-5.8 | mEq/L |
| 氯（Cl⁻） | 102-120 | 112-129 | mEq/L |
| 钙（Ca²⁺） | 8.8-11.2 | 8.0-10.5 | mg/dL |
| 离子钙（iCa） | 1.1-1.4 | 1.1-1.4 | mmol/L |
| 磷（P） | 3.0-6.2 | 2.8-5.5 | mg/dL |
| 镁（Mg²⁺） | 1.5-2.5 | 1.5-2.5 | mg/dL |


## 钠离子紊乱

### 低钠血症

| 项目 | 内容 |
|------|------|
| 定义 | Na⁺ 小于139 mEq/L（犬），小于145 mEq/L（猫） |
| 病因 | 呕吐、腹泻、利尿剂、肾衰、阿迪森、SIADH |
| 临床表现 | 虚弱、恶心、抽搐、昏迷 |
| 治疗 | 补钠（0.9% NaCl）、治疗原发病 |
| 纠正速率 | 每小时不超过0.5-1 mEq/L |
| 注意事项 | 快速纠正可致脑水肿 |

### 高钠血症

| 项目 | 内容 |
|------|------|
| 定义 | Na⁺ 大于154 mEq/L（犬），大于158 mEq/L（猫） |
| 病因 | 脱水、饮水不足、糖尿病、尿崩症 |
| 临床表现 | 口渴、虚弱、抽搐、昏迷 |
| 治疗 | 补液（0.45% NaCl或5%葡萄糖） |
| 纠正速率 | 每小时不超过0.5-1 mEq/L |
| 注意事项 | 快速纠正可致脑水肿 |


## 钾离子紊乱

### 低钾血症

| 项目 | 内容 |
|------|------|
| 定义 | K⁺ 小于3.6 mEq/L（犬），小于3.5 mEq/L（猫） |
| 病因 | 呕吐、腹泻、利尿剂、肾小管酸中毒、胰岛素 |
| 临床表现 | 肌无力、心律失常、多饮多尿 |
| 治疗 | 补钾（见补钾方案） |
| 补钾方案 | 血清钾3.0-3.5：30 mEq/L；小于3.0：40 mEq/L |
| 最大速率 | 0.5 mEq/kg/h |
| 注意事项 | 补钾前需确认有尿 |

### 高钾血症

| 项目 | 内容 |
|------|------|
| 定义 | K⁺ 大于5.6 mEq/L（犬），大于5.8 mEq/L（猫） |
| 病因 | 肾衰、阿迪森、尿道梗阻、溶血、酸中毒 |
| 临床表现 | 心动过缓、心律失常、肌无力 |
| 治疗 | 补钙、胰岛素加葡萄糖、利尿、透析 |
| 急诊处理 | 10%葡萄糖酸钙 0.5-1.5 mL/kg IV 缓慢 |
| 注意事项 | 监测心电图 |

### 高钾血症心电图表现

| 血钾 | 心电图表现 |
|------|-----------|
| 5.5-6.5 | T波高尖 |
| 6.5-7.5 | P波消失、QRS增宽 |
| 大于7.5 | 正弦波、心室颤动、心脏停搏 |


## 钙离子紊乱

### 低钙血症

| 项目 | 内容 |
|------|------|
| 定义 | Ca²⁺ 小于8.8 mg/dL（犬），小于8.0 mg/dL（猫） |
| 病因 | 产后瘫、肾衰、甲旁减、胰腺炎、低蛋白 |
| 临床表现 | 肌肉震颤、抽搐、面部瘙痒 |
| 治疗 | 10%葡萄糖酸钙 0.5-1.5 mL/kg IV 缓慢 |
| 注意事项 | 监测心电图，避免快速推注 |

### 高钙血症

| 项目 | 内容 |
|------|------|
| 定义 | Ca²⁺ 大于11.2 mg/dL（犬），大于10.5 mg/dL（猫） |
| 病因 | 肿瘤、甲旁亢、维生素D中毒、肾衰 |
| 临床表现 | 多饮多尿、呕吐、虚弱、肾结石 |
| 治疗 | 补液、利尿、降钙素、糖皮质激素 |
| 注意事项 | 治疗原发病 |

| 临床表现 | 肌无力、溶血、抽搐 |

| 治疗 | 磷结合剂、肾脏处方粮 |

## 电解质紊乱处理流程

电解质异常
    |
    ▼
确认异常（钠、钾、氯、钙、磷、镁）
    |
    ▼
评估病因（肾、胃肠、内分泌、药物）
    |
    ▼
根据严重程度处理
    ├── 轻度 -> 治疗原发病
    ├── 中度 -> 补充或限制
    └── 重度 -> 紧急处理
    |
    ▼
监测（血气、心电图、电解质）
    |
    ▼
调整方案


## 电解质紊乱紧急处理

| 情况 | 处理 |
|------|------|
| 高钾血症（心电图异常） | 补钙、胰岛素加葡萄糖 |
| 低钙血症（抽搐） | 10%葡萄糖酸钙 IV 缓慢 |
| 低钠血症（抽搐） | 补钠（缓慢纠正） |
| 高钠血症（抽搐） | 补液（缓慢纠正） |
| 低钾血症（心律失常） | 补钾（监测心电图） |


## 客户沟通要点

### 解释电解质紊乱时
- 电解质紊乱需要结合血气和其他检查综合判断。
- 纠正电解质紊乱需要缓慢进行，快速纠正可能引起严重并发症。
- 需要定期复查电解质，调整治疗方案。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查电解质和血气。
- 如果出现肌无力、抽搐或精神变差，立即复诊。
