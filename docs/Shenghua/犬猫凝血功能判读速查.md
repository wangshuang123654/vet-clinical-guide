# 犬猫凝血功能判读速查

> 执业兽医师临床决策工具 | PT、APTT、D-二聚体、FDP判读 | 更新日期：2026年9月15日


## 凝血功能核心指标

| 指标 | 犬参考 | 猫参考 | 意义 |
|------|--------|--------|------|
| PT | 6-12秒 | 6-12秒 | 外源性凝血途径 |
| APTT | 12-22秒 | 12-22秒 | 内源性凝血途径 |
| FDP | 小于10 μg/mL | 小于10 μg/mL | 纤维蛋白降解产物 |
| D-二聚体 | 小于0.5 μg/mL | 小于0.5 μg/mL | 交联纤维蛋白降解产物 |
| 纤维蛋白原 | 150-300 mg/dL | 150-300 mg/dL | 纤维蛋白原 |
| 血小板 | 200-500 ×10³/μL | 200-700 ×10³/μL | 一期止血 |


## PT（凝血酶原时间）

| 项目 | 说明 |
|------|------|
| 检测途径 | 外源性凝血途径（因子II、V、VII、X） |
| 犬参考 | 6-12秒 |
| 猫参考 | 6-12秒 |
| 延长原因 | 华法林中毒、肝病、DIC、维生素K缺乏 |
| 临床意义 | PT延长提示外源性凝血途径异常 |

### PT延长常见原因

| 原因 | 说明 |
|------|------|
| 抗凝血灭鼠药 | 华法林类，维生素K拮抗 |
| 肝病 | 凝血因子合成减少 |
| DIC | 凝血因子消耗 |
| 维生素K缺乏 | 肠道吸收不良、长期抗生素 |
| 遗传性凝血因子缺乏 | 罕见 |


## APTT（活化部分凝血活酶时间）

| 项目 | 说明 |
|------|------|
| 检测途径 | 内源性凝血途径（因子VIII、IX、XI、XII） |
| 犬参考 | 12-22秒 |
| 猫参考 | 12-22秒 |
| 延长原因 | 肝病、DIC、血友病、抗凝治疗 |
| 临床意义 | APTT延长提示内源性凝血途径异常 |

### APTT延长常见原因

| 原因 | 说明 |
|------|------|
| 肝病 | 凝血因子合成减少 |
| DIC | 凝血因子消耗 |
| 血友病 | 因子VIII或IX缺乏 |
| 抗凝治疗 | 肝素 |
| 遗传性凝血因子缺乏 | 罕见 |


## FDP（纤维蛋白降解产物）

| 项目 | 说明 |
|------|------|
| 参考 | 小于10 μg/mL |
| 升高原因 | DIC、血栓、纤溶亢进 |
| 临床意义 | 提示纤溶系统激活 |

### FDP升高常见原因

| 原因 | 说明 |
|------|------|
| DIC | 弥散性血管内凝血 |
| 血栓 | 深静脉血栓、肺栓塞 |
| 纤溶亢进 | 原发性纤溶 |
| 肝病 | 清除减少 |


## D-二聚体

| 项目 | 说明 |
|------|------|
| 参考 | 小于0.5 μg/mL |
| 升高原因 | DIC、血栓、纤溶亢进 |
| 临床意义 | 比FDP更特异，提示交联纤维蛋白降解 |

### D-二聚体升高常见原因

| 原因 | 说明 |
|------|------|
| DIC | 弥散性血管内凝血 |
| 血栓 | 深静脉血栓、肺栓塞 |
| 手术 | 术后轻度升高 |
| 肿瘤 | 高凝状态 |
| 炎症 | 全身炎症反应 |


## 纤维蛋白原

| 项目 | 说明 |
|------|------|
| 参考 | 150-300 mg/dL |
| 升高原因 | 炎症、感染、肿瘤 |
| 降低原因 | DIC、肝病、纤溶亢进 |
| 临床意义 | 急性期蛋白，也参与凝血 |


## DIC诊断

### DIC诊断标准

| 项目 | 异常 |
|------|------|
| 血小板 | 小于100 ×10³/μL |
| PT | 延长大于参考上限 |
| APTT | 延长大于参考上限 |
| 纤维蛋白原 | 小于150 mg/dL |
| FDP | 大于10 μg/mL |
| D-二聚体 | 大于0.5 μg/mL |

> 符合3项及以上，结合临床可诊断DIC。

### DIC治疗

| 项目 | 处理 |
|------|------|
| 治疗原发病 | 感染、肿瘤、创伤 |
| 补液 | 维持灌注 |
| 输血 | 血小板、新鲜冷冻血浆 |
| 抗凝 | 肝素（争议） |
| 支持 | 监测凝血功能 |


## 凝血功能判读流程

凝血功能检查
    |
    ▼
PT（外源性）
    |
    ▼
APTT（内源性）
    |
    ▼
FDP、D-二聚体（纤溶）
    |
    ▼
纤维蛋白原、血小板
    |
    ▼
综合判断
    ├── PT延长 -> 外源性途径异常
    ├── APTT延长 -> 内源性途径异常
    ├── PT+APTT延长 -> 共同途径异常、DIC、肝病
    ├── FDP/D-二聚体升高 -> 纤溶亢进、DIC
    └── 全部异常 -> DIC

| PT | APTT | FDP | D-二聚体 | 可能原因 |
|-----|------|-----|---------|---------|
| ↑ | 正常 | 正常 | 正常 | 华法林中毒、维生素K缺乏 |
| 正常 | ↑ | 正常 | 正常 | 血友病、肝素 |
| ↑ | ↑ | ↑ | ↑ | DIC |
| ↑ | ↑ | 正常 | 正常 | 肝病 |
| 正常 | 正常 | ↑ | ↑ | 血栓、纤溶亢进 |


## 抗凝血灭鼠药中毒

| 项目 | 说明 |
|------|------|
| 毒物 | 华法林、溴敌隆 |
| 机制 | 维生素K拮抗 |
| 临床表现 | 出血倾向、瘀斑、血便 |
| PT | 延长 |
| APTT | 延长 |
| 治疗 | 维生素K1 2.5-5 mg/kg SC/IM |
| 疗程 | 3-4周 |
| 监测 | PT、APTT |


## 客户沟通要点

### 解释凝血功能时
- 凝血功能检查可以评估出血风险和凝血障碍。
- PT和APTT延长提示凝血因子异常，需要进一步检查。
- DIC是危重并发症，需要紧急处理。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查凝血功能。
- 如果出现出血倾向、瘀斑或血便，立即复诊。
