# 犬猫细胞学判读速查

> 执业兽医师临床决策工具 | 细针穿刺、积液、皮肤细胞学判读 | 更新日期：2026年9月15日


## 细胞学采样方法

| 方法 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 细针穿刺（FNA） | 肿块、淋巴结、内脏 | 快速、微创 | 细胞量少 |
| 压片 | 组织表面、切口 | 简单 | 细胞易变形 |
| 刮片 | 皮肤、黏膜 | 表层细胞 | 仅表层 |
| 积液涂片 | 胸腔、腹腔积液 | 诊断积液性质 | 细胞易退化 |
| 灌洗 | 支气管、膀胱 | 深部细胞 | 需器械 |
| 印片 | 活检组织 | 细胞排列 | 仅表面 |

### 采样注意事项

| 项目 | 说明 |
|------|------|
| 无菌 | 严格无菌操作 |
| 快速 | 采样后立即涂片 |
| 薄涂 | 涂片要薄，细胞单层 |
| 自然干燥 | 风干，不用加热 |
| 染色 | Diff-Quik或瑞氏染色 |


## 细胞学判读基础

### 细胞类型

| 细胞 | 形态 | 临床意义 |
|------|------|---------|
| 中性粒细胞 | 分叶核 | 炎症、感染 |
| 淋巴细胞 | 圆形、核深染 | 淋巴瘤、炎症 |
| 巨噬细胞 | 大、空泡 | 慢性炎症、分支杆菌 |
| 浆细胞 | 偏心核、嗜碱性 | 慢性炎症 |
| 嗜酸性粒细胞 | 红色颗粒 | 过敏、寄生虫 |
| 肥大细胞 | 紫色颗粒 | 肥大细胞瘤 |
| 肿瘤细胞 | 异型性 | 肿瘤 |

### 炎症类型

| 类型 | 主要细胞 | 常见原因 |
|------|---------|---------|
| 化脓性炎症 | 中性粒细胞为主 | 细菌感染 |
| 肉芽肿性炎症 | 巨噬细胞为主 | 真菌、分支杆菌 |
| 嗜酸性炎症 | 嗜酸性粒细胞为主 | 过敏、寄生虫 |
| 混合性炎症 | 多种细胞 | 慢性炎症 |
| 淋巴浆细胞性 | 淋巴细胞、浆细胞 | 慢性炎症、免疫介导 |


## 常见肿瘤细胞学

### 圆形细胞肿瘤

| 肿瘤 | 细胞特征 | 鉴别 |
|------|---------|------|
| 淋巴瘤 | 淋巴细胞单一增生、核大 | 流式细胞术 |
| 肥大细胞瘤 | 紫色颗粒 | 细针穿刺 |
| 组织细胞瘤 | 组织细胞、空泡 | 年轻犬、可自愈 |
| 浆细胞瘤 | 浆细胞、偏心核 | 骨髓瘤 |
| 传染性性病肿瘤 | 圆形细胞、有丝分裂 | 犬、交配传播 |

### 上皮性肿瘤

| 肿瘤 | 细胞特征 | 鉴别 |
|------|---------|------|
| 腺瘤/腺癌 | 细胞成团、细胞连接 | 活检 |
| 鳞状细胞癌 | 角化细胞、细胞大 | 活检 |
| 基底细胞瘤 | 基底细胞样 | 活检 |

### 间质性肿瘤

| 肿瘤 | 细胞特征 | 鉴别 |
|------|---------|------|
| 纤维肉瘤 | 纺锤形细胞 | 活检 |
| 骨肉瘤 | 成骨细胞、骨质 | X光、活检 |
| 血管肉瘤 | 内皮细胞 | 活检 |
| 脂肪瘤/脂肪肉瘤 | 脂肪细胞 | 活检 |


## 积液细胞学

### 积液分类

| 类型 | 蛋白 | 细胞 | 常见原因 |
|------|------|------|---------|
| 漏出液 | 低（小于2.5 g/dL） | 少（小于1000/μL） | 低蛋白、心衰、肝衰 |
| 渗出液 | 高（大于3.0 g/dL） | 多（大于3000/μL） | 感染、肿瘤、FIP |
| 血性积液 | 高 | 红细胞多 | 出血、肿瘤 |
| 乳糜性积液 | 高 | 淋巴细胞多 | 乳糜胸 |
| 脓性积液 | 高 | 中性粒细胞多 | 脓胸 |

### 积液细胞学判读

| 表现 | 可能原因 |
|------|---------|
| 中性粒细胞为主 | 细菌感染、脓胸 |
| 淋巴细胞为主 | 乳糜胸、FIP |
| 巨噬细胞为主 | 慢性炎症、FIP |
| 肿瘤细胞 | 肿瘤转移 |
| 细菌 | 感染 |
| 真菌 | 真菌感染 |
| 结晶体 | 尿酸盐、胆固醇 |

## 细胞学判读流程

细胞学样本
    |
    ▼
染色（Diff-Quik或瑞氏）
    |
    ▼
低倍镜（评估细胞量、分布）
    |
    ▼
高倍镜（细胞形态、类型）
    |
    ▼
分类
    ├── 炎症 -> 化脓性、肉芽肿性、嗜酸性
    ├── 肿瘤 -> 圆形细胞、上皮性、间质性
    ├── 积液 -> 漏出液、渗出液、血性、乳糜性
    └── 感染 -> 细菌、真菌、寄生虫


## 细胞学判读注意事项

| 项目 | 说明 |
|------|------|
| 采样质量 | 细胞量、细胞形态 |
| 炎症背景 | 有无炎症、坏死 |
| 细胞异型性 | 核大、核仁明显、有丝分裂 |
| 细胞排列 | 成团、散在、腺样 |
| 背景 | 坏死、出血、黏液 |
| 微生物 | 细菌、真菌、寄生虫 |
| 结合临床 | 细胞学不能替代活检 |


## 客户沟通要点

### 解释细胞学时
- 细胞学是快速筛查手段，可以在几分钟内得到初步结果。
- 细胞学不能完全替代活检，有时需要进一步检查。
- 细胞学结果需要结合临床和其他检查综合判断。

### 出院指导
- 如果细胞学提示肿瘤，可能需要进一步活检和分期。
- 如果细胞学提示感染，需要根据培养和药敏选择抗生素。
- 定期复查，监测病情变化。
