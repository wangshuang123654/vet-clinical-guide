# 犬猫血常规判读速查

> 执业兽医师临床决策工具 | 红细胞、白细胞、血小板判读 | 更新日期：2026年9月15日


## 血常规判读核心原则

| 原则 | 说明 |
|------|------|
| 结合临床 | 血常规不能单独诊断，需结合病史和体检 |
| 动态监测 | 单次值不如趋势有价值 |
| 三系联合 | 红细胞、白细胞、血小板联合判读 |
| 排除干扰 | 脱水、应激、年龄影响结果 |
| 参考范围 | 不同实验室参考值有差异 |


## 红细胞参数

### 红细胞计数（RBC）

| 项目 | 犬参考 | 猫参考 |
|------|--------|--------|
| RBC | 5.5-8.5 ×10⁶/μL | 5.0-10.0 ×10⁶/μL |
| HCT | 37-55% | 30-45% |
| Hb | 12-18 g/dL | 8-15 g/dL |
| MCV | 60-77 fL | 39-55 fL |
| MCHC | 32-36 g/dL | 30-36 g/dL |
| 网织红细胞 | 0-1.5% | 0-1.0% |

### 贫血判读

| 类型 | MCV | MCHC | 网织红细胞 | 常见原因 |
|------|-----|------|-----------|---------|
| 再生性贫血 | ↑ | 正常 | ↑ | 失血、溶血 |
| 非再生性贫血 | 正常/↓ | 正常 | ↓ | 骨髓抑制、慢性病 |
| 小细胞性贫血 | ↓ | ↓ | 不定 | 缺铁 |
| 大细胞性贫血 | ↑ | 正常 | ↑ | 再生性贫血 |

### 贫血分级

| 分级 | HCT（犬） | HCT（猫） | 临床意义 |
|------|----------|----------|---------|
| 轻度 | 30-37% | 25-30% | 需监测 |
| 中度 | 20-30% | 15-25% | 需治疗 |
| 重度 | 小于20% | 小于15% | 需输血 |

### 红细胞增多

| 类型 | 原因 |
|------|------|
| 相对增多 | 脱水 |
| 绝对增多 | 慢性缺氧、EPO增多、真性红细胞增多症 |

### 白细胞增多

| 类型 | 常见原因 |
|------|---------|
| 中性粒细胞增多 | 细菌感染、炎症、应激 |
| 淋巴细胞增多 | 病毒感染、慢性炎症、淋巴瘤 |
| 单核细胞增多 | 慢性感染、炎症、肿瘤 |
| 嗜酸性粒细胞增多 | 过敏、寄生虫、嗜酸性粒细胞白血病 |
| 全白细胞增多 | 严重感染、白血病 |

### 白细胞减少

| 类型 | 常见原因 |
|------|---------|
| 中性粒细胞减少 | 病毒感染、骨髓抑制、败血症 |
| 淋巴细胞减少 | 应激、病毒感染、免疫缺陷 |
| 全白细胞减少 | 猫瘟、骨髓抑制、化疗 |


## 白细胞形态判读

| 形态 | 临床意义 |
|------|---------|
| 中性粒细胞左移 | 感染、炎症 |
| 中性粒细胞右移 | 慢性感染、应激 |
| 中毒性变化 | 严重感染（中毒性颗粒、Dohle小体） |
| 退行性变化 | 败血症（细胞肿胀、核溶解） |
| 异型淋巴细胞 | 病毒感染、淋巴瘤 |
| 淋巴母细胞 | 淋巴瘤、白血病 |


## 血小板参数

### 血小板计数（PLT）

| 项目 | 犬参考 | 猫参考 |
|------|--------|--------|
| PLT | 200-500 ×10³/μL | 200-700 ×10³/μL |
| MPV | 7-12 fL | 7-12 fL |

### 血小板减少

| 分级 | PLT | 临床意义 |
|------|------|---------|
| 轻度 | 100-200 ×10³/μL | 需监测 |
| 中度 | 50-100 ×10³/μL | 需治疗 |
| 重度 | 小于50 ×10³/μL | 出血风险高 |
| 极重度 | 小于10 ×10³/μL | 需输血 |

### 血小板减少原因

| 原因 | 说明 |
|------|------|
| 免疫介导 | IMTP |
| 感染 | 埃立克体、巴贝斯虫 |
| DIC | 消耗性凝血 |
| 骨髓抑制 | 化疗、猫瘟 |
| 脾脏扣押 | 脾肿大 |
| 假性减少 | 血小板凝集 |


## 血常规判读流程

血常规
    |
    ▼
红细胞（RBC、HCT、Hb、MCV、MCHC、网织红细胞）
    |
    ▼
白细胞（WBC、分类、形态）
    |
    ▼
血小板（PLT、MPV）
    |
    ▼
综合判断
    ├── 贫血 -> 再生性、非再生性
    ├── 白细胞异常 -> 感染、炎症、白血病
    └── 血小板异常 -> 免疫介导、DIC、感染

## 客户沟通要点

### 解释血常规时
- 血常规可以评估贫血、感染和血液病。
- 血常规异常需要结合生化、影像学和临床症状综合判断。
- 有些指标需要动态监测，单次结果不能说明全部。

### 出院指导
- 按医嘱复查血常规，监测病情变化。
- 如果出现精神变差、发热、出血倾向或黄疸，立即复诊。
