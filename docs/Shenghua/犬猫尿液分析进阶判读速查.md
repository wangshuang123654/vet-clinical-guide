## 尿沉渣镜检

### 尿沉渣制备

| 步骤 | 操作 |
|------|------|
| 1 | 取新鲜尿液5-10 mL |
| 2 | 离心（1500-2000 rpm，5分钟） |
| 3 | 弃上清，留沉淀0.5 mL |
| 4 | 混匀，取一滴于载玻片 |
| 5 | 加盖玻片 |
| 6 | 显微镜检查（低倍+高倍） |


## 尿沉渣细胞判读

| 细胞 | 正常 | 异常 | 临床意义 |
|------|------|------|---------|
| 红细胞 | 0-5/HPF | 大于5/HPF | 出血、炎症、结石、肿瘤 |
| 白细胞 | 0-5/HPF | 大于5/HPF | 尿路感染、炎症 |
| 上皮细胞 | 少量 | 大量 | 尿路炎症、肿瘤 |
| 鳞状上皮细胞 | 少量 | 大量 | 尿道、阴道污染 |
| 移行上皮细胞 | 少量 | 大量 | 膀胱炎、肿瘤 |
| 肾小管上皮细胞 | 无 | 可见 | 肾小管损伤 |


## 尿沉渣管型判读

| 管型 | 形态 | 临床意义 |
|------|------|---------|
| 透明管型 | 透明、均质 | 正常或轻度肾损伤 |
| 颗粒管型 | 颗粒状 | 肾小管损伤 |
| 红细胞管型 | 含红细胞 | 肾小球肾炎 |
| 白细胞管型 | 含白细胞 | 肾盂肾炎 |
| 上皮细胞管型 | 含上皮细胞 | 肾小管坏死 |
| 蜡样管型 | 蜡状、折光 | 慢性肾病 |
| 脂肪管型 | 含脂肪滴 | 肾病综合征 |

> 管型需在低倍镜下观察，高倍镜确认。管型数量需结合临床判读。


## 尿沉渣结晶判读

| 结晶 | 形态 | 尿液pH | 临床意义 |
|------|------|--------|---------|
| 鸟粪石 | 棺材盖形 | 碱性 | 尿路感染、结石 |
| 草酸钙 | 信封形 | 酸性 | 肾结石、乙二醇中毒 |
| 尿酸铵 | 刺果形 | 酸性 | 肝病、门体分流 |
| 胱氨酸 | 六角形 | 酸性 | 遗传性胱氨酸尿 |
| 胆红素 | 针状 | 酸性 | 肝病 |
| 胆固醇 | 透明方形 | 酸性 | 肾病综合征 |
| 药物结晶 | 形态不一 | - | 药物代谢 |

### 结晶临床意义

| 结晶 | 意义 |
|------|------|
| 鸟粪石 | 常见，与感染相关 |
| 草酸钙 | 常见，与肾结石相关 |
| 尿酸铵 | 提示肝病 |
| 胱氨酸 | 遗传病 |
| 胆红素 | 提示肝病 |


## 尿沉渣微生物判读

| 微生物 | 形态 | 临床意义 |
|--------|------|---------|
| 细菌 | 杆状或球状 | 尿路感染 |
| 酵母菌 | 圆形或椭圆形 | 真菌感染 |
| 寄生虫 | 形态不一 | 尿路寄生虫 |
| 真菌菌丝 | 丝状 | 真菌感染 |
| 病毒包涵体 | 细胞内 | 病毒感染 |


## 尿沉渣其他成分

| 成分 | 形态 | 临床意义 |
|------|------|---------|
| 黏液 | 丝状 | 正常或炎症 |
| 脂肪滴 | 折光小滴 | 肾病综合征 |

## 尿沉渣判读流程

尿沉渣
    |
    ▼
低倍镜（10×）
    ├── 管型
    ├── 结晶
    └── 细胞分布
    |
    ▼
高倍镜（40×）
    ├── 细胞形态
    ├── 微生物
    └── 管型细节
    |
    ▼
综合判读
    ├── 细胞 -> 红细胞、白细胞、上皮细胞
    ├── 管型 -> 透明、颗粒、红细胞、白细胞
    ├── 结晶 -> 鸟粪石、草酸钙、尿酸铵
    └── 微生物 -> 细菌、真菌


## 尿沉渣判读注意事项

| 项目 | 说明 |
|------|------|
| 新鲜样本 | 采集后30分钟内检测 |
| 离心速度 | 1500-2000 rpm，5分钟 |
| 沉淀量 | 0.5 mL |
| 低倍镜 | 管型、结晶 |
| 高倍镜 | 细胞、微生物 |
| 结合临床 | 需结合试纸、血液检查 |
| 避免污染 | 避免粪便、阴道分泌物污染 |

## 客户沟通要点

### 解释尿沉渣时
- 尿沉渣检查可以评估尿路感染、结石和肾病。
- 尿沉渣异常需要结合试纸、血液检查和影像学综合判断。
- 如果发现结晶或感染，可能需要调整饮食或使用抗生素。

### 出院指导
- 按医嘱复查尿检，监测病情变化。
- 增加饮水，减少结石风险。
- 如果出现排尿困难、血尿或精神变差，立即复诊。
