## 甲状腺功能试验

### T4（总甲状腺素）

| 项目 | 犬 | 猫 |
|------|-----|-----|
| 参考范围 | 1.0-4.0 μg/dL | 1.0-4.0 μg/dL |
| 升高 | 甲亢（猫）、甲状腺素补充过量 | 甲亢 |
| 降低 | 甲减（犬）、非甲状腺疾病、药物 | 非甲状腺疾病、药物 |

| 升高 | 甲亢 | 甲亢 |
| 降低 | 甲减 | 非甲状腺疾病 |

### TSH（促甲状腺激素）

| 项目 | 犬 | 猫 |
|------|-----|-----|
| 参考范围 | 0.1-0.6 ng/mL | 0.1-0.6 ng/mL |
| 升高 | 甲减（原发性） | 甲减（罕见） |
| 降低 | 甲亢、垂体性甲减 | 甲亢 |

### 甲状腺功能判读

| T4 | fT4 | TSH | 判读 |
|-----|-----|-----|------|
| ↑ | ↑ | ↓ | 甲亢 |
| ↓ | ↓ | ↑ | 甲减（原发性） |
| ↓ | ↓ | ↓/正常 | 非甲状腺疾病、药物 |
| 正常 | 正常 | ↑ | 早期甲减 |

### 甲状腺功能试验选择

| 物种 | 首选 | 补充 |
|------|------|------|
| 犬（甲减） | T4 + TSH | fT4 |
| 猫（甲亢） | T4 | fT4 |
| 猫（T4正常但怀疑甲亢） | fT4、T4抑制试验 | 甲状腺闪烁扫描 |


## 肾上腺功能试验

### 皮质醇（基础）

| 项目 | 犬 | 猫 |
|------|-----|-----|
| 参考范围 | 1-5 μg/dL | 1-5 μg/dL |
| 升高 | 库欣、应激 | 库欣、应激 |
| 降低 | 阿迪森 | 阿迪森 |

### ACTH刺激试验

| 项目 | 说明 |
|------|------|
| 方法 | 注射ACTH后1小时测皮质醇 |
| 犬参考 | 刺激后5-20 μg/dL |
| 猫参考 | 刺激后5-20 μg/dL |
| 升高 | 库欣（肾上腺肿瘤） |
| 降低 | 阿迪森 |
| 临床意义 | 诊断库欣和阿迪森 |

### 低剂量地塞米松抑制试验（LDDST）

| 项目 | 说明 |
|------|------|
| 方法 | 注射地塞米松后2、4、8小时测皮质醇 |
| 正常 | 皮质醇被抑制（小于1.4 μg/dL） |
| 库欣 | 皮质醇不被抑制 |
| 临床意义 | 诊断库欣 |

### 高剂量地塞米松抑制试验（HDDST）

| 项目 | 说明 |
|------|------|
| 方法 | 注射高剂量地塞米松后测皮质醇 |
| 垂体性库欣 | 皮质醇被抑制 |
| 肾上腺性库欣 | 皮质醇不被抑制 |
| 临床意义 | 鉴别垂体性和肾上腺性库欣 |

### 肾上腺功能判读

| 试验 | 结果 | 判读 |
|------|------|------|
| ACTH刺激 | 皮质醇↑ | 库欣 |
| ACTH刺激 | 皮质醇↓ | 阿迪森 |
| LDDST | 不被抑制 | 库欣 |
| LDDST | 被抑制 | 正常 |
| HDDST | 被抑制 | 垂体性库欣 |
| HDDST | 不被抑制 | 肾上腺性库欣 |

## 内分泌功能试验判读流程

疑似内分泌疾病
    |
    ▼
甲状腺功能（T4、fT4、TSH）
    |
    ▼
肾上腺功能（皮质醇、ACTH刺激、LDDST、HDDST）
    |
    ▼
胰腺功能（血糖、果糖胺、胰岛素、fPL、cPL、TLI）
    |
    ▼
综合判断
    ├── 甲亢 -> T4↑
    ├── 甲减 -> T4↓、TSH↑
    ├── 库欣 -> ACTH刺激↑、LDDST不被抑制
    ├── 阿迪森 -> ACTH刺激↓
    ├── 糖尿病 -> 血糖↑、果糖胺↑
    ├── 胰岛素瘤 -> 胰岛素/血糖比值↑
    └── 胰腺炎 -> fPL/cPL↑

|------|------|---------|

| TSH | ↑ | 甲减 |

| fPL | ↑ | 胰腺炎（猫） |
| cPL | ↑ | 胰腺炎（犬） |
| TLI | ↓ | EPI |


## 客户沟通要点

### 解释内分泌试验时
- 内分泌试验需要多次采血，可能需要住院进行。
- 试验结果需要结合临床症状综合判断。
- 有些试验需要动态监测，单次结果不能说明全部。

### 出院指导
- 按医嘱复查内分泌指标，监测病情变化。
- 如果出现多饮多尿、体重下降、脱毛或精神变差，立即复诊。
