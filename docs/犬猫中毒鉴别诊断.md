# 犬猫中毒鉴别诊断 · 思维导图

> 执业兽医师急诊决策工具 | 快速识别毒物、判断是否催吐、启动解毒方案 | 更新日期：2026年9月9日


## 中毒急诊处理流程（5步法）

第一步：稳定生命体征（ABC）
- 气道通畅？呼吸正常？循环稳定？
- 惊厥或呼吸抑制 -> 先处理，再问诊

第二步：快速问诊（3个关键问题）
1. 吃了什么？（保留包装或残留物或拍照）
2. 吃了多少？（估算摄入量）
3. 什么时候吃的？（决定是否催吐）

第三步：决定是否催吐

可以催吐的情况：摄入后2小时内；动物清醒、无抽搐；摄入非腐蚀性毒物
禁止催吐的情况：摄入强酸或强碱；摄入石油类产品；动物已昏迷或抽搐；摄入尖锐异物

第四步：启动解毒方案
- 活性炭（1-2 g/kg 口服，多数毒物适用）
- 特效解毒药（见下表）
- 对症支持（输液、保肝、保肾）

第五步：监测与随访
- 肝肾功能、凝血功能、电解质
- 抗凝血灭鼠药需随访数周


## 常见中毒分类速查

### 食物中毒

| 毒物 | 犬 | 猫 | 临床特征 | 解毒或治疗 |
|------|----|----|---------|-----------|
| 巧克力 | 有毒 | 有毒 | 兴奋、心动过速、震颤 | 催吐加活性炭加控制心律 |
| 洋葱或大蒜 | 有毒 | 有毒 | 黏膜苍白或黄疸、血红蛋白尿 | 停用诱因加抗氧化加输血 |
| 葡萄或提子 | 有毒 | 有毒 | 呕吐、少尿或无尿、急性肾衰 | 催吐加活性炭加输液利尿 |
| 木糖醇 | 剧毒 | 慎用 | 虚弱、共济失调、低血糖 | 静脉补糖加保肝 |
| 酒精或生面团 | 有毒 | 有毒 | 醉酒状、呕吐、低体温 | 保温加输液加对症支持 |
| 澳洲坚果 | 有毒 | 有毒 | 后肢无力、共济失调、呕吐 | 对症支持（24-48小时恢复） |

### 药物中毒

| 毒物 | 犬 | 猫 | 临床特征 | 解毒或治疗 |
|------|----|----|---------|-----------|
| NSAIDs | 有毒 | 有毒 | 呕吐（带血）、黑便、肾衰 | 停用加催吐加硫糖铝加输液 |
| 对乙酰氨基酚 | 有毒 | 剧毒 | 猫：发绀；犬：肝损 | 猫用NAC；犬用NAC加保肝 |
| 抗抑郁药（SSRI） | 有毒 | 有毒 | 镇静或兴奋、呕吐、心动过速 | 催吐加活性炭加对症支持 |
| 苯二氮卓类（安定） | 有毒 | 有毒 | 共济失调、镇静嗜睡 | 对症支持加氟马西尼 |
| 降血压药 | 有毒 | 有毒 | 虚弱、晕厥、低血压 | 输液升压加监测血压 |

### 灭鼠药和杀虫剂中毒

| 毒物 | 犬 | 猫 | 临床特征 | 解毒或治疗 |
|------|----|----|---------|-----------|
| 抗凝血类灭鼠药 | 有毒 | 有毒 | 出血倾向、牙龈出血、血便 | 维生素K1（数周）加输血 |
| 维生素D3类灭鼠药 | 有毒 | 有毒 | 高钙血症、肾衰 | 大量输液加降钙素加激素 |
| 有机磷杀虫剂 | 有毒 | 有毒 | 流涎流泪、缩瞳、肌肉震颤 | 阿托品加解磷定 |
| 菊酯类（猫敏感） | 慎用 | 剧毒 | 肌肉震颤、流涎、抽搐 | 温水洗去残留加控制抽搐 |

### 植物中毒

| 毒物 | 犬 | 猫 | 临床特征 | 解毒或治疗 |
|------|----|----|---------|-----------|
| 百合花 | 慎用 | 剧毒 | 呕吐、嗜睡、急性肾衰 | 催吐加大量输液加活性炭 |
| 杜鹃花或夹竹桃 | 有毒 | 有毒 | 呕吐、心动过缓、心律不齐 | 催吐加活性炭加抗心律失常 |
| 苏铁（铁树种子） | 有毒 | 有毒 | 呕血、肝衰竭、神经症状 | 催吐加活性炭加保肝（预后差） |
| 大麻 | 有毒 | 有毒 | 共济失调、嗜睡、尿失禁 | 对症支持（24-72小时恢复） |

### 化学品中毒

| 毒物 | 犬 | 猫 | 临床特征 | 解毒或治疗 |
|------|----|----|---------|-----------|
| 防冻液（乙二醇） | 剧毒 | 剧毒 | 醉酒状、呕吐、少尿 | 4-甲基吡唑或乙醇加透析 |
| 洗涤剂或清洁剂 | 有毒 | 有毒 | 口鼻泡、吸入性肺炎 | 禁止催吐！补液加呼吸支持 |
| 重金属（铅或锌或铜） | 有毒 | 有毒 | 呕吐、贫血、肝损伤 | 驱螯合剂（EDTA或SAMe） |


## 中毒快速鉴别流程图

中毒疑似病例
    |
    第一步：问诊（什么？多少？何时？）
    |
    第二步：有无神经症状（震颤或抽搐或昏迷）？
    ├── 有 -> 菊酯类（猫）或有机磷或溴甲烷或大麻或酒精
    └── 无 -> 第三步
    |
    第三步：有无出血倾向？
    ├── 有 -> 抗凝血灭鼠药或洋葱或NSAIDs
    └── 无 -> 第四步
    |
    第四步：有无肾衰征象（少尿或无尿）？
    ├── 有 -> 百合花（猫）或葡萄或乙二醇或维生素D3
    └── 无 -> 第五步
    |
    第五步：有无肝损伤（黄疸或肝酶升高）？
    ├── 有 -> 苏铁或对乙酰氨基酚或木糖醇（犬）
    └── 无 -> 第六步
    |
    第六步：有无胃肠道症状（呕吐或腹泻）？
    ├── 有 -> 巧克力或澳洲坚果或植物中毒或化学毒物
    └── 无 -> 继续观察或实验室检查


## 特效解毒药速查

| 毒物 | 解毒药 | 剂量（犬或猫） | 说明 |
|------|--------|-------------|------|
| 抗凝血灭鼠药 | 维生素K1 | 2.5-5 mg/kg SC或IM | 连续用药3-4周 |
| 有机磷 | 阿托品 | 0.1-0.2 mg/kg IV或IM | 用于控制副交感症状 |
| 有机磷 | 解磷定 | 10-20 mg/kg IV | 早期使用，缓慢给药 |
| 乙二醇 | 4-甲基吡唑 | 20 mg/kg IV（首次） | 随后15 mg/kg |
| 乙二醇 | 乙醇 | 5-7 mL/kg IV（20%溶液） | 监测血酒精浓度 |
| 对乙酰氨基酚 | N-乙酰半胱氨酸 | 140 mg/kg PO或IV（首次） | 后续70 mg/kg 每6小时一次 |
| 苯二氮卓类 | 氟马西尼 | 0.01 mg/kg IV | 可重复给药 |
| 阿片类 | 纳洛酮 | 0.01-0.04 mg/kg IV | 可重复给药 |
| 重金属 | 依地酸钙钠 | 25-50 mg/kg IV 每日两次 | 连用3-5天 |


## 客户沟通要点

### 急诊问诊
- "麻烦您仔细回想一下，是什么时候、吃的是什么、吃了大概多少？"
- "有没有保留包装或残留物？拍照给我看会更准确。"
- "现在有什么症状？多久前开始的？"

### 解释方案
- "催吐不是万能的——如果是强酸强碱或汽油类，催吐反而会造成更大的伤害。"
- "活性炭可以吸附毒物，减少胃肠道吸收，越早用效果越好。"

### 告知预后
- "抗凝血灭鼠药中毒需要数周的维生素K1治疗和凝血监测。"
- "猫对百合花和菊酯类极度敏感——即使只舔了几口花粉或滴了一滴犬用驱虫药，也可能危及生命。"
