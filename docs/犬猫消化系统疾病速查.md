## 消化系统解剖与功能

| 器官 | 主要功能 | 常见疾病 |
|------|---------|---------|
| 口腔 | 咀嚼、吞咽 | 牙周病、口炎、异物 |
| 食道 | 输送食物 | 食道炎、巨食道、异物 |
| 胃 | 储存、消化 | 胃炎、溃疡、异物、GDV |
| 小肠 | 消化吸收 | 肠炎、IBD、异物、肿瘤 |
| 大肠 | 吸收水分、储存粪便 | 结肠炎、便秘、巨结肠 |
| 胰腺 | 消化酶、胰岛素 | 胰腺炎、糖尿病 |
| 肝脏 | 代谢、解毒 | 肝炎、肝硬化、胆管炎 |
| 胆囊 | 储存胆汁 | 胆囊炎、胆结石 |


## 食道疾病

### 食道炎

| 项目 | 内容 |
|------|------|
| 病因 | 胃酸反流、异物损伤、药物刺激 |
| 临床表现 | 吞咽困难、反流、流涎、食欲下降 |
| 诊断 | 食道镜、X光钡餐 |
| 治疗 | 抑酸（奥美拉唑）、黏膜保护剂（硫糖铝）、流质饮食 |
| 预后 | 良好，多数1-2周恢复 |

### 巨食道

| 项目 | 内容 |
|------|------|
| 病因 | 先天性（品种）、获得性（重症肌无力、食道炎） |
| 临床表现 | 反流、吞咽困难、体重下降、吸入性肺炎 |
| 诊断 | X光（食道扩张）、食道镜 |
| 治疗 | 直立喂食、流质饮食、促动力药 |
| 预后 | 先天性预后较好，获得性取决于原发病 |

### 食道异物

| 项目 | 内容 |
|------|------|
| 病因 | 误吞骨头、玩具、鱼钩 |
| 临床表现 | 吞咽困难、流涎、干呕、疼痛 |
| 诊断 | X光、食道镜 |
| 治疗 | 内镜取出、手术取出 |
| 预后 | 及时取出预后良好，延误可致食道穿孔 |


## 胃部疾病

### 急性胃炎

| 项目 | 内容 |
|------|------|
| 病因 | 饮食不当、药物、感染、毒素 |
| 临床表现 | 呕吐、食欲下降、腹痛 |
| 诊断 | 病史、体检、X光 |
| 治疗 | 禁食12-24小时、止吐、补液、胃黏膜保护剂 |
| 预后 | 良好，多数1-3天恢复 |

### 胃溃疡

| 项目 | 内容 |
|------|------|
| 病因 | NSAIDs、应激、肝肾疾病、肿瘤 |
| 临床表现 | 呕吐（带血）、黑便、腹痛、贫血 |
| 诊断 | 胃镜、X光 |
| 治疗 | 抑酸（奥美拉唑）、黏膜保护剂（硫糖铝）、停用NSAIDs |
| 预后 | 良好，但需治疗原发病 |

### 胃扩张扭转（GDV）

| 项目 | 内容 |
|------|------|
| 病因 | 大型深胸犬、进食过快、运动后进食 |
| 临床表现 | 干呕、腹胀、呼吸困难、休克 |
| 诊断 | X光（胃扩张、脾脏移位） |
| 治疗 | 紧急胃减压、手术固定 |
| 预后 | 及时手术预后较好，延误死亡率高 |

### 胃异物

| 项目 | 内容 |
|------|------|
| 病因 | 误吞玩具、骨头、衣物 |
| 临床表现 | 呕吐、食欲下降、腹痛 |
| 诊断 | X光、B超、内镜 |
| 治疗 | 内镜取出、手术取出 |
| 预后 | 及时取出预后良好 |


## 肠道疾病

### 急性肠炎

| 项目 | 内容 |
|------|------|
| 病因 | 饮食不当、感染、寄生虫 |
| 临床表现 | 腹泻、呕吐、腹痛 |
| 诊断 | 粪检、血常规 |
| 治疗 | 补液、止泻、益生菌、驱虫 |
| 预后 | 良好，多数1-3天恢复 |

### 炎性肠病（IBD）

| 项目 | 内容 |
|------|------|
| 病因 | 免疫介导、肠道菌群失调 |
| 临床表现 | 慢性呕吐、腹泻、体重下降 |
| 诊断 | B超（肠壁增厚）、活检 |
| 治疗 | 饮食管理（低敏或水解蛋白）、免疫抑制剂（泼尼松龙） |
| 预后 | 需要长期管理，多数可控制 |

### 肠梗阻

| 项目 | 内容 |
|------|------|
| 病因 | 异物、肿瘤、肠套叠、粘连 |
| 临床表现 | 呕吐、腹痛、腹胀、无排便 |
| 诊断 | X光、B超 |
| 治疗 | 手术解除梗阻 |
| 预后 | 及时手术预后较好，延误可致肠坏死 |

### 结肠炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染、寄生虫、食物过敏、IBD |
| 临床表现 | 腹泻（带黏液或血）、里急后重 |
| 诊断 | 粪检、结肠镜 |
| 治疗 | 饮食管理、抗生素、免疫抑制剂 |
| 预后 | 多数可控制 |

### 便秘

| 项目 | 内容 |
|------|------|
| 病因 | 饮水不足、纤维不足、疼痛、神经性疾病 |
| 临床表现 | 排便困难、排出干硬粪便 |
| 诊断 | X光、体检 |
| 治疗 | 增加饮水、增加纤维、灌肠、泻药 |
| 预后 | 多数可改善，严重者可致巨结肠 |


## 胰腺疾病

### 胰腺炎

| 项目 | 内容 |
|------|------|
| 病因 | 高脂饮食、肥胖、药物、感染 |
| 临床表现 | 呕吐、腹痛（弓背）、食欲下降、发热 |
| 诊断 | fPL（猫胰腺脂肪酶）、cPL（犬胰腺特异性脂肪酶）、B超 |
| 治疗 | 补液、止痛、止吐、低脂饮食 |
| 预后 | 轻度预后良好，重度死亡率较高 |

### 胰腺外分泌功能不全（EPI）

| 项目 | 内容 |
|------|------|
| 病因 | 胰腺腺泡萎缩 |
| 临床表现 | 慢性腹泻、体重下降、多食 |
| 诊断 | TLI（胰蛋白酶样免疫反应性） |
| 治疗 | 胰酶补充、饮食管理 |
| 预后 | 需要终身管理 |


## 肝脏疾病

### 肝炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染、中毒、免疫介导 |
| 临床表现 | 黄疸、呕吐、食欲下降、腹水 |
| 诊断 | 生化（ALT或AST升高）、B超、活检 |
| 治疗 | 保肝（SAMe、水飞蓟）、支持治疗 |
| 预后 | 急性肝炎预后较好，慢性肝炎需长期管理 |

### 胆管肝炎（猫）

| 项目 | 内容 |
|------|------|
| 病因 | 细菌感染、免疫介导、寄生虫 |
| 临床表现 | 黄疸、发热、食欲下降、呕吐 |
| 诊断 | 生化、B超、胆汁培养 |
| 治疗 | 抗生素、保肝、支持治疗 |
| 预后 | 及时治疗预后较好 |

### 肝硬化

| 项目 | 内容 |
|------|------|
| 病因 | 慢性肝炎、胆管肝炎晚期 |
| 临床表现 | 腹水、黄疸、肝性脑病、消瘦 |
| 诊断 | B超、生化、活检 |
| 治疗 | 保肝、利尿、低蛋白饮食、乳果糖 |
| 预后 | 不可逆，需长期管理 |

### 肝性脑病

| 项目 | 内容 |
|------|------|
| 病因 | 肝功能衰竭、门体分流 |
| 临床表现 | 神经症状（抽搐、昏迷）、流涎、行为异常 |
| 诊断 | 血氨升高、胆汁酸升高 |
| 治疗 | 乳果糖、低蛋白饮食、抗生素 |
| 预后 | 取决于原发病 |


## 消化系统疾病诊疗流程

呕吐或腹泻
    |
    ▼
病史和体检
    |
    ▼
基础检查（血常规、生化、粪检）
    |
    ▼
影像学检查（X光、B超）
    |
    ▼
根据结果分诊
    ├── 异物 -> 内镜或手术
    ├── 胰腺炎 -> 补液、止痛、低脂饮食
    ├── IBD -> 饮食管理、免疫抑制
    ├── 肝病 -> 保肝、支持治疗
    └── 感染 -> 抗生素、驱虫


## 客户沟通要点

### 解释消化系统疾病时
- 消化系统疾病很多与饮食有关，调整饮食是治疗的重要部分。
- 慢性消化系统疾病需要长期管理，不能指望一次治愈。
- 如果出现持续呕吐、腹泻或体重下降，需要进一步检查。

### 出院指导
- 按医嘱用药，不要随意停药。
- 饮食管理是关键，避免喂食油腻、不易消化的食物。
- 定期复查，监测病情变化。
- 如果出现症状加重，及时复诊。
