## 犬常见传染病

### 犬细小病毒（CPV）

| 项目 | 内容 |
|------|------|
| 病原 | 犬细小病毒（CPV-2） |
| 易感动物 | 未接种疫苗的幼犬（6周-6月龄高发） |
| 传播途径 | 粪-口传播，环境抵抗力强 |
| 潜伏期 | 3-7天 |
| 临床症状 | 呕吐、血便（番茄酱样）、食欲废绝、精神沉郁、脱水 |
| 诊断 | CPV抗原检测（粪便）、血常规（白细胞减少） |
| 治疗 | 输液支持、止吐、抗生素（防继发感染）、干扰素、单克隆抗体 |
| 预防 | 疫苗接种（核心疫苗）、环境消毒（含氯消毒剂） |
| 预后 | 及时治疗存活率70-90%，延误治疗死亡率高 |
| 隔离要求 | 严格隔离，专用器具，人员防护 |

### 犬传染性肝炎（CAV）

| 项目 | 内容 |
|------|------|
| 病原 | 犬腺病毒1型（CAV-1） |
| 易感动物 | 未接种疫苗的犬 |
| 传播途径 | 粪-口传播、尿液传播 |
| 潜伏期 | 4-7天 |
| 临床症状 | 发热、呕吐、腹泻、肝区疼痛、角膜浑浊（蓝眼）、凝血障碍 |
| 诊断 | PCR、抗体检测、生化（ALT/AST升高） |
| 治疗 | 支持治疗、保肝、输液、输血（严重时） |
| 预防 | 疫苗接种（核心疫苗） |
| 预后 | 及时治疗预后较好，严重病例死亡率高 |
| 隔离要求 | 隔离，尿液污染环境需消毒 |

## 传染病隔离与防控

### 隔离原则

| 项目 | 要求 |
|------|------|
| 隔离区域 | 独立病房，通风良好 |
| 专用器具 | 专用听诊器、体温计、输液泵 |
| 人员防护 | 手套、隔离衣、鞋套 |
| 进出管理 | 进出消毒，避免交叉感染 |
| 废弃物处理 | 专用容器，医疗废物处理 |

### 环境消毒

| 病原 | 推荐消毒剂 | 注意事项 |
|------|-----------|---------|
| 犬细小病毒 | 含氯消毒剂（1:32稀释漂白水） | 环境抵抗力强，需彻底消毒 |
| 猫瘟 | 含氯消毒剂（1:32稀释漂白水） | 环境抵抗力强，需彻底消毒 |
| 犬瘟热 | 含氯消毒剂、过氧乙酸 | 飞沫传播，需空气消毒 |
| 猫疱疹病毒 | 含氯消毒剂、过氧乙酸 | 环境抵抗力较弱 |
| 猫杯状病毒 | 含氯消毒剂 | 环境抵抗力较强 |
| 钩端螺旋体 | 含氯消毒剂 | 尿液污染环境需彻底消毒 |

### 疫苗接种建议

| 疫苗 | 犬 | 猫 |
|------|-------|-------|
| 核心疫苗 | 犬瘟热、细小病毒、传染性肝炎、狂犬病 | 猫瘟、疱疹病毒、杯状病毒、狂犬病 |
| 非核心疫苗 | 副流感、博德特氏菌、钩端螺旋体、冠状病毒 | 白血病、衣原体、FIV |


## 客户沟通要点

### 解释传染病时
- 传染病需要及时隔离和治疗，否则可能危及生命。
- 疫苗接种是预防传染病最有效的方法。
- 幼犬幼猫需要按时完成疫苗程序，才能获得足够保护。

### 告知隔离要求时
- 患病动物需要单独隔离，避免传染给其他动物。
- 接触患病动物后需洗手消毒。
- 患病动物的排泄物需戴手套处理。

### 出院指导
- 按医嘱完成治疗，不要提前停药。
- 定期复查，确保完全康复。
- 环境彻底消毒，避免再次感染。
- 按时接种疫苗，做好预防。
