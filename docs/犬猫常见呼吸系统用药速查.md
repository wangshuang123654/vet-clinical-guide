| 步骤 | 操作 |

| 2 | 动物保持安静，避免应激 |
| 3 | 吸入时间5-10分钟 |
| 4 | 吸入后清洁面部 |
| 5 | 记录吸入药物和剂量 |


## 客户沟通要点

### 解释用药时
- 呼吸系统用药需要按时给药，不要随意停药。
- 吸入治疗需要耐心，让动物适应面罩。
- 糖皮质激素需要逐渐减量，不要突然停药。

### 出院指导
- 按医嘱用药，不要随意停药或调整剂量。
- 避免环境刺激（烟雾、粉尘、香水）。
- 定期复查，监测病情变化。
- 如果出现呼吸急促、发绀或精神变差，立即复诊。
