# 院内感染控制（隔离消毒）速查

> 执业兽医师临床决策工具 | 传染病隔离、消毒剂选择、院感防控 | 更新日期：2026年9月15日


## 院感防控核心原则

| 原则 | 说明 |
|------|------|
| 隔离 | 传染病动物立即隔离 |
| 消毒 | 环境、器械、人员规范消毒 |
| 防护 | 人员穿戴防护装备 |
| 分区 | 清洁区、污染区、半污染区分明 |
| 单向流动 | 从清洁区到污染区，不逆行 |
| 记录 | 隔离和消毒记录完整 |


## 传染病隔离

### 隔离分级

| 分级 | 疾病类型 | 隔离要求 |
|------|---------|---------|
| 严格隔离 | 犬细小、猫瘟、狂犬病 | 独立病房、专用器具、全套防护 |
| 接触隔离 | 皮肤癣菌、耳螨、跳蚤 | 独立病房、手套、隔离衣 |
| 飞沫隔离 | 犬窝咳、猫疱疹 | 独立病房、口罩、手套 |
| 保护性隔离 | 免疫抑制动物 | 独立病房、反向隔离 |

### 隔离操作规范

| 项目 | 要求 |
|------|------|
| 病房 | 独立、通风、易消毒 |
| 器具 | 专用听诊器、体温计、输液泵 |
| 人员 | 专用人员或最后处理 |
| 防护 | 手套、隔离衣、鞋套、口罩 |
| 进出 | 进出消毒，避免交叉 |
| 废弃物 | 专用容器，医疗废物处理 |
| 记录 | 隔离记录、消毒记录 |


## 消毒剂选择

### 常用消毒剂

| 消毒剂 | 有效浓度 | 适用 | 注意事项 |
|--------|---------|------|---------|
| 含氯消毒剂（漂白水） | 1:32稀释（约1500ppm） | 细小、猫瘟、环境 | 现配现用，腐蚀金属 |
| 过氧乙酸 | 0.2%-0.5% | 广谱、环境 | 腐蚀性强，通风 |
| 氯己定 | 2%-4% | 皮肤、器械 | 对真菌有效 |
| 碘伏 | 0.5%-1% | 皮肤、黏膜 | 避免与含氯合用 |
| 戊二醛 | 2% | 器械 | 刺激性大，需冲洗 |
| 季铵盐 | 按产品说明 | 环境、器械 | 对细小无效 |
| 酒精 | 70%-75% | 皮肤、器械 | 对孢子无效 |

### 消毒剂选择速查

| 病原 | 推荐消毒剂 | 注意事项 |
|------|-----------|---------|
| 犬细小病毒 | 含氯消毒剂（1:32） | 环境抵抗力强，需彻底消毒 |
| 猫瘟 | 含氯消毒剂（1:32） | 环境抵抗力强，需彻底消毒 |
| 犬瘟热 | 含氯消毒剂、过氧乙酸 | 飞沫传播，需空气消毒 |
| 猫疱疹病毒 | 含氯消毒剂、过氧乙酸 | 环境抵抗力较弱 |
| 猫杯状病毒 | 含氯消毒剂 | 环境抵抗力较强 |
| 钩端螺旋体 | 含氯消毒剂 | 尿液污染环境需彻底消毒 |
| 皮肤癣菌 | 含氯消毒剂、氯己定 | 环境抵抗力强 |
| 耳螨 | 含氯消毒剂 | 环境消毒 |
| 跳蚤 | 含氯消毒剂、杀虫剂 | 环境灭蚤 |


## 环境消毒

### 日常消毒

| 区域 | 频率 | 消毒剂 |
|------|------|--------|
| 诊室 | 每天 | 含氯消毒剂 |
| 病房 | 每天 | 含氯消毒剂 |
| 手术室 | 每台手术后 | 含氯消毒剂、过氧乙酸 |
| 候诊区 | 每天 | 含氯消毒剂 |
| 隔离病房 | 每天 | 含氯消毒剂 |
| 器械 | 每次使用后 | 高压灭菌、戊二醛 |

### 终末消毒

| 步骤 | 操作 |
|------|------|
| 1 | 清除所有物品 |
| 2 | 清洗地面、墙面、台面 |
| 3 | 含氯消毒剂喷洒 |
| 4 | 作用30分钟 |
| 5 | 清水冲洗 |
| 6 | 干燥 |
| 7 | 紫外线照射（可选） |

## 客户沟通要点

### 解释隔离时
- 传染病动物需要隔离，避免传染给其他动物。
- 隔离期间不能探视，但我们会每天更新情况。
- 隔离动物的排泄物需要特殊处理。

### 出院指导
- 环境彻底消毒，避免再次感染。
- 接触患病动物后洗手消毒。
- 按时接种疫苗，预防传染病。
