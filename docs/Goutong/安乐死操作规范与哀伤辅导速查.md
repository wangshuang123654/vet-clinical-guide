## 安乐死适应症

| 适应症 | 说明 |
|--------|------|
| 不可治愈的疾病 | 晚期肿瘤、器官衰竭 |
| 无法控制的疼痛 | 药物无法缓解 |
| 生活质量严重下降 | 无法进食、饮水、活动 |
| 严重创伤 | 预后极差 |
| 传染病晚期 | 无法治愈且痛苦 |
| 主人无法承担治疗 | 需充分沟通 |


## 安乐死前沟通

### 确认决定

| 项目 | 说明 |
|------|------|
| 确认主人意愿 | 明确表达安乐死意愿 |
| 确认动物状态 | 评估生活质量 |
| 排除可逆因素 | 确认无治疗可能 |
| 留出考虑时间 | 不催促，给主人时间 |
| 签署知情同意书 | 书面记录 |

### 生活质量评估（HHHHHMM）

| 项目 | 评估内容 |
|------|---------|
| H（Hurt）疼痛 | 是否疼痛，能否控制 |
| H（Hunger）食欲 | 是否进食，是否体重下降 |
| H（Hydration）饮水 | 是否饮水，是否脱水 |
| H（Hygiene）卫生 | 是否清洁，是否失禁 |
| H（Happiness）快乐 | 是否享受生活，是否互动 |
| H（Mobility）活动 | 是否能站立、行走 |
| M（More good days than bad）好日子多于坏日子 | 综合评估 |


## 安乐死操作流程

### 操作前准备

| 物品 | 说明 |
|------|------|
| 留置针 | 24G-22G |
| 麻醉药 | 丙泊酚 |
| 安乐死药物 | 戊巴比妥钠 |
| 注射器 | 5-10 mL |
| 听诊器 | 确认心跳停止 |
| 纸巾 | 主人使用 |
| 毯子 | 覆盖动物 |

### 操作步骤

| 步骤 | 操作 |
|------|------|
| 1 | 确认主人签署知情同意书 |
| 2 | 安置动物在舒适位置 |
| 3 | 建立静脉通路（留置针） |
| 4 | 主人与动物告别 |
| 5 | 注射麻醉药（丙泊酚）使动物深度麻醉 |
| 6 | 确认麻醉深度（角膜反射消失） |
| 7 | 注射安乐死药物（戊巴比妥钠） |
| 8 | 听诊确认心跳停止 |
| 9 | 确认呼吸停止、瞳孔散大 |
| 10 | 告知主人动物已离开 |

### 药物选择

| 药物 | 剂量 | 说明 |
|------|------|------|
| 丙泊酚 | 4-6 mg/kg IV | 先麻醉 |
| 戊巴比妥钠 | 80-100 mg/kg IV | 安乐死药物 |
| 氯化钾 | 1-2 mEq/kg IV | 心脏停搏（麻醉后使用） |

> 注意：必须先麻醉，再注射安乐死药物。单独使用戊巴比妥钠可能引起动物兴奋。


## 操作注意事项

| 项目 | 说明 |
|------|------|
| 静脉通路 | 确保留置针通畅 |
| 麻醉深度 | 确认动物完全麻醉后再注射安乐死药物 |
| 速度 | 缓慢注射，观察反应 |
| 确认死亡 | 听诊心跳停止、呼吸停止、瞳孔散大 |
| 尊重 | 操作过程保持安静、尊重 |
| 隐私 | 提供私密空间 |
| 主人陪伴 | 允许主人陪伴 |
| 遗体处理 | 尊重主人选择（带走或火化） |


## 哀伤辅导

### 主人常见情绪

| 情绪 | 表现 | 回应 |
|------|------|------|
| 悲伤 | 哭泣、沉默 | 递纸巾、安静陪伴 |
| 自责 | “我是不是做错了” | “这不是您的错” |
| 愤怒 | 对医生或自己发火 | 认可情绪、不辩解 |
| 否认 | “不可能” | 耐心、不争论 |
| 解脱 | “它终于不痛苦了” | 认可、不评判 |
| 矛盾 | 犹豫不决 | 给时间、不催促 |

### 哀伤辅导话术

| 场景 | 话术 |
|------|------|
| 主人哭泣 | “我知道这很难，您可以慢慢来。” |
| 主人自责 | “您已经为它做了最好的选择，这不是您的错。” |
| 主人问“它会怪我吗” | “它不会怪您，它知道您爱它。” |

| 主人离开 | “您有什么需要随时联系我们。” |

## 客户沟通要点

### 解释安乐死时
- 安乐死是让动物在无痛苦中离开的方式。
- 操作前会先麻醉，动物不会感到痛苦。
- 您可以陪伴它到最后，也可以选择不陪伴。

### 操作过程中
- 保持安静、尊重。
- 允许主人和动物告别。
- 操作后给主人留出时间。

### 操作后
- 确认死亡后告知主人。
- 尊重主人对遗体的选择。
- 提供哀伤支持资源。
- 1-2周后回访。
