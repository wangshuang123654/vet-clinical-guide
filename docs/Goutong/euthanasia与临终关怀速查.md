> 执业兽医师临床决策工具 | 生活质量评估、姑息治疗、临终关怀 | 更新日期：2026年9月15日


## 临终关怀核心理念

| 理念 | 说明 |
|------|------|
| 舒适优先 | 以减轻痛苦为首要目标 |
| 尊重生命 | 尊重动物和主人的选择 |
| 陪伴支持 | 陪伴动物和主人走过最后阶段 |
| 不放弃 | 即使不能治愈，也不放弃关怀 |
| 不拖延 | 不让动物承受不必要的痛苦 |


## 生活质量评估（HHHHHMM量表）

| 项目 | 评估内容 | 评分（0-10） |
|------|---------|-------------|
| H（Hurt）疼痛 | 是否疼痛，能否控制 | |
| H（Hunger）食欲 | 是否进食，是否体重下降 | |
| H（Hydration）饮水 | 是否饮水，是否脱水 | |
| H（Hygiene）卫生 | 是否清洁，是否失禁 | |
| H（Happiness）快乐 | 是否享受生活，是否互动 | |
| H（Mobility）活动 | 是否能站立、行走 | |
| M（More good days than bad）好日子多于坏日子 | 综合评估 | |
| **总分** | | |

### 评分解读

| 总分 | 建议 |
|------|------|
| 大于50 | 生活质量良好，继续治疗 |
| 30-50 | 生活质量下降，考虑调整方案 |
| 小于30 | 生活质量差，考虑安乐死 |

## 安乐死决策

### 决策要点

| 项目 | 说明 |
|------|------|
| 生活质量 | HHHHHMM评分小于30 |
| 疼痛控制 | 药物无法控制 |
| 预后 | 不可治愈，预后极差 |
| 主人意愿 | 主人明确决定 |
| 医生评估 | 医生认为安乐死是合理选择 |

### 安乐死时机

| 时机 | 说明 |
|------|------|
| 不要过早 | 生活质量尚可时，不急于安乐死 |
| 不要过晚 | 不要让动物承受不必要的痛苦 |
| 综合评估 | 结合评分、主人意愿、医生判断 |

## 客户沟通要点

### 解释临终关怀时
- 临终关怀的目标是让动物舒适，而不是治愈。
- 我们会用药物控制疼痛和其他症状。
- 您可以陪伴它，给它最后的温暖。

### 解释安乐死时
- 安乐死是让动物在无痛苦中离开的方式。
- 操作前会先麻醉，动物不会感到痛苦。
- 您可以陪伴它到最后，也可以选择不陪伴。

### 出院指导
- 按医嘱用药，控制疼痛和症状。
- 保持环境舒适、安静。
- 如果出现痛苦加重，及时联系我们。
- 提供哀伤支持资源。
