# 医疗纠纷预防与沟通技巧速查

> 执业兽医师临床决策工具 | 风险告知、知情同意、纠纷处理 | 更新日期：2026年9月15日


## 医疗纠纷常见原因

| 原因 | 说明 | 预防措施 |
|------|------|---------|
| 沟通不足 | 未充分告知病情、风险、费用 | 规范沟通流程 |
| 期望过高 | 主人期望治愈，但实际预后差 | 提前告知预后 |
| 费用争议 | 费用超出预期 | 书面报价、签字确认 |
| 治疗效果不佳 | 治疗无效或出现并发症 | 告知风险、签知情同意 |
| 态度问题 | 医护人员态度冷淡 | 培训沟通技巧 |
| 记录不全 | 病历记录不完整 | 规范病历书写 |
| 操作失误 | 操作不当导致损伤 | 规范操作、培训 |
| 动物死亡 | 治疗中或术后死亡 | 提前告知风险、签同意书 |


## 风险告知规范

### 告知内容

| 项目 | 说明 |
|------|------|
| 诊断 | 明确诊断或疑似诊断 |
| 治疗方案 | 推荐方案、替代方案 |
| 预期效果 | 可能达到的效果 |
| 风险 | 可能出现的并发症、副作用 |
| 预后 | 可能的结局 |
| 费用 | 预估费用 |
| 不治疗的后果 | 如果不治疗会怎样 |

### 告知方式

| 方式 | 说明 |
|------|------|
| 口头告知 | 日常沟通 |
| 书面告知 | 重要治疗、手术、麻醉 |
| 知情同意书 | 手术、麻醉、输血、化疗 |
| 费用确认单 | 高费用治疗 |
| 录音录像 | 征得同意后 |


## 知情同意书要点

| 项目 | 内容 |
|------|------|
| 动物信息 | 姓名、品种、年龄、体重 |
| 主人信息 | 姓名、联系方式 |
| 诊断 | 明确或疑似诊断 |
| 治疗方案 | 推荐方案、替代方案 |
| 风险 | 并发症、副作用、死亡风险 |
| 预后 | 可能结局 |
| 费用 | 预估费用 |
| 主人声明 | 已了解风险，同意治疗 |
| 签字 | 主人签字、医生签字 |
| 日期 | 签署日期 |


## 沟通技巧

### 沟通原则

| 原则 | 说明 |
|------|------|
| 诚实 | 不隐瞒、不夸大 |
| 清晰 | 用通俗语言 |
| 同理 | 理解主人情绪 |
| 有准备 | 提前想好怎么说 |
| 有记录 | 记录沟通内容 |
| 有方案 | 不只说问题，还给选择 |

### 沟通话术

| 场景 | 话术 |
|------|------|
| 告知风险 | “这个手术有X%的风险，包括……” |
| 告知费用 | “整个治疗预计需要X元，这是详细清单。” |
| 告知预后 | “目前的情况是……预后可能是……” |
| 告知并发症 | “可能出现X并发症，我们会密切监测。” |
| 告知死亡风险 | “这个病有死亡风险，我们会尽全力。” |
| 主人情绪激动 | “我理解您的心情，我们一起想办法。” |
| 主人要求“不惜一切代价” | “我们会尽全力，但也需要您了解实际情况。” |


## 病历记录规范

| 项目 | 要求 |
|------|------|
| 时间 | 记录就诊时间 |
| 主诉 | 主人描述的症状 |
| 体检 | 详细体检记录 |
| 诊断 | 明确或疑似诊断 |
| 治疗 | 治疗方案、药物、剂量 |
| 沟通 | 沟通内容、主人决定 |
| 知情同意 | 是否签署 |
| 费用 | 费用记录 |
| 签字 | 医生签字 |


## 纠纷处理流程

| 步骤 | 操作 |
|------|------|
| 1 | 保持冷静，不辩解 |
| 2 | 倾听主人诉求 |
| 3 | 表达同理心 |
| 4 | 查看病历和记录 |
| 5 | 解释实际情况 |
| 6 | 提出解决方案 |
| 7 | 记录处理过程 |
| 8 | 必要时上报 |


## 纠纷预防措施

| 措施 | 说明 |
|------|------|
| 规范沟通 | 重要治疗前充分告知 |
| 书面记录 | 病历、知情同意书、费用单 |
| 规范操作 | 按标准流程操作 |
| 培训 | 沟通技巧、操作规范 |
| 监控 | 重要区域监控 |
| 保险 | 医疗责任保险 |
| 法律顾问 | 必要时咨询 |


## 客户沟通要点

### 预防纠纷
- 提前告知风险、预后、费用。
- 签署知情同意书。
- 规范病历记录。
- 保持良好沟通态度。

### 处理纠纷
- 保持冷静，不辩解。
- 倾听主人诉求。
- 查看记录，解释实际情况。
- 提出合理解决方案。
- 记录处理过程。
