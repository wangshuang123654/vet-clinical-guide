# 急诊沟通与心肺复苏告知速查

> 执业兽医师临床决策工具 | 紧急决策、抢救告知、情绪支持 | 更新日期：2026年9月15日


## 急诊沟通核心原则

| 原则 | 说明 |
|------|------|
| 快速 | 急诊沟通要快，不拖延 |
| 清晰 | 用最简单的话说清病情 |
| 直接 | 不绕弯子，直接说重点 |
| 分秒必争 | 抢救优先，沟通同步 |
| 记录 | 沟通内容记录在病历 |
| 同理 | 理解主人焦急情绪 |


## 急诊分诊沟通

### 分诊分级沟通

| 分级 | 沟通话术 |
|------|---------|
| 红区（危重） | “情况非常危急，我们需要立即抢救，请您在外面等候。” |
| 黄区（不稳定） | “情况比较严重，需要优先处理，请稍等。” |
| 绿区（稳定） | “目前情况稳定，请稍等，我们会尽快安排。” |

### 分诊沟通要点

| 项目 | 说明 |
|------|------|
| 快速评估 | 先评估再沟通 |
| 告知分级 | 让主人知道紧急程度 |
| 安抚情绪 | 理解主人焦虑 |
| 告知流程 | 说明接下来会发生什么 |
| 留下联系方式 | 确保能联系到主人 |


## 紧急决策沟通

### 需要立即手术

| 话术 |
|------|
| “它的情况非常危急，需要立即手术，否则可能有生命危险。” |
| “手术有风险，但不手术风险更大，需要您尽快决定。” |
| “请您签署手术同意书，我们马上准备。” |

### 需要紧急输血

| 话术 |
|------|
| “它严重贫血，需要立即输血。” |
| “输血有风险，包括过敏反应和传染病传播，但我们会严格筛查。” |
| “需要您签署输血同意书。” |

### 需要安乐死决策

| 话术 |
|------|
| “目前它的痛苦已经很难控制，继续治疗可能只是延长痛苦。” |
| “您可以考虑安乐死，让它无痛苦地离开。” |
| “这个决定很艰难，无论您怎么选择，我们都支持您。” |

### 需要放弃抢救

| 话术 |
|------|
| “我们已经抢救了X分钟，但没有恢复自主心跳。” |
| “继续抢救可能意义不大，您可以选择停止。” |
| “我们尊重您的决定。” |


## 心肺复苏（CPR）告知

### CPR启动时

| 话术 |
|------|
| “它的心脏已经停止跳动，我们马上进行心肺复苏。” |
| “请您在外面等候，我们会随时更新情况。” |
| “这是抢救同意书，请签字。” |

### CPR进行中

| 时间 | 沟通话术 |
|------|---------|
| 5分钟 | “正在持续心肺复苏，目前心律是……” |
| 10分钟 | “已经抢救10分钟，仍在努力。” |
| 15分钟 | “目前情况不乐观，但我们会继续。” |
| 20分钟 | “已经抢救20分钟，如果仍无反应，可能需要考虑停止。” |
| 30分钟 | “已经抢救30分钟，没有恢复自主心跳，建议停止。” |

### CPR终止时

| 话术 |
|------|
| “我们尽了全力，但它的心脏没有恢复跳动。” |
| “它在X点X分离开了我们。” |
| “您可以进去和它告别。” |
| “后续的事情我们可以帮您安排。” |

### CPR成功后

| 话术 |
|------|
| “心脏已经恢复跳动，但接下来24-48小时是关键期。” |
| “需要密切监护，防止再次停搏。” |
| “我们会尽全力，但需要您做好心理准备。” |


## 急诊费用沟通

| 场景 | 话术 |
|------|------|
| 预估费用 | “抢救费用大约X元，包括……” |
| 费用较高 | “急诊费用比较高，需要您了解。” |
| 需要预付 | “需要先预付X元，后续多退少补。” |
| 主人费用敏感 | “我们可以选择基础抢救方案，但效果可能有限。” |


## 急诊情绪支持

| 主人情绪 | 回应 |
|---------|------|
| 哭泣 | 递纸巾，安静陪伴 |
| 愤怒 | 认可情绪，不辩解 |
| 否认 | 耐心重复，不争论 |
| 自责 | “这不是您的错” |
| 要求“不惜一切代价” | “我们会尽全力，但也需要您了解实际情况” |
| 反复提问 | 耐心重复，不表现不耐烦 |
| 要求立即安乐死 | 确认决定，留出考虑时间 |

## 客户沟通要点

### 急诊沟通时
- 快速、清晰、直接。
- 先稳定生命体征，再详细沟通。
- 重要决策需书面签字。
- 记录沟通内容。

### 抢救时
- 抢救优先，沟通同步。
- 每5-10分钟更新一次。
- 终止抢救需明确告知。
- 提供情绪支持。

### 抢救后
- 成功：告知后续风险。
- 失败：告知死亡时间，允许告别。
- 提供哀伤支持。
