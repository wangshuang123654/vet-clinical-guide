# 住院动物探视与沟通规范速查

> 执业兽医师临床决策工具 | 探视制度、每日沟通、住院管理 | 更新日期：2026年9月15日


## 住院沟通核心原则

| 原则 | 说明 |
|------|------|
| 每日沟通 | 每天主动联系主人，更新病情 |
| 透明 | 如实告知病情变化和治疗进展 |
| 及时 | 病情变化时立即通知主人 |
| 尊重 | 尊重主人知情权和决定权 |
| 记录 | 沟通内容记录在病历中 |
| 同理 | 理解主人焦虑和担忧 |


## 住院每日沟通流程

### 沟通时间

| 时间 | 内容 |
|------|------|
| 早上（8:00-10:00） | 更新夜间情况、当日计划 |
| 下午（14:00-16:00） | 更新当日进展、检查结果 |
| 晚上（18:00-20:00） | 更新当日总结、夜间安排 |
| 病情变化时 | 立即通知主人 |

### 沟通内容

| 项目 | 说明 |
|------|------|
| 精神状态 | 比昨天好还是差 |
| 食欲 | 吃了多少，是否主动进食 |
| 饮水 | 喝了多少 |
| 排泄 | 排尿排便情况 |
| 体温 | 是否发热 |
| 检查结果 | 新的检查结果 |
| 治疗调整 | 是否调整用药 |
| 费用 | 当日费用累计 |
| 下一步计划 | 明天计划做什么 |

### 沟通方式

| 方式 | 适用 |
|------|------|
| 电话 | 主要沟通方式 |
| 微信 | 发送照片、视频 |
| 当面沟通 | 探视时 |
| 书面 | 重要病情变化 |


## 探视制度

### 探视时间

| 类型 | 建议时间 | 说明 |
|------|---------|------|
| 普通住院 | 每天1-2次，每次15-30分钟 | 避免影响治疗 |
| 危重病例 | 限制探视，医生评估后决定 | 减少应激 |
| 传染病隔离 | 不探视，视频沟通 | 防止传播 |
| 术后恢复 | 麻醉清醒后探视 | 避免兴奋 |

### 探视要求

| 项目 | 要求 |
|------|------|
| 预约 | 提前预约，避免高峰 |
| 消毒 | 探视前洗手消毒 |
| 防护 | 必要时穿隔离衣 |
| 安静 | 保持安静，避免刺激动物 |
| 时间 | 控制探视时间 |
| 饮食 | 不随意喂食 |
| 记录 | 记录探视情况 |

### 探视注意事项

| 项目 | 说明 |
|------|------|
| 情绪 | 主人情绪稳定后再探视 |
| 互动 | 适度互动，避免过度兴奋 |
| 其他动物 | 不接触其他住院动物 |
| 儿童 | 不建议儿童探视 |
| 拍照 | 允许拍照，但不影响治疗 |


## 病情变化沟通

### 病情好转

| 话术 |
|------|
| “今天它的精神状态比昨天好，开始主动进食了。” |
| “检查结果显示炎症指标在下降，治疗有效。” |
| “如果继续保持，可能过几天就可以出院了。” |

### 病情稳定

| 话术 |
|------|
| “今天情况比较稳定，没有明显恶化。” |
| “我们继续观察，明天再复查。” |
| “您不用太担心，我们会密切监测。” |

### 病情恶化

| 话术 |
|------|
| “今天它的状态比昨天差，我们正在调整治疗方案。” |
| “检查结果显示病情有进展，我们需要和您谈一下。” |
| “目前情况比较危急，需要您做好心理准备。” |

### 需要紧急决策

| 话术 |
|------|
| “情况紧急，需要您尽快决定是否手术。” |
| “目前有两个选择，积极治疗或姑息治疗，您怎么考虑？” |
| “我们会在X分钟内等您的回复。” |

## 客户沟通要点

### 每日沟通时
- 主动联系主人，不等主人问。
- 如实告知病情，不隐瞒不夸大。
- 用通俗语言解释。
- 记录沟通内容。

### 探视时
- 提前告知探视制度。
- 控制探视时间。
- 观察主人情绪。
- 探视后评估动物状态。

### 病情变化时
- 立即通知主人。
- 解释变化原因。
- 给出下一步方案。
- 记录沟通内容。
