# 预后沟通与坏消息告知速查

> 执业兽医师临床决策工具 | 沟通框架、话术模板、常见场景 | 更新日期：2026年9月15日


## 核心沟通原则

| 原则 | 说明 |
|------|------|
| 诚实 | 不隐瞒病情，不夸大希望 |
| 同理心 | 理解主人情绪，不评判 |
| 清晰 | 用通俗语言，避免专业术语 |
| 有准备 | 提前想好怎么说，不即兴发挥 |
| 有时间 | 留出足够时间让主人提问 |
| 有方案 | 不只告知坏消息，还要给出选择 |
| 有支持 | 让主人知道不是一个人面对 |


## 坏消息告知框架（SPIKES模型）

| 步骤 | 说明 | 示例话术 |
|------|------|---------|
| S（Setting）准备环境 | 安静私密的空间，坐下来说 | “我们到这边坐下来聊。” |
| P（Perception）了解认知 | 先问主人知道多少 | “您对目前的检查结果了解多少？” |
| I（Invitation）获取许可 | 询问是否想知道详情 | “检查结果出来了，您想了解具体情况吗？” |
| K（Knowledge）告知信息 | 用通俗语言告知，分次给信息 | “检查结果显示，它的肾脏功能已经严重下降。” |
| E（Empathy）回应情绪 | 认可主人情绪，不急于解决问题 | “我知道这个消息很难接受。” |
| S（Strategy）给出方案 | 给出下一步选择，不只说坏消息 | “我们可以选择积极治疗，也可以选择让它在舒适中度过。” |


## 不同场景话术模板

### 场景一：告知确诊重病

| 步骤 | 话术 |
|------|------|
| 开场 | “检查结果出来了，我需要和您认真谈一谈。” |
| 告知 | “根据检查结果，它确诊为XX病。” |
| 停顿 | （留出几秒，让主人消化） |
| 同理 | “我知道这个消息对您来说很难接受。” |
| 解释 | “这种病的特点是……目前的情况是……” |
| 方案 | “我们可以选择积极治疗，也可以选择让它在舒适中度过。您觉得哪种方式更适合它？” |

### 场景二：告知预后不良

| 步骤 | 话术 |
|------|------|
| 开场 | “我需要和您坦诚地谈一下它的预后。” |
| 告知 | “目前的情况不太乐观，即使积极治疗，可能也只有X时间。” |
| 同理 | “我知道您已经尽力了，这不是您的错。” |
| 解释 | “我们会尽全力让它舒适，但需要您做好心理准备。” |
| 方案 | “我们可以继续积极治疗，也可以转为姑息治疗，重点放在减轻痛苦上。” |

### 场景三：告知需要安乐死

| 步骤 | 话术 |
|------|------|
| 开场 | “我知道您很爱它，也一直在为它努力。” |
| 告知 | “目前它的痛苦已经很难用药物控制了，继续下去可能只是延长痛苦。” |
| 同理 | “这个决定非常艰难，无论您怎么选择，我们都会支持您。” |
| 解释 | “安乐死是一种让它在无痛苦中离开的方式。” |
| 方案 | “您可以再考虑一下，也可以和家人商量。我们随时都在。” |

### 场景四：告知治疗费用较高

| 步骤 | 话术 |
|------|------|
| 开场 | “治疗方案确定后，我需要和您说一下费用。” |
| 告知 | “整个治疗预计需要X元，包括……” |
| 同理 | “我知道这个费用不低，您可以根据自己的情况决定。” |
| 方案 | “我们可以选择积极治疗，也可以选择经济方案，或者只做缓解症状的治疗。” |

### 场景五：告知抢救无效

| 步骤 | 话术 |
|------|------|
| 开场 | “我们尽了全力，但很遗憾……” |
| 告知 | “它在X点X分离开了我们。” |
| 同理 | “我知道这个消息对您来说非常沉重。” |
| 支持 | “您可以进去和它告别，我们会在外面等您。” |
| 后续 | “后续的事情我们可以帮您安排，您有什么需要随时告诉我们。” |


## 常见沟通误区

| 误区 | 正确做法 |
|------|---------|
| 说“我们也没办法了” | 说“我们可以选择让它在舒适中度过” |
| 说“它不行了” | 说“它的病情已经非常严重” |
| 说“您要不要放弃治疗” | 说“您可以根据情况选择治疗方案” |
| 说“这个病治不好” | 说“这个病目前无法治愈，但我们可以控制症状” |
| 说“您早该带它来” | 说“我们现在一起想办法” |
| 过度承诺“一定能治好” | 说“我们会尽全力，但需要做好心理准备” |
| 在走廊或公共区域谈坏消息 | 到安静的诊室坐下来谈 |
| 一次给太多信息 | 分次告知，留出提问时间 |


## 情绪支持技巧

| 主人情绪 | 回应技巧 |
|---------|---------|
| 哭泣 | 递纸巾，安静等待，不打断 |
| 愤怒 | 认可情绪，不辩解，不反击 |
| 否认 | 不争论，重复事实，留出时间 |
| 自责 | 说“这不是您的错”，不评判 |
| 沉默 | 留出空间，不急于填满 |
| 反复提问 | 耐心重复，不表现出不耐烦 |
| 要求“不惜一切代价” | 解释现实，给出合理方案 |
| 要求“立即安乐死” | 确认决定，留出考虑时间 |


## 沟通记录与法律保护

| 项目 | 说明 |
|------|------|
| 知情同意书 | 重要治疗前签署 |
| 沟通记录 | 记录沟通时间、内容、主人决定 |
| 录音录像 | 征得同意后可录音 |
| 见证人 | 重要沟通可有护士在场 |
| 病历记录 | 详细记录病情、沟通、决策 |
| 费用告知 | 书面报价，主人签字确认 |


## 客户沟通要点

### 告知坏消息前
- 确认检查结果准确
- 准备好通俗解释
- 选择安静私密环境
- 留出足够时间
- 准备好下一步方案

### 告知坏消息时
- 坐下来说，不要站着
- 用通俗语言，避免术语
- 分次给信息，留出停顿
- 认可主人情绪
- 不只说坏消息，还要给出选择

### 告知坏消息后
- 留出提问时间
- 提供书面资料
- 安排后续沟通
- 记录沟通内容
- 提供心理支持
