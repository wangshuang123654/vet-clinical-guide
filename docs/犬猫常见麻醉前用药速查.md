# 犬猫常见麻醉前用药速查

> 执业兽医师临床决策工具 | 镇静、镇痛、抗胆碱能 | 更新日期：2026年9月15日


## 麻醉前用药目的

| 目的 | 说明 |
|------|------|
| 镇静 | 减少应激、便于操作 |
| 镇痛 | 减少术中及术后疼痛 |
| 减少麻醉药用量 | 降低诱导和维持药物剂量 |
| 抑制分泌物 | 减少呼吸道分泌物 |
| 稳定心律 | 预防迷走神经反射 |
| 止吐 | 减少呕吐误吸风险 |

## 麻醉前用药注意事项

| 项目 | 说明 |
|------|------|
| 剂量调整 | 老年、虚弱、休克动物减量 |
| 品种差异 | 柯利犬避免伊维菌素类 |
| 心血管状态 | 低血压动物避免乙酰丙嗪 |
| 呼吸状态 | 呼吸抑制动物避免阿片类过量 |
| 肝肾功能 | 肝肾功能不全动物减量 |
| 妊娠 | 避免使用对胎儿有影响的药物 |


## 常见不良反应处理

| 药物 | 不良反应 | 处理 |
|------|---------|------|
| 乙酰丙嗪 | 低血压 | 补液、减量 |
| 美托咪定 | 心动过缓 | 阿托品、阿替美唑 |
| 阿片类 | 呼吸抑制 | 纳洛酮、辅助通气 |
| 阿片类 | 呕吐 | 止吐药、禁食 |
| 抗胆碱能药 | 心动过速 | 减量、监测 |
| 咪达唑仑 | 兴奋 | 氟马西尼 |


## 客户沟通要点

### 解释麻醉前用药时
- 麻醉前用药是为了减少应激、镇痛和减少麻醉药用量。
- 用药后会观察动物反应，确保安全。
- 部分药物可能引起轻微副作用，但通常是可控的。

### 出院指导
- 麻醉前需禁食6-8小时，禁水2-4小时。
- 按医嘱完成术前检查。
- 如果动物有特殊病史或用药史，提前告知兽医。
