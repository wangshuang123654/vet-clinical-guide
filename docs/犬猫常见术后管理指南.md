# 犬猫常见术后管理指南

> 执业兽医师临床决策工具 | 术后24小时关键监护期 | 更新日期：2026年9月9日


## 术后管理核心原则（三大目标）

| 目标 | 说明 | 评估指标 |
|------|------|---------|
| 维持生命体征稳定 | 血压、心率、呼吸、体温在正常范围内 | 每15-30分钟监测一次，直至完全清醒 |
| 控制疼痛 | 有效止痛是术后恢复的基础 | 疼痛评估量表每2-4小时评估一次 |
| 预防并发症 | 早期识别并干预术后并发症 | 系统性观察、及时发现异常 |


## 术后立即处理（麻醉苏醒期）

### 呼吸系统监测与维护

| 项目 | 正常值或目标 | 异常处理 |
|------|-----------|---------|
| 呼吸频率（犬） | 10-30次/分钟 | 频率升高可能提示疼痛、发热、肺水肿；频率降低可能提示麻醉过深 |
| 呼吸频率（猫） | 20-30次/分钟 | 同犬 |
| SpO₂ | 大于等于95% | 小于95%需检查气管插管位置、供氧、听诊肺部 |
| 气道通畅 | 无阻塞、无异物 | 保持舌向前拉、清理口腔分泌物，必要时放置口咽通气道 |
| 黏膜颜色 | 粉红湿润 | 发绀提示缺氧；苍白提示贫血或低血压 |

**操作要点：**
- 拔管前确保吞咽反射恢复（能吞咽分泌物）
- 拔管后保持颈部伸直，观察呼吸5-10分钟
- 可放置鼻氧管或面罩吸氧，维持SpO₂大于95%

### 心血管系统监测

| 项目 | 正常值或目标 | 异常处理 |
|------|-----------|---------|
| 心率（犬） | 60-140次/分钟 | 心动过速提示疼痛、低血容量；心动过缓提示麻醉过深、低体温 |
| 心率（猫） | 160-220次/分钟 | 同犬 |
| 血压 | 收缩压100-150 mmHg | 低血压需输液、升压药；高血压需排查疼痛、液体过负荷 |
| CRT | 1-2秒 | 大于2秒提示低血容量、心输出量下降 |
| 脉搏质量 | 强而规律 | 弱提示低血容量；不规律提示心律失常 |

### 体温管理

| 项目 | 犬 | 猫 |
|------|-------|-------|
| 正常体温 | 37.8-39.2℃ | 38.0-39.2℃ |
| 体温低于37.5℃ | 复温干预 | 复温干预 |
| 体温低于36.0℃ | 积极复温、警惕心律失常 | 积极复温、警惕心律失常 |
| 体温高于39.5℃ | 排查疼痛、感染 | 排查疼痛、感染 |

**复温方法（按优先级排序）：**
1. 热风毯或循环温水毯（最有效）
2. 加热输液
3. 保温灯或加热垫（注意避免烫伤）
4. 增加环境温度、覆盖保温毯

### 疼痛评估与干预

| 疼痛评分 | 表现 | 干预 |
|---------|------|------|
| 0-1分（无痛） | 安静、正常行为 | 继续观察 |
| 2-3分（轻度） | 略警惕、偶尔呜咽 | 可增加非阿片类止痛药 |
| 4-5分（中度） | 呜咽、心率升高、呼吸急促、紧张 | 给予阿片类药物 |
| 6-7分（重度） | 持续呜咽或尖叫、挣扎、攻击性 | 强效阿片类药物加镇静剂 |
| 8-10分（剧痛） | 喘息、虚脱、无法安抚 | 评估是否需要急诊干预 |


## 术后并发症预防与处理

### 出血

| 类型 | 表现 | 处理 |
|------|------|------|
| 创口渗血 | 敷料上有少量血渍 | 加压包扎，更换敷料，评估凝血功能 |
| 活动性出血 | 持续滴血、敷料浸透、贫血体征 | 手术切口探查、结扎止血、输血（严重时） |
| 内出血或腹腔出血 | 心率升高、血压下降、黏膜苍白、腹围增大 | 紧急B超探查、手术止血 |

### 感染或切口问题

| 类型 | 表现 | 处理 |
|------|------|------|
| 切口感染 | 红肿、热痛、脓性渗出、发热 | 抗生素（根据培养和药敏）、清创、引流 |
| 切口裂开 | 切口边缘分离、组织外露 | 评估是否需要二次缝合、包扎减张 |
| 血清肿 | 切口下波动感、无痛、有液体 | 少量可自行吸收；大量需穿刺引流 |
| 切口肉芽肿 | 切口处增生性肿物 | 观察或手术切除 |

### 呕吐或反流或误吸

| 类型 | 表现 | 处理 |
|------|------|------|
| 术后呕吐 | 术后24小时内呕吐 | 止吐药（马罗匹坦0.5-1 mg/kg IV或SC）、排查麻醉相关因素、排查疼痛、排查胃肠道原发病变 |
| 反流或误吸 | 口腔内有食物或液体残留、呼吸急促 | 头低脚高位、吸引气道、抗生素（防吸入性肺炎）、氧疗 |

### 膀胱尿潴留

| 表现 | 处理 |
|------|------|
| 膀胱充盈、24小时未排尿 | 手动挤压膀胱（确认无尿道梗阻）；必要时导尿 |
| 排尿困难、排尿疼痛 | 排查尿路感染或损伤 |


## 不同手术类型的特殊管理要点

### 腹部手术（胃肠切开或切除、膀胱切开、子宫蓄脓摘除等）

- 术后24小时内禁食（术后4-6小时可少量喂水）
- 术后24小时后少量流质饮食，逐步过渡
- 排查是否出现腹胀、腹膜炎体征
- 评估缝合处愈合情况

### 骨科手术（骨折内固定、截骨、关节置换）

- 术后即开始物理治疗（被动活动、按摩）
- 评估神经功能（有无运动障碍、感觉异常）
- 肢体抬高（减少水肿），必要时冷敷（术后24小时内）
- 术后4-6周严格限制活动，之后逐步康复训练
- 术后6-8周复查X光评估骨骼愈合

### 泌尿系统手术（尿道造口、膀胱切开、肾脏手术）

- 术后24小时内严格监测尿量和颜色
- 导尿管留置期间做好护理（每日更换集尿袋）
- 拔管后评估排尿情况（能否自主排尿、有无血尿）
- 监测肾功能（BUN、Crea、尿比重）

### 口腔手术（拔牙、牙周治疗等）

- 术后禁食12小时
- 24小时内给予流质或半流质食物
- 术后2周内不进硬食、不啃咬硬物
- 口腔冲洗（温和、避开缝合线）
- 必要时放置食道饲管

### 眼科手术（眼睑、角膜、晶状体手术）

- 严格佩戴伊丽莎白圈，防止抓挠
- 按时滴眼药，注意无菌操作
- 避免强光刺激、定期复查
- 密切观察有无角膜水肿或穿孔征象


## 术后护理常规

### 创口护理

| 项目 | 操作 |
|------|------|
| 敷料更换 | 术后24-48小时首次更换，此后视渗出情况每24-48小时更换一次 |
| 创口观察 | 每日检查创口有无红肿、渗出、裂开（至少2次） |
| 拆线时间 | 皮肤缝线：术后10-14天；颈部或头部：7-10天；张力较大部位：14-21天 |
| 保护措施 | 佩戴伊丽莎白圈或穿戴术后服，防止舔咬创口 |
| 禁忌 | 拆线前创口不沾水、不涂药膏（除非兽医处方） |

### 饮食管理

| 时间 | 犬 | 猫 |
|------|-------|-------|
| 术后6-12小时 | 少量饮水（不呕吐可喂少量温水） | 少量饮水（不呕吐可喂少量温水） |
| 术后12-24小时 | 流质饮食（稀饭、湿粮） | 流质饮食（湿粮加水打成糊） |
| 术后24-48小时 | 半流质（软食、湿粮） | 半流质（湿粮） |
| 术后48小时后 | 逐步恢复正常饮食 | 逐步恢复正常饮食 |

> 若连续12小时以上无法进食，应考虑放置食道饲管或鼻饲管进行营养支持。

### 活动管理

| 术后时间 | 活动限制 |
|---------|---------|
| 术后24小时内 | 严格笼养，防止摔伤 |
| 术后2-7天 | 限制活动，短时间遛狗（5-10分钟） |
| 术后7-14天 | 逐步增加活动，但仍避免跳跃、奔跑 |
| 术后14天以上 | 根据恢复情况逐步恢复正常活动 |

## 术后出院指导（宠主版）

### 创口护理
- 术后10-14天拆线，在此期间不要撕咬或舔舐创口，必须戴伊丽莎白圈
- 每天检查创口2次，如果出现红肿、渗出、裂开，及时复诊

### 活动限制
- 术后1周内严格限制活动，不要让动物跳跃或剧烈运动
- 遛狗时牵短绳，控制活动范围

### 饮食管理
- 术后12-24小时给予流质或半流质饮食，之后逐步恢复正常饮食
- 如果动物食欲不振超过48小时，需复诊

### 用药指导
- 止痛药需按医嘱定时服用，不要随意增减或停用
- 抗生素需按疗程完成，不要提前停药

### 复查安排
- 术后10-14天复查拆线
- 骨科手术需术后4-6周复查X光

### 紧急情况联系
- 呼吸困难、张口呼吸、舌头发紫
- 创口大量出血或持续渗血
- 精神萎靡、食欲废绝超过24-48小时
- 反复呕吐或腹泻
- 体温异常


## 常见术后并发症预警

| 并发症 | 预警信号 | 干预时机 |
|--------|---------|---------|
| 肺水肿 | 呼吸急促、湿啰音、SpO₂下降 | 术后1-2小时内出现需立即处理 |
| 术后出血 | 心率升高、血压下降、黏膜苍白 | 术后6-12小时内评估是否需要二次手术 |
| 术后肠梗阻 | 持续呕吐、腹围增大、无排便 | 术后48-72小时内排查原因 |
| 切口感染 | 红肿、热、脓性渗出、发热 | 术后3-5天后出现需根据药敏选用抗生素 |
| 猫脂肪肝 | 术后厌食超过48-72小时 | 术后48-72小时立即开始营养支持 |

> 术后管理金句：
> 稳定在先——生命体征稳定是术后恢复的基础
> 疼痛在前——术后第一个24小时控制疼痛是关键
> 营养在早——不呕吐的情况下尽早恢复经口进食
> 监测在勤——术后前2小时每15-30分钟监测一次
> 沟通在清——出院指导是预防术后问题的最后一道防线
