# 犬猫留置管护理速查

> 执业兽医师临床决策工具 | 胸腔引流、鼻饲管、中心静脉、导尿管护理 | 更新日期：2026年9月15日


## 胸腔引流管护理

### 适应症

| 适应症 | 说明 |
|--------|------|
| 气胸 | 胸腔积气 |
| 胸腔积液 | 脓胸、乳糜胸、血胸 |
| 胸部手术后 | 引流渗血、渗液 |
| 肺叶切除术后 | 监测漏气 |

### 放置位置

| 动物 | 位置 |
|------|------|
| 犬 | 第7-9肋间，背侧（气胸）或腹侧（积液） |
| 猫 | 第6-8肋间，背侧（气胸）或腹侧（积液） |

### 护理要点

| 项目 | 频率 | 说明 |
|------|------|------|
| 观察引流 | 每小时 | 记录引流量、颜色、性状 |
| 检查管道 | 每小时 | 有无扭曲、堵塞、脱落 |
| 检查水封 | 每小时 | 水封瓶有无气泡、波动 |
| 更换敷料 | 每天 | 无菌操作，观察穿刺点 |
| 更换引流瓶 | 每天或按需 | 无菌操作 |
| 冲洗管道 | 按需 | 生理盐水冲洗（医生操作） |
| 抗生素 | 根据医嘱 | 预防感染 |

### 引流量记录

| 引流量 | 处理 |
|--------|------|
| 少量（小于1 mL/kg/h） | 继续观察 |
| 中量（1-2 mL/kg/h） | 密切监测 |
| 大量（大于2 mL/kg/h） | 通知医生，评估出血 |

### 并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 管道堵塞 | 引流量突然减少 | 冲洗管道 |
| 管道脱落 | 引流管脱出 | 立即封闭伤口，通知医生 |
| 感染 | 发热、穿刺点红肿 | 抗生素、更换敷料 |
| 气胸加重 | 呼吸困难 | 检查管道、水封 |
| 肺水肿 | 呼吸急促 | 评估输液量 |


## 鼻饲管护理

### 适应症

| 适应症 | 说明 |
|--------|------|
| 厌食 | 猫脂肪肝、术后厌食 |
| 口腔疾病 | 口炎、颌骨骨折 |
| 食道疾病 | 巨食道、食道狭窄 |
| 神经疾病 | 吞咽困难 |
| 营养支持 | 危重病例 |

### 放置位置

| 类型 | 位置 | 适用 |
|------|------|------|
| 鼻饲管 | 鼻腔→食道 | 短期（小于1周） |
| 鼻食道管 | 鼻腔→食道 | 短期 |
| 食道饲管 | 颈部食道 | 长期（数周至数月） |
| 胃饲管 | 胃 | 长期 |

### 护理要点

| 项目 | 频率 | 说明 |
|------|------|------|
| 检查固定 | 每天 | 防止脱落 |
| 检查鼻孔 | 每天 | 有无红肿、分泌物 |
| 冲洗管道 | 每次喂食前后 | 生理盐水冲洗 |
| 喂食 | 按医嘱 | 少量多餐 |
| 更换敷料 | 每天 | 无菌操作 |
| 伊丽莎白圈 | 持续 | 防止抓挠 |

### 喂食要点

| 项目 | 说明 |
|------|------|
| 食物温度 | 室温或微温 |
| 喂食速度 | 缓慢（5-10分钟） |
| 喂食量 | 按医嘱，少量多餐 |
| 喂食后 | 冲洗管道，保持直立 |
| 监测 | 呕吐、腹泻、腹胀 |

### 并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 管道堵塞 | 无法喂食 | 冲洗管道 |
| 管道脱落 | 管道脱出 | 重新放置 |
| 吸入性肺炎 | 呼吸急促、发热 | 抗生素、吸氧 |
| 鼻炎 | 鼻分泌物 | 清洁、抗生素 |
| 呕吐 | 喂食后呕吐 | 减量、减慢速度 |


## 中心静脉导管护理

### 适应症

| 适应症 | 说明 |
|--------|------|
| 危重病例 | 监测中心静脉压 |
| 长期输液 | 高渗液体、肠外营养 |
| 采血 | 频繁采血 |
| 给药 | 急救药物 |

### 放置位置

| 类型 | 位置 |
|------|------|
| 颈静脉 | 最常用 |
| 股静脉 | 备选 |
| 头静脉 | 外周 |

### 护理要点

| 项目 | 频率 | 说明 |
|------|------|------|
| 检查敷料 | 每天 | 有无潮湿、脱落 |
| 更换敷料 | 每2-3天 | 无菌操作 |
| 冲洗管道 | 每天2-3次 | 生理盐水冲洗 |
| 检查穿刺点 | 每天 | 有无红肿、渗出 |
| 更换输液管 | 每24-48小时 | 无菌操作 |
| 监测体温 | 每天 | 发热提示感染 |

### 并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 感染 | 发热、穿刺点红肿 | 拔管、抗生素 |
| 血栓 | 肢体肿胀 | 抗凝、拔管 |
| 气胸 | 呼吸困难 | 胸腔穿刺 |
| 导管堵塞 | 无法输液 | 冲洗、更换 |
| 导管脱落 | 导管脱出 | 拔管、压迫止血 |


## 导尿管护理

### 适应症

| 适应症 | 说明 |
|--------|------|
| 尿道梗阻 | 公猫尿闭 |
| 尿潴留 | 膀胱充盈 |
| 尿量监测 | 危重病例 |
| 膀胱冲洗 | 膀胱炎 |

### 护理要点

| 项目 | 频率 | 说明 |
|------|------|------|
| 检查固定 | 每天 | 防止脱落 |
| 更换集尿袋 | 每天 | 无菌操作 |
| 冲洗导尿管 | 每天2-3次 | 生理盐水冲洗 |
| 监测尿量 | 每小时 | 记录尿量 |
| 监测尿液 | 每天 | 颜色、透明度 |
| 会阴清洁 | 每天 | 碘伏消毒 |

### 并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 尿路感染 | 发热、脓尿 | 抗生素 |
| 导尿管堵塞 | 无尿流出 | 冲洗导尿管 |
| 导尿管脱落 | 尿液外漏 | 重新放置 |
| 血尿 | 尿液呈红色 | 监测、冲洗 |


## 留置管护理通用原则

| 原则 | 说明 |
|------|------|
| 无菌操作 | 所有操作严格无菌 |
| 固定牢靠 | 防止管道脱落 |
| 定期检查 | 每天检查管道和穿刺点 |
| 记录 | 记录引流量、尿量、喂食量 |
| 监测 | 监测生命体征和并发症 |
| 沟通 | 与医生保持沟通，及时处理问题 |


## 客户沟通要点

### 解释留置管时
- 留置管是治疗和监测的重要手段，需要住院护理。
- 留置管可能引起感染，我们会严格无菌操作。
- 留置管期间需要限制活动，防止脱落。

### 出院指导（带管出院）
- 按医嘱护理管道，保持清洁。
- 定期复查，更换敷料。
- 如果出现管道脱落、发热或穿刺点红肿，立即复诊。
- 戴伊丽莎白圈，防止抓挠。
