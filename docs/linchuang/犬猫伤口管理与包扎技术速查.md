## 伤口评估

### 伤口分类

| 类型 | 特点 | 处理原则 |
|------|------|---------|
| 清洁伤口 | 手术切口，无感染 | 一期缝合 |
| 清洁污染伤口 | 手术切口有轻度污染 | 一期缝合或延迟缝合 |
| 污染伤口 | 外伤，有异物或细菌 | 清创后缝合或开放 |
| 感染伤口 | 已有感染，脓性分泌物 | 清创、引流、开放 |

### 伤口评估要点

| 项目 | 评估内容 |
|------|---------|
| 位置 | 伤口所在部位 |
| 大小 | 长度、宽度、深度 |
| 深度 | 是否涉及肌肉、肌腱、骨骼、体腔 |
| 污染 | 有无异物、泥土、毛发 |
| 感染 | 有无红肿、热痛、脓性分泌物 |
| 血供 | 伤口周围组织血供 |
| 神经 | 有无神经损伤 |
| 血管 | 有无大血管损伤 |


## 伤口清创

### 清创步骤

| 步骤 | 操作 |
|------|------|
| 1 | 剃毛（伤口周围广泛剃毛） |
| 2 | 冲洗（大量生理盐水冲洗） |
| 3 | 消毒（碘伏或氯己定） |
| 4 | 探查（评估深度、异物、体腔） |
| 5 | 切除（切除坏死组织、失活组织） |
| 6 | 再次冲洗（生理盐水） |
| 7 | 评估（是否缝合或开放） |

### 冲洗液选择

| 冲洗液 | 适用情况 | 备注 |
|--------|---------|------|
| 生理盐水 | 所有伤口 | 首选 |
| 乳酸林格液 | 所有伤口 | 备选 |
| 稀释碘伏（0.1%） | 污染伤口 | 避免高浓度 |
| 氯己定（0.05%） | 污染伤口 | 避免高浓度 |
| 过氧化氢 | 厌氧菌感染 | 避免用于健康组织 |

### 清创注意事项

| 项目 | 说明 |
|------|------|
| 无菌操作 | 严格无菌，避免交叉感染 |
| 充分冲洗 | 大量生理盐水冲洗，减少细菌 |
| 切除失活组织 | 切除坏死、失活、污染组织 |
| 保护健康组织 | 避免过度清创 |
| 止血 | 清创后彻底止血 |
| 评估神经血管 | 清创时注意保护 |


## 伤口缝合

### 缝合时机

| 伤口类型 | 缝合时机 |
|---------|---------|
| 清洁伤口 | 立即缝合 |
| 清洁污染伤口 | 清创后缝合 |
| 污染伤口 | 清创后延迟缝合（24-72h） |
| 感染伤口 | 开放引流，控制感染后缝合 |

### 缝合材料

| 材料 | 特点 | 适用 |
|------|------|------|
| 可吸收线 | 无需拆线 | 皮下、内脏 |
| 不可吸收线 | 需拆线 | 皮肤 |
| 单股线 | 感染风险低 | 污染伤口 |
| 多股线 | 强度高 | 清洁伤口 |

### 缝合技术

| 技术 | 适用 |
|------|------|
| 简单间断缝合 | 一般皮肤 |
| 简单连续缝合 | 长切口 |
| 十字缝合 | 张力大 |
| 褥式缝合 | 张力大 |
| 荷包缝合 | 圆形伤口 |


## 伤口引流

### 引流适应症

| 适应症 | 说明 |
|--------|------|
| 感染伤口 | 脓性分泌物 |
| 污染伤口 | 异物、坏死组织 |
| 死腔 | 皮下空腔 |
| 渗出多 | 术后渗液 |

### 引流类型

| 类型 | 特点 | 适用 |
|------|------|------|
| 被动引流 | 纱布、引流条 | 浅表伤口 |
| 主动引流 | 负压引流 | 深部伤口 |
| Penrose引流 | 乳胶管 | 一般引流 |
| Jackson-Pratt引流 | 负压球 | 深部引流 |

### 引流护理

| 项目 | 频率 | 说明 |
|------|------|------|
| 观察引流 | 每小时 | 引流量、颜色、性状 |
| 更换敷料 | 每天或按需 | 无菌操作 |
| 检查管道 | 每天 | 有无扭曲、堵塞 |
| 引流管拔除 | 根据引流情况 | 引流量减少后拔除 |


## 伤口包扎

### 包扎目的

| 目的 | 说明 |
|------|------|
| 保护伤口 | 防止污染、损伤 |
| 吸收渗出 | 保持伤口干燥 |
| 固定 | 固定敷料、引流管 |
| 压迫 | 止血、减少水肿 |
| 支撑 | 骨折固定 |

### 包扎材料

| 材料 | 作用 |
|------|------|
| 接触层 | 不粘连敷料 |
| 吸收层 | 纱布、棉垫 |
| 固定层 | 绷带、胶带 |
| 保护层 | 防水膜、弹性绷带 |

### 包扎技术

| 部位 | 包扎方法 |
|------|---------|
| 头部 | 帽式包扎 |
| 颈部 | 环形包扎 |
| 胸部 | 环形包扎 |
| 腹部 | 环形包扎 |
| 四肢 | 螺旋包扎 |
| 尾部 | 螺旋包扎 |

### 包扎注意事项

| 项目 | 说明 |
|------|------|
| 松紧适度 | 过紧影响血供，过松易脱落 |
| 覆盖完全 | 覆盖整个伤口 |
| 固定牢靠 | 防止脱落 |
| 定期更换 | 根据渗出情况 |
| 观察远端 | 观察肢体远端有无肿胀 |


## 伤口感染处理

### 感染征象

| 征象 | 说明 |
|------|------|
| 红肿 | 伤口周围红肿 |
| 热痛 | 局部温度升高、疼痛 |
| 脓性分泌物 | 黄色或绿色脓液 |
| 异味 | 伤口有臭味 |
| 发热 | 全身发热 |
| 白细胞升高 | 血常规异常 |

### 感染处理

| 步骤 | 操作 |
|------|------|
| 1 | 开放伤口，充分引流 |
| 2 | 清创，切除坏死组织 |
| 3 | 冲洗，生理盐水或稀释碘伏 |
| 4 | 抗生素，根据培养和药敏 |
| 5 | 更换敷料，每天或按需 |
| 6 | 监测，观察感染控制情况 |


## 特殊伤口处理

| 伤口类型 | 处理 |
|---------|------|
| 咬伤 | 清创、引流、抗生素 |
| 烧伤 | 冷却、清创、包扎 |
| 化学伤 | 大量冲洗、清创 |
| 撕裂伤 | 清创、缝合、引流 |
| 穿刺伤 | 探查、清创、引流 |
| 手术切口 | 无菌操作、缝合 |


## 客户沟通要点

### 解释伤口处理时
- 伤口需要清创、缝合或引流，根据情况决定。
- 伤口愈合需要时间，需要定期更换敷料。
- 感染伤口需要开放引流，愈合时间更长。

### 出院指导
- 按医嘱更换敷料，保持伤口清洁。
- 戴伊丽莎白圈，防止舔舐。
- 限制活动，防止伤口裂开。
- 如果出现红肿、渗液、发热或伤口裂开，立即复诊。
