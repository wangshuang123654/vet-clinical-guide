# 犬猫胸腔穿刺与腹腔穿刺速查

> 执业兽医师临床决策工具 | 穿刺适应症、操作步骤、并发症处理 | 更新日期：2026年9月15日


## 胸腔穿刺

### 适应症

| 适应症 | 说明 |
|--------|------|
| 胸腔积液 | 诊断性或治疗性引流 |
| 气胸 | 紧急排气 |
| 脓胸 | 引流脓液 |
| 乳糜胸 | 引流乳糜液 |
| 血胸 | 引流血液 |
| 胸腔内给药 | 化疗药物 |

### 禁忌症

| 禁忌症 | 说明 |
|--------|------|
| 严重凝血障碍 | 出血风险高 |
| 穿刺部位感染 | 可能扩散感染 |
| 动物极度躁动 | 需镇静后操作 |

### 器械准备

| 物品 | 说明 |
|------|------|
| 穿刺针 | 16-22G，长度根据体型 |
| 注射器 | 20-60 mL |
| 三通阀 | 连接 |
| 无菌手套 | 一次性 |
| 消毒液 | 碘伏、氯己定 |
| 无菌巾 | 铺巾 |
| 收集管 | 积液分析 |
| 局麻药 | 利多卡因 |

### 穿刺位置

| 动物 | 位置 |
|------|------|
| 犬 | 第7-9肋间，背侧（气胸）或腹侧（积液） |
| 猫 | 第6-8肋间，背侧（气胸）或腹侧（积液） |

### 操作步骤

| 步骤 | 操作 |
|------|------|
| 1 | 镇静或局麻 |
| 2 | 保定动物（站立或侧卧） |
| 3 | 剃毛、消毒、铺巾 |
| 4 | 局麻（穿刺点） |
| 5 | 穿刺针连接三通阀和注射器 |
| 6 | 沿肋骨前缘刺入（避开肋间血管神经） |
| 7 | 回抽，见液体或气体 |
| 8 | 缓慢抽吸 |
| 9 | 抽吸完毕，拔出穿刺针 |
| 10 | 消毒穿刺点，包扎 |

### 注意事项

| 项目 | 说明 |
|------|------|
| 无菌操作 | 严格无菌，避免感染 |
| 避开血管神经 | 沿肋骨前缘刺入 |
| 缓慢抽吸 | 避免快速抽吸导致肺水肿 |
| 抽吸量 | 单次不超过20-30 mL/kg |
| 监测 | 监测呼吸、心率 |
| 并发症 | 气胸、出血、感染 |

### 并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 气胸 | 呼吸困难 | 胸腔穿刺排气 |
| 出血 | 血性积液 | 压迫止血、输血 |
| 感染 | 发热、穿刺点红肿 | 抗生素 |
| 肺水肿 | 呼吸急促 | 吸氧、利尿 |
| 迷走神经反射 | 心动过缓 | 阿托品 |

### 器械准备

| 动物 | 位置 |

| 猫 | 脐下1-2 cm，腹中线旁开1-2 cm |
| 膀胱穿刺 | 耻骨前缘，腹中线 |

### 操作步骤

| 步骤 | 操作 |
|------|------|
| 1 | 镇静或局麻 |
| 2 | 保定动物（仰卧或侧卧） |
| 3 | 剃毛、消毒、铺巾 |
| 4 | 局麻（穿刺点） |
| 5 | 穿刺针连接三通阀和注射器 |
| 6 | 沿腹中线旁开刺入 |
| 7 | 回抽，见液体 |
| 8 | 缓慢抽吸 |
| 9 | 抽吸完毕，拔出穿刺针 |
| 10 | 消毒穿刺点，包扎 |

### 注意事项

| 项目 | 说明 |
|------|------|
| 无菌操作 | 严格无菌，避免感染 |
| 避开肠管 | 穿刺前触诊，避开肠管 |
| 缓慢抽吸 | 避免快速抽吸导致休克 |
| 抽吸量 | 单次不超过20-30 mL/kg |
| 监测 | 监测心率、血压 |
| 并发症 | 肠穿孔、出血、感染 |

### 并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 肠穿孔 | 腹膜炎、腹痛 | 手术修复、抗生素 |
| 出血 | 血性积液 | 压迫止血、输血 |
| 感染 | 发热、腹痛 | 抗生素 |
| 低血容量 | 低血压 | 补液 |
| 迷走神经反射 | 心动过缓 | 阿托品 |


## 积液分析

### 积液分类

| 类型 | 特点 | 常见原因 |
|------|------|---------|
| 漏出液 | 蛋白低、细胞少 | 低蛋白、心衰、肝衰 |
| 渗出液 | 蛋白高、细胞多 | 感染、肿瘤、FIP |
| 血性积液 | 红色 | 出血、肿瘤 |
| 乳糜性积液 | 乳白色 | 乳糜胸 |
| 脓性积液 | 脓性 | 感染 |

### 积液分析项目

| 项目 | 说明 |
|------|------|
| 外观 | 颜色、透明度 |
| 蛋白 | 总蛋白、白蛋白 |
| 细胞 | 细胞计数、细胞学 |
| 葡萄糖 | 与血糖对比 |
| 乳酸 | 感染时升高 |
| 培养 | 细菌感染 |
| PCR | FIP、感染 |
| 甘油三酯 | 乳糜胸 |


## 客户沟通要点

### 解释穿刺时
- 穿刺是诊断和治疗的重要手段，可以快速明确积液性质。
- 穿刺需要镇静或局麻，减少动物疼痛。
- 穿刺可能引起气胸、出血或感染，我们会密切监测。

### 术后护理
- 观察呼吸、心率、精神。
- 穿刺点保持清洁干燥。
- 如果出现呼吸困难、精神变差或穿刺点红肿，立即复诊。
