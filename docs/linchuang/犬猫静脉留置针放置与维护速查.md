### 放置步骤

| 步骤 | 操作 |
|------|------|
| 1 | 保定动物，暴露静脉 |
| 2 | 剃毛（头静脉、隐静脉、颈静脉） |
| 3 | 消毒（碘伏、氯己定，待干） |
| 4 | 扎止血带（近心端） |
| 5 | 绷紧皮肤，固定静脉 |
| 6 | 穿刺（15-30度角） |
| 7 | 见回血后，推进留置针 |
| 8 | 拔出针芯，连接三通阀 |
| 9 | 冲洗（肝素盐水） |
| 10 | 固定（胶带、绷带） |

## 留置针维护

### 日常维护

| 项目 | 频率 | 说明 |
|------|------|------|
| 检查穿刺点 | 每天 | 有无红肿、渗出 |
| 检查固定 | 每天 | 有无松动、脱落 |
| 冲洗 | 每天2-3次 | 肝素盐水冲洗 |
| 更换敷料 | 每2-3天 | 无菌操作 |
| 更换三通阀 | 每2-3天 | 无菌操作 |
| 更换输液管 | 每24-48小时 | 无菌操作 |
| 监测体温 | 每天 | 发热提示感染 |

### 封管

| 项目 | 说明 |
|------|------|
| 封管液 | 肝素盐水（10-100 U/mL） |
| 封管量 | 1-2 mL |
| 频率 | 每次输液后、每天2-3次 |
| 方法 | 正压封管，防止回血 |


## 留置针并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 穿刺点感染 | 红肿、渗出、疼痛 | 拔除留置针，抗生素 |
| 静脉炎 | 静脉走行红肿、疼痛 | 拔除留置针，热敷 |
| 血栓 | 静脉堵塞，无法输液 | 拔除留置针，抗凝 |
| 渗漏 | 穿刺点周围肿胀 | 拔除留置针，重新放置 |
| 留置针脱落 | 留置针脱出 | 拔除，重新放置 |
| 血肿 | 穿刺点血肿 | 压迫止血 |
| 全身感染 | 发热、白细胞升高 | 拔除留置针，抗生素 |


## 留置针拔除

| 项目 | 说明 |
|------|------|
| 拔除时机 | 治疗结束、并发症出现 |

| 拔除后护理 | 压迫止血5分钟，消毒 |

## 客户沟通要点

### 解释留置针时
- 留置针是输液和给药的必要通道，需要住院护理。
- 留置针可能引起感染，我们会严格无菌操作。
- 留置针期间需要限制活动，防止脱落。

### 出院指导（带留置针出院）
- 按医嘱护理留置针，保持清洁。
- 定期复查，更换敷料。
- 如果出现穿刺点红肿、渗液或留置针脱落，立即复诊。
- 戴伊丽莎白圈，防止抓挠。
