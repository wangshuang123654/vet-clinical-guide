## 导尿适应症

| 适应症 | 说明 |
|--------|------|
| 尿道梗阻 | 公猫尿闭、结石、栓子 |
| 尿潴留 | 膀胱充盈但无法排尿 |
| 尿量监测 | 危重病例监测尿量 |
| 膀胱冲洗 | 膀胱炎、血凝块 |
| 尿液采集 | 无菌尿培养 |
| 术前准备 | 泌尿系统手术 |
| 造影检查 | 尿道造影、膀胱造影 |


## 导尿禁忌症

| 禁忌症 | 说明 |
|--------|------|
| 尿道完全断裂 | 导尿可能加重损伤 |
| 严重凝血障碍 | 出血风险高 |
| 膀胱破裂 | 需紧急手术 |
| 尿道感染急性期 | 可能加重感染 |

## 导尿操作步骤

### 公犬导尿

| 步骤 | 操作 |
|------|------|
| 1 | 镇静或麻醉 |
| 2 | 动物仰卧或侧卧 |
| 3 | 挤出包皮内尿液，消毒龟头 |
| 4 | 导尿管涂润滑剂 |
| 5 | 插入导尿管，沿尿道缓慢推进 |
| 6 | 到达膀胱后，尿液流出 |
| 7 | 固定导尿管（缝合或胶带） |
| 8 | 连接集尿袋 |

## 导尿注意事项

| 项目 | 说明 |
|------|------|
| 无菌操作 | 严格无菌，避免尿路感染 |
| 润滑 | 充分润滑，减少尿道损伤 |
| 轻柔 | 遇到阻力时不要强行推进 |
| 固定 | 导尿管需固定牢靠，防止脱落 |
| 集尿袋 | 保持低于膀胱位置，防止尿液反流 |
| 监测 | 监测尿量、颜色、有无血尿 |
| 抗生素 | 根据情况预防性使用 |


## 导尿管维护

| 项目 | 频率 | 说明 |
|------|------|------|
| 检查固定 | 每天 | 防止导尿管脱落 |
| 更换集尿袋 | 每天 | 无菌操作 |
| 冲洗导尿管 | 每天2-3次 | 生理盐水冲洗 |
| 监测尿量 | 每小时 | 记录尿量 |
| 监测尿液 | 每天 | 颜色、透明度、有无血尿 |
| 会阴清洁 | 每天 | 碘伏消毒 |
| 抗生素 | 根据医嘱 | 预防感染 |


## 导尿管拔除

| 项目 | 说明 |
|------|------|
| 拔除时机 | 梗阻解除、尿液通畅、动物能自主排尿 |
| 拔除前 | 夹闭导尿管，观察能否自主排尿 |
| 拔除后 | 观察排尿情况、有无血尿 |
| 拔除后监测 | 尿量、排尿困难、尿痛 |


## 尿道造口护理

### 尿道造口适应症

| 适应症 | 说明 |
|--------|------|
| 反复尿道梗阻 | 公猫反复尿闭 |
| 尿道狭窄 | 外伤或手术后狭窄 |
| 尿道肿瘤 | 肿瘤切除后 |
| 尿道破裂 | 无法修复 |

### 术后护理

| 项目 | 频率 | 说明 |
|------|------|------|
| 观察造口 | 每天 | 有无红肿、渗出、出血 |
| 清洁造口 | 每天 | 生理盐水或碘伏 |
| 抗生素 | 根据医嘱 | 预防感染 |
| 止痛 | 根据医嘱 | 控制疼痛 |
| 伊丽莎白圈 | 持续 | 防止舔舐 |
| 饮食 | 术后24h | 流质饮食 |
| 活动 | 术后1-2周 | 限制活动 |

### 造口并发症

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 造口狭窄 | 排尿困难 | 扩张或二次手术 |
| 造口感染 | 红肿、渗出 | 抗生素、清洁 |
| 尿失禁 | 无法控制排尿 | 评估神经损伤 |
| 造口出血 | 渗血 | 压迫止血、检查 |
| 造口周围皮炎 | 皮肤红肿、糜烂 | 清洁、保护皮肤 |


## 导尿并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 尿道损伤 | 出血、疼痛 | 停止操作、抗生素 |
| 尿路感染 | 发热、脓尿 | 抗生素、更换导尿管 |
| 导尿管堵塞 | 无尿流出 | 冲洗导尿管 |
| 导尿管脱落 | 尿液外漏 | 重新放置 |
| 膀胱痉挛 | 疼痛、排尿 | 止痛、解痉 |
| 血尿 | 尿液呈红色 | 监测、冲洗 |


## 客户沟通要点

### 解释导尿时
- 导尿是解除尿道梗阻的必要操作，需要镇静或麻醉。
- 导尿管需要留置一段时间，期间需要住院观察。
- 导尿可能引起尿路感染，我们会使用抗生素预防。

### 解释尿道造口时
- 尿道造口是解决反复尿道梗阻的手术方案。
- 术后需要长期护理，注意造口清洁。
- 造口后猫的排尿姿势可能改变，属于正常现象。

### 出院指导
- 按医嘱用药，不要随意停药。
- 保持造口清洁，每天消毒。
- 戴伊丽莎白圈，防止舔舐。
- 如果出现排尿困难、造口红肿或渗血，立即复诊。
