# 犬猫骨髓穿刺与活检速查

> 执业兽医师临床决策工具 | 适应症、操作步骤、判读要点 | 更新日期：2026年9月15日


## 骨髓穿刺适应症

| 适应症 | 说明 |
|--------|------|
| 非再生性贫血 | 网织红细胞不升高 |
| 全血细胞减少 | 贫血加白细胞减少加血小板减少 |
| 疑似白血病 | 异常细胞增多 |
| 疑似骨髓肿瘤 | 转移性肿瘤 |
| 不明原因发热 | 排除骨髓疾病 |
| 血液病监测 | 化疗后骨髓抑制 |
| 骨髓培养 | 不明原因感染 |

### 禁忌症

| 禁忌症 | 说明 |
|--------|------|
| 严重凝血障碍 | 出血风险高 |
| 穿刺部位感染 | 可能扩散感染 |
| 动物极度躁动 | 需镇静或麻醉 |
| 严重心肺疾病 | 无法耐受麻醉 |


## 穿刺部位

| 部位 | 特点 | 适用 |
|------|------|------|
| 髂骨 | 最常用，操作简单 | 犬猫均可 |
| 股骨近端 | 备选 | 犬猫均可 |
| 肱骨近端 | 备选 | 犬 |
| 胸骨 | 风险较高 | 犬 |

### 髂骨穿刺定位

| 动物 | 位置 |
|------|------|
| 犬 | 髂骨翼，背侧 |
| 猫 | 髂骨翼，背侧 |

## 操作步骤

### 骨髓穿刺

| 步骤 | 操作 |
|------|------|
| 1 | 镇静或麻醉 |
| 2 | 保定动物（侧卧或俯卧） |
| 3 | 剃毛、消毒、铺巾 |
| 4 | 局麻（穿刺点） |
| 5 | 穿刺针垂直刺入皮肤 |
| 6 | 旋转推进至骨髓腔（有落空感） |
| 7 | 拔出针芯，连接注射器 |
| 8 | 快速抽吸（0.5-1 mL） |
| 9 | 拔出穿刺针，压迫止血 |
| 10 | 涂片、送检 |

### 骨髓活检

| 步骤 | 操作 |
|------|------|
| 1 | 镇静或麻醉 |
| 2 | 保定动物 |
| 3 | 剃毛、消毒、铺巾 |
| 4 | 局麻 |
| 5 | 活检针垂直刺入 |
| 6 | 旋转推进至骨髓腔 |
| 7 | 取出活检针 |
| 8 | 取出骨髓组织 |
| 9 | 压迫止血 |
| 10 | 固定、送检 |


## 注意事项

| 项目 | 说明 |
|------|------|
| 无菌操作 | 严格无菌，避免感染 |
| 快速抽吸 | 抽吸时间短，避免血液稀释 |
| 抽吸量 | 0.5-1 mL，不宜过多 |
| 涂片 | 立即涂片，避免凝固 |
| 止血 | 穿刺后压迫止血 |
| 监测 | 监测生命体征 |
| 并发症 | 出血、感染、疼痛 |


## 骨髓判读要点

### 正常骨髓

| 项目 | 正常表现 |
|------|---------|
| 细胞密度 | 30-70% |
| 粒红比 | 1-3比1 |
| 巨核细胞 | 可见 |
| 淋巴细胞 | 小于10% |
| 浆细胞 | 小于5% |

### 异常骨髓

| 异常 | 可能原因 |
|------|---------|
| 细胞密度降低 | 再生障碍性贫血、化疗后 |
| 粒红比升高 | 炎症、感染 |
| 粒红比降低 | 溶血、失血 |
| 巨核细胞减少 | 免疫介导、骨髓抑制 |
| 原始细胞增多 | 白血病 |
| 肿瘤细胞 | 骨髓转移瘤 |


## 骨髓穿刺并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 出血 | 穿刺点血肿 | 压迫止血 |
| 感染 | 发热、穿刺点红肿 | 抗生素 |
| 疼痛 | 穿刺点疼痛 | 止痛 |
| 血肿 | 皮下血肿 | 压迫、冷敷 |
| 骨髓液稀释 | 涂片细胞少 | 重新穿刺 |


## 客户沟通要点

### 解释骨髓穿刺时
- 骨髓穿刺是诊断血液病的重要手段，可以明确贫血、白细胞异常的原因。
- 穿刺需要镇静或麻醉，减少动物疼痛。
- 穿刺可能引起出血或感染，我们会密切监测。

### 术后护理
- 观察穿刺点有无出血、红肿。
- 限制活动，避免剧烈运动。
- 如果出现穿刺点出血、发热或精神变差，立即复诊。
