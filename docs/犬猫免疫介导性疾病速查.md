## 免疫介导性疾病概述

| 类型 | 机制 | 常见疾病 |
|------|------|---------|
| II型 | 抗体攻击自身细胞 | IMHA、IMTP |
| III型 | 免疫复合物沉积 | 系统性红斑狼疮、肾小球肾炎 |
| IV型 | T细胞介导 | 炎症性肠病、接触性皮炎 |
| 混合型 | 多种机制参与 | 多发性关节炎、天疱疮 |


## 血液系统免疫介导性疾病

### 免疫介导性溶血性贫血（IMHA）

| 项目 | 内容 |
|------|------|
| 病因 | 自身抗体攻击红细胞 |
| 临床表现 | 黏膜苍白、黄疸、血红蛋白尿、虚弱 |
| 诊断 | 红细胞凝集、Coombs试验阳性、网织红细胞增多 |
| 治疗 | 免疫抑制（泼尼松）、输血（严格配血）、抗血栓 |
| 监测 | PCV、网织红细胞、胆红素 |
| 预后 | 及时治疗预后较好，复发率较高 |

### 免疫介导性血小板减少症（IMTP）

| 项目 | 内容 |
|------|------|
| 病因 | 自身抗体攻击血小板 |
| 临床表现 | 瘀点、瘀斑、鼻出血、血便 |
| 诊断 | 血小板减少、血涂片可见大型血小板 |
| 治疗 | 免疫抑制（泼尼松）、输血（严重时）、长春新碱 |
| 监测 | 血小板计数 |
| 预后 | 多数预后良好，部分复发 |

### 埃文斯综合征

| 项目 | 内容 |
|------|------|
| 病因 | IMHA合并IMTP |
| 临床表现 | 贫血加出血倾向 |
| 诊断 | 同时符合IMHA和IMTP诊断标准 |
| 治疗 | 免疫抑制、输血、抗血栓 |
| 监测 | PCV、血小板 |
| 预后 | 比单一疾病预后差 |

### 再生障碍性贫血

| 项目 | 内容 |
|------|------|
| 病因 | 免疫介导骨髓抑制、药物、毒素 |
| 临床表现 | 全血细胞减少、贫血、感染、出血 |
| 诊断 | 全血细胞减少、骨髓穿刺 |

## 免疫介导性疾病诊疗流程

疑似免疫介导性疾病
    |
    ▼
病史和体检
    |
    ▼
基础检查（血常规、生化、尿检）
    |
    ▼
免疫学检查（Coombs、ANA、RF、抗体检测）
    |
    ▼
根据结果分诊
    ├── 血液 -> IMHA、IMTP
    ├── 皮肤 -> 天疱疮、红斑狼疮
    ├── 关节 -> 多发性关节炎
    ├── 肾脏 -> 肾小球肾炎
    └── 神经 -> 重症肌无力、多发性神经病

## 客户沟通要点

### 解释免疫介导性疾病时
- 免疫介导性疾病是免疫系统攻击自身组织，需要长期管理。
- 治疗通常需要数月甚至数年，不能随意停药。
- 免疫抑制药物有副作用，需要定期复查血常规和生化。

### 出院指导
- 按医嘱用药，不要随意停药或调整剂量。
- 定期复查血常规、生化和免疫指标。
- 避免接触感染源，减少感染风险。
- 如果出现精神变差、发热、出血或呼吸困难，立即复诊。
