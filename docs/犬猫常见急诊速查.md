# 犬猫常见急诊速查

> 执业兽医师临床决策工具 | 急诊分诊、稳定、系统处理 | 更新日期：2026年9月15日


## 急诊分诊原则

### 急诊分诊流程

| 步骤 | 内容 |
|------|------|
| 1 | 快速评估（ABC：气道、呼吸、循环） |
| 2 | 生命体征测量（心率、呼吸、体温、CRT、血压） |
| 3 | 分诊分级（红、黄、绿） |
| 4 | 稳定生命体征 |
| 5 | 针对性检查 |
| 6 | 确定性治疗 |

### 急诊分诊分级

| 分级 | 状态 | 处理 | 例子 |
|------|------|------|------|
| 红区 | 危重，随时可能死亡 | 立即抢救 | 呼吸窘迫、休克、癫痫持续状态、尿闭 |
| 黄区 | 不稳定，可能恶化 | 优先处理 | 呕吐腹泻脱水、腹痛、发热 |
| 绿区 | 稳定，可等待 | 常规处理 | 轻度外伤、慢性病复查 |

### 急诊快速评估（ABC）

| 评估项目 | 内容 | 异常处理 |
|---------|------|---------|
| A（气道） | 气道是否通畅 | 清理气道、插管 |
| B（呼吸） | 呼吸频率、深度、SpO2 | 吸氧、辅助通气 |
| C（循环） | 心率、脉搏、CRT、血压 | 补液、升压药 |


## 呼吸系统急诊

| 情况 | 临床表现 | 紧急处理 |
|------|---------|---------|
| 呼吸窘迫 | 张口呼吸、发绀、呼吸急促 | 吸氧、镇静、限制操作 |
| 胸腔积液 | 腹式呼吸、心音遥远 | 胸腔穿刺 |
| 气胸 | 突发呼吸困难、胸廓扩张 | 胸腔穿刺排气 |
| 肺水肿 | 湿啰音、咳粉红色泡沫痰 | 呋塞米、吸氧 |
| 上呼吸道梗阻 | 喘鸣音、吸气困难 | 保持气道通畅、插管 |
| 气管塌陷 | 雁鸣样咳嗽、发绀 | 镇静、吸氧 |

| 情况 | 临床表现 | 紧急处理 |
|------|---------|---------|
| 心脏骤停 | 无脉搏、无呼吸、昏迷 | 立即CPR |

## 急诊监护指标

| 指标 | 正常范围 | 异常处理 |
|------|---------|---------|
| 心率（犬） | 60-140次/分 | 心率异常：排查原因 |
| 心率（猫） | 160-220次/分 | 心率异常：排查原因 |
| 呼吸频率 | 10-30次/分 | 呼吸异常：吸氧、辅助通气 |
| SpO2 | 大于等于95% | 低于95%：吸氧 |
| 血压 | 收缩压100-150 mmHg | 低血压：补液、升压药 |
| CRT | 1-2秒 | 延长：低血容量 |
| 体温 | 37.5-39.2℃ | 低体温：复温；高热：降温 |
| 尿量 | 1-2 mL/kg/h | 少尿：补液、利尿 |


## 客户沟通要点

### 急诊沟通时
- 急诊需要先稳定生命体征，再查找病因。
- 部分急诊需要紧急手术或住院治疗。
- 急诊费用可能较高，需要提前告知。

### 告知风险时
- 目前情况危重，随时可能恶化。
- 我们会尽全力抢救，但需要做好心理准备。
- 如果出现病情变化，我们会及时通知。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查，监测病情变化。
- 如果出现症状加重或新症状，立即复诊。
