## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 犬窝咳 | 详细问诊（接触史） | 呼吸道病原PCR |
| 鼻炎/鼻窦炎 | 鼻腔镜、X光 | 细菌培养、CT |
| 慢性支气管炎 | 胸部X光（支气管征） | 支气管镜、BALF |
| 气管塌陷 | 动态X光（吸/呼气相） | 气管镜、荧光透视 |
| 肺炎 | 胸部X光、血常规 | BALF培养、PCR |
| 肺肿瘤 | 胸部X光、CT | 活检、BALF |
| 心源性肺水肿 | 胸部X光、心超 | 心电图、血压 |
| 心丝虫病 | 心丝虫抗原/微丝蚴检测 | X光、心超 |
| 肺动脉高压 | 心超（右心评估） | 血压、血气 |
| 二尖瓣病 | 心超、听诊 | 心电图、X光 |
| 外伤/异物 | X光、CT | 气管镜 |

## 🐾 客户沟通要点

### 接诊时
- "狗狗咳嗽多久了？是干咳还是有痰？什么时间咳得比较厉害？"
- "最近有没有接触过其他狗？（犬窝咳）"
- "运动或激动时会不会加重？晚上睡觉会不会咳？"
- "有没有流鼻涕、打喷嚏或发烧？"

### 解释检查时
- "我们建议拍个X光，看看是气管、肺部还是心脏的问题。"
- "如果怀疑是心丝虫，需要抽血查一下。"

### 告知风险时
- "气管塌陷虽然不能根治，但可以通过药物和体重管理来很好的控制。"
- "心脏问题引起的咳嗽不能忽视，需要长期服药和定期复查。"

### 出院指导
- "避免剧烈运动和过热环境。"
- "按时吃药，定期复查，注意观察咳嗽频率和精神状态的变化。"
- "如果出现呼吸困难或咳血，立即来医院。"

## 📌 用药参考（犬）

| 药物 | 剂量 | 用途 |
|------|------|------|
| 布托啡诺 | 0.1-0.2 mg/kg IV/SC | 镇咳 |
| 多西环素 | 5-10 mg/kg PO BID | 犬窝咳/细菌感染 |
| 呋塞米 | 2-4 mg/kg PO/IV BID-TID | 心源性肺水肿 |
| ACEI类（依那普利） | 0.25-0.5 mg/kg PO SID-BID | 心脏基础病 |
| 匹莫苯丹 | 0.25-0.5 mg/kg PO BID | 二尖瓣病/扩心病 |
| 泼尼松龙 | 0.5-1 mg/kg PO SID | 慢性支气管炎/过敏 |
| 支气管扩张剂 | 按具体品种剂量 | 哮喘/过敏 |

> ⚠️ 用药前请结合患犬具体体重、肝肾功能及有无用药禁忌再执行。
