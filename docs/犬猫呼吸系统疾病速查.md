# 犬猫呼吸系统疾病速查

> 执业兽医师临床决策工具 | 上呼吸道、下呼吸道、胸腔疾病 | 更新日期：2026年9月15日


## 呼吸系统解剖与功能

| 部位 | 主要功能 | 常见疾病 |
|------|---------|---------|
| 鼻腔 | 过滤、加温、湿润空气 | 鼻炎、鼻窦炎、肿瘤、异物 |
| 咽喉 | 发声、吞咽 | 咽喉炎、喉麻痹、软腭过长 |
| 气管 | 输送空气 | 气管塌陷、气管炎 |
| 支气管 | 输送空气 | 支气管炎、哮喘 |
| 肺 | 气体交换 | 肺炎、肺水肿、肺肿瘤 |
| 胸腔 | 保护、负压 | 胸腔积液、气胸、脓胸 |
| 膈肌 | 呼吸运动 | 膈疝 |


## 上呼吸道疾病

### 鼻炎或鼻窦炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染（病毒、细菌、真菌）、过敏、异物、肿瘤 |
| 临床表现 | 打喷嚏、鼻分泌物、鼻出血、呼吸困难 |
| 诊断 | 鼻腔镜、X光、CT、细胞学、培养 |
| 治疗 | 冲洗鼻腔、抗生素、抗真菌、抗炎、手术 |
| 预后 | 感染性预后良好，肿瘤预后取决于类型 |

### 咽喉炎或扁桃体炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染、异物、过敏 |
| 临床表现 | 吞咽困难、干呕、咽喉红肿、发热、流涎 |
| 诊断 | 咽喉镜、细胞学、培养 |
| 治疗 | 抗生素、抗炎、流质饮食、严重时扁桃体切除 |
| 预后 | 多数预后良好 |

### 喉麻痹

| 项目 | 内容 |
|------|------|
| 病因 | 先天性（品种）、获得性（神经损伤、肿瘤） |
| 临床表现 | 喘鸣音、吸气困难、运动不耐受、声音改变 |
| 诊断 | 喉镜、X光 |
| 治疗 | 手术（喉成形术）、控制体重、避免过热 |
| 预后 | 手术预后较好 |

### 短头品种气道综合征

| 项目 | 内容 |
|------|------|
| 病因 | 解剖结构异常（软腭过长、鼻孔狭窄、喉小囊外翻） |
| 临床表现 | 打鼾、呼吸费力、运动不耐受、发绀 |
| 诊断 | 喉镜、X光 |
| 治疗 | 手术矫正、控制体重、避免应激 |
| 预后 | 手术预后较好 |


## 下呼吸道疾病

### 气管塌陷

| 项目 | 内容 |
|------|------|
| 病因 | 先天性（小型犬）、获得性（慢性气管炎） |
| 临床表现 | 干咳（雁鸣样）、运动后加重、激动时加重 |
| 诊断 | X光（吸气或呼气相）、气管镜、荧光透视 |
| 治疗 | 镇咳、支气管扩张剂、控制体重、严重时放置支架 |
| 预后 | 保守治疗可控制，严重者需手术 |

### 慢性支气管炎

| 项目 | 内容 |
|------|------|
| 病因 | 慢性炎症、环境刺激、感染 |
| 临床表现 | 慢性干咳（大于2个月）、运动不耐受 |
| 诊断 | X光（支气管征）、支气管镜、BALF |
| 治疗 | 支气管扩张剂、抗炎、控制体重、环境管理 |
| 预后 | 需要长期管理 |

### 猫哮喘

| 项目 | 内容 |
|------|------|
| 病因 | 过敏、环境刺激 |
| 临床表现 | 阵发性干咳、呼气困难、喘息 |
| 诊断 | X光（支气管征）、BALF（嗜酸性粒细胞增多） |
| 治疗 | 支气管扩张剂、糖皮质激素、环境管理 |
| 预后 | 需要长期管理，多数可控制 |

### 肺炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌、病毒、真菌、吸入性 |
| 临床表现 | 发热、湿咳、呼吸急促、精神沉郁 |
| 诊断 | X光（肺泡浸润）、血常规、BALF培养 |
| 治疗 | 抗生素（根据药敏）、雾化、补液、吸氧 |
| 预后 | 及时治疗预后较好 |

### 肺水肿

| 项目 | 内容 |
|------|------|
| 病因 | 心源性（左心衰）、非心源性（ARDS、中毒） |
| 临床表现 | 呼吸急促、湿啰音、发绀、咳粉红色泡沫痰 |
| 诊断 | X光（肺水肿征）、心超、NT-proBNP |
| 治疗 | 利尿（呋塞米）、吸氧、强心、扩血管 |
| 预后 | 心源性预后取决于心脏病的控制 |

### 肺肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 原发性或转移性 |
| 临床表现 | 慢性咳、体重下降、呼吸困难 |
| 诊断 | X光、CT、活检 |
| 治疗 | 手术切除、化疗、放疗 |
| 预后 | 取决于肿瘤类型和分期 |


## 胸腔疾病

### 胸腔积液

| 项目 | 内容 |
|------|------|
| 病因 | 心衰、FIP、脓胸、乳糜胸、肿瘤 |
| 临床表现 | 呼吸急促、腹式呼吸、心音遥远 |
| 诊断 | X光、B超、胸腔穿刺、积液分析 |
| 治疗 | 胸腔穿刺引流、治疗原发病 |
| 预后 | 取决于原发病 |

### 气胸

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、肺大泡破裂、医源性 |
| 临床表现 | 突发呼吸困难、胸廓扩张、发绀 |
| 诊断 | X光、B超（肺滑动征消失） |
| 治疗 | 胸腔穿刺排气、胸腔引流、手术 |
| 预后 | 及时处理预后良好 |

### 脓胸

| 项目 | 内容 |
|------|------|
| 病因 | 细菌感染（咬伤、肺炎、食道穿孔） |
| 临床表现 | 发热、呼吸急促、精神沉郁 |
| 诊断 | X光、B超、胸腔穿刺（脓性积液） |
| 治疗 | 胸腔引流、抗生素、手术（严重时） |
| 预后 | 及时治疗预后较好 |

### 乳糜胸

| 项目 | 内容 |
|------|------|
| 病因 | 胸导管破裂、心衰、肿瘤 |
| 临床表现 | 呼吸急促、运动不耐受 |
| 诊断 | X光、胸腔穿刺（乳白色积液）、甘油三酯检测 |
| 治疗 | 胸腔引流、低脂饮食、手术（胸导管结扎） |
| 预后 | 保守治疗部分可控制，手术预后较好 |

### 膈疝

| 项目 | 内容 |
|------|------|
| 病因 | 先天性、外伤性 |
| 临床表现 | 呼吸急促、呕吐、腹痛 |
| 诊断 | X光（膈肌不连续、腹腔脏器进入胸腔） |
| 治疗 | 手术修复 |
| 预后 | 及时手术预后良好 |


## 呼吸系统疾病诊疗流程

呼吸困难
    |
    ▼
稳定生命体征（吸氧、镇静）
    |
    ▼
病史和体检
    |
    ▼
基础检查（血常规、生化、X光）
    |
    ▼
根据结果分诊
    ├── 上呼吸道 -> 鼻腔镜、喉镜
    ├── 下呼吸道 -> X光、BALF、心超
    ├── 胸腔 -> 胸腔穿刺、B超
    └── 心源性 -> 心超、NT-proBNP


## 呼吸系统疾病紧急处理

| 情况 | 处理 |
|------|------|
| 呼吸窘迫 | 吸氧、镇静、限制操作 |
| 发绀 | 立即吸氧，准备插管 |
| 胸腔积液 | 胸腔穿刺引流 |
| 气胸 | 胸腔穿刺排气 |
| 肺水肿 | 呋塞米、吸氧 |
| 上呼吸道梗阻 | 保持气道通畅，必要时插管 |


## 客户沟通要点

### 解释呼吸系统疾病时
- 呼吸系统疾病可轻可重，需要根据检查结果制定治疗方案。
- 慢性呼吸系统疾病需要长期管理，不能指望一次治愈。
- 如果出现呼吸急促、发绀或精神变差，需要立即就诊。

### 出院指导
- 按医嘱用药，不要随意停药。
- 避免环境刺激（烟雾、粉尘、香水）。
- 控制体重，避免剧烈运动。
- 定期复查，监测病情变化。
