## 牙科检查流程

### 基础检查

| 步骤 | 操作 |
|------|------|
| 1 | 视诊：面部对称性、咬合、口腔气味 |
| 2 | 触诊：颌骨、颞下颌关节、颈部淋巴结 |
| 3 | 口腔检查：唇、颊、舌、腭、口咽 |
| 4 | 牙周检查：牙周袋深度、牙龈退缩、牙松动度 |
| 5 | 牙齿检查：牙冠完整性、颜色、磨损、骨折 |
| 6 | 影像学检查：口内X光（全口或牙科X光） |

### 牙周检查指标

| 指标 | 正常 | 异常 |
|------|------|------|
| 牙周袋深度 | 犬小于3mm，猫小于1mm | 犬大于3mm，猫大于1mm |
| 牙龈指数 | 0（正常） | 1-3（轻度至重度炎症） |
| 牙松动度 | 0（稳固） | 1-3（轻度至重度松动） |
| 牙菌斑指数 | 0（无） | 1-3（少量至大量） |
| 牙结石指数 | 0（无） | 1-3（少量至大量） |


## 常见牙科疾病

### 牙周病

| 项目 | 内容 |
|------|------|
| 病因 | 牙菌斑、牙结石、细菌感染 |
| 临床表现 | 口臭、牙龈红肿、牙周袋、牙松动、牙槽骨吸收 |
| 分级 | 1级（牙龈炎）、2级（早期牙周炎）、3级（中期牙周炎）、4级（晚期牙周炎） |
| 治疗 | 洁牙、抛光、牙周袋冲洗、拔牙（严重时） |
| 预防 | 定期洁牙、刷牙、牙科零食 |

### 牙吸收（猫）

| 项目 | 内容 |
|------|------|
| 病因 | 破牙细胞异常活跃，导致牙体组织吸收 |
| 临床表现 | 牙齿缺损、牙龈覆盖、疼痛、流涎、食欲下降 |
| 诊断 | 口内X光（可见牙根吸收） |
| 治疗 | 拔牙（首选）、牙冠修复（有限） |
| 预防 | 定期口腔检查、X光筛查 |

### 牙折

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、咬硬物 |
| 临床表现 | 牙冠缺损、牙髓暴露、疼痛、感染 |
| 分级 | 简单牙冠折、复杂牙冠折（牙髓暴露）、牙根折 |
| 治疗 | 牙髓治疗、根管治疗、拔牙 |
| 预防 | 避免咬硬物 |

### 口炎（猫）

| 项目 | 内容 |
|------|------|
| 病因 | 免疫介导、病毒（FCV或FIV）、牙菌斑 |
| 临床表现 | 口腔疼痛、流涎、口臭、食欲下降、牙龈红肿 |
| 诊断 | 口腔检查、活检、病毒检测 |
| 治疗 | 拔牙（全口或部分）、免疫抑制、止痛 |
| 预防 | 减少应激、控制病毒 |

### 口腔肿瘤

| 类型 | 临床表现 | 治疗 |
|------|---------|------|
| 鳞状细胞癌 | 口腔溃疡、肿块、颌骨破坏 | 手术切除、放疗 |
| 纤维肉瘤 | 口腔肿块、浸润性生长 | 手术切除、放疗 |
| 恶性黑色素瘤 | 口腔色素性肿块 | 手术切除、化疗 |
| 棘皮瘤 | 牙龈肿块、良性 | 手术切除 |

## 洁牙操作规范

### 洁牙步骤

| 步骤 | 操作 |
|------|------|
| 1 | 麻醉（气管插管，防止误吸） |
| 2 | 口腔检查（记录牙周袋深度、牙松动度） |
| 3 | 口内X光（全口或牙科X光） |
| 4 | 超声洁牙（去除牙结石） |
| 5 | 抛光（光滑牙面，减少菌斑附着） |
| 6 | 牙周袋冲洗（氯己定或盐水） |
| 7 | 涂氟（可选） |
| 8 | 记录和医嘱 |

### 洁牙注意事项

| 项目 | 说明 |
|------|------|
| 麻醉 | 必须气管插管，防止水和碎屑误吸 |
| 超声洁牙 | 避免在同一位置停留过久，防止牙体损伤 |
| 抛光 | 必须抛光，减少菌斑再附着 |
| 冲洗 | 牙周袋冲洗，减少细菌 |
| 术后 | 24小时内软食，避免硬物 |


## 拔牙技术

### 拔牙适应症

| 适应症 | 说明 |
|--------|------|
| 严重牙周病 | 牙松动、牙槽骨吸收 |
| 牙折 | 牙髓暴露、无法修复 |
| 牙吸收 | 猫牙吸收 |
| 根尖周脓肿 | 无法根管治疗 |
| 口腔肿瘤 | 肿瘤侵犯 |
| 乳牙滞留 | 影响恒牙萌出 |
| 咬合异常 | 影响口腔功能 |

### 拔牙步骤

| 步骤 | 操作 |
|------|------|
| 1 | 麻醉、X光评估 |
| 2 | 切开牙龈（牙周袋切开） |
| 3 | 分离牙周韧带（牙挺） |
| 4 | 拔除牙齿（拔牙钳） |
| 5 | 清理牙槽窝（去除碎片） |
| 6 | 缝合牙龈（可吸收线） |
| 7 | 术后X光确认 |

### 拔牙注意事项

| 项目 | 说明 |
|------|------|
| 多根牙 | 分根后分别拔除 |
| 牙根折断 | 尽量取出，避免残留 |
| 猫牙吸收 | 牙根可能完全吸收，需X光确认 |
| 缝合 | 可吸收线，减少二次麻醉 |
| 术后镇痛 | 阿片类加NSAID |


## 牙科麻醉要点

| 项目 | 说明 |
|------|------|
| 气管插管 | 必须带气囊插管，防止误吸 |
| 麻醉深度 | 适当加深，减少口腔操作反应 |
| 监测 | 心率、血压、SpO₂、EtCO₂ |
| 止痛 | 术前给予阿片类，术后给予NSAID |
| 局部麻醉 | 神经阻滞（上颌、下颌） |
| 苏醒 | 拔管前确保吞咽反射恢复 |


## 客户沟通要点

### 解释牙科治疗时
- 牙科疾病不仅影响口腔健康，还会影响心脏、肾脏等全身器官。
- 定期洁牙可以预防牙周病，减少牙齿脱落。
- 拔牙后动物仍然可以正常进食，不需要担心。

### 告知治疗风险时
- 牙科治疗需要麻醉，我们会做术前评估确保安全。
- 拔牙后可能出现轻微出血和肿胀，通常1-2天恢复。
- 如果出现持续出血、疼痛或食欲下降，请及时复诊。

### 出院指导
- 术后24小时内软食，避免硬物。
- 按医嘱给予止痛药和抗生素。
- 术后7-10天复查，确认愈合情况。
- 日常刷牙、使用牙科零食，预防牙周病。
