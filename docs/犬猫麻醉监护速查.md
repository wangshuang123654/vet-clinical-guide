## 麻醉前评估

### ASA分级

| 分级 | 状态 | 麻醉风险 |
|------|------|---------|
| ASA I | 健康动物，无系统性疾病 | 低 |
| ASA II | 轻度系统性疾病，不影响日常活动 | 低至中 |
| ASA III | 中度系统性疾病，影响日常活动 | 中 |
| ASA IV | 重度系统性疾病，威胁生命 | 高 |
| ASA V | 濒死状态，不手术无法存活 | 极高 |

### 术前检查清单

| 检查项目 | 目的 |
|---------|------|
| 血常规 | 评估贫血、感染、血小板 |
| 生化 | 评估肝肾功能、电解质、血糖 |
| 胸片 | 评估心肺状态（老年动物必查） |
| 心超 | 评估心脏功能（心脏病动物） |
| 血压 | 评估循环状态 |
| 心电图 | 评估心律 |
| 凝血功能 | 评估出血风险 |

## 麻醉维持

### 吸入麻醉

| 药物 | MAC（犬） | MAC（猫） | 特点 |
|------|----------|----------|------|
| 异氟烷 | 1.3% | 1.6% | 常用，心血管抑制较轻 |
| 七氟烷 | 2.1% | 2.6% | 诱导快、苏醒快 |
| 地氟烷 | 7.2% | 9.7% | 苏醒最快，但刺激气道 |

### 麻醉深度判断

| 麻醉深度 | 表现 | 处理 |
|---------|------|------|
| 过浅 | 眼睑反射存在、眼球运动、心率升高、血压升高、体动 | 加深麻醉 |
| 合适 | 眼睑反射消失、眼球居中、心率血压稳定、肌肉松弛 | 维持 |
| 过深 | 瞳孔散大、角膜反射消失、心率下降、血压下降、呼吸抑制 | 减浅麻醉，支持循环呼吸 |


## 术中监护指标

### 循环系统

| 指标 | 正常范围 | 异常处理 |
|------|---------|---------|
| 心率（犬） | 60-140次/分 | 升高：疼痛、浅麻醉；下降：深麻醉、低体温、高血钾 |
| 心率（猫） | 160-220次/分 | 同犬 |
| 血压（收缩压） | 100-150 mmHg | 低于90：输液、升压药；高于160：加深麻醉、降压 |
| 血压（平均压） | 70-110 mmHg | 低于60：立即处理 |
| CRT | 1-2秒 | 大于2秒：低血容量、心输出量下降 |
| 脉搏 | 强而规律 | 弱：低血容量；不规律：心律失常 |
| 黏膜颜色 | 粉红湿润 | 苍白：贫血、低灌注；发绀：缺氧 |

### 呼吸系统

| 指标 | 正常范围 | 异常处理 |
|------|---------|---------|
| 呼吸频率 | 10-30次/分 | 升高：疼痛、浅麻醉；下降：深麻醉、呼吸抑制 |
| SpO₂ | 大于等于95% | 低于95%：检查插管、供氧、吸痰 |
| EtCO₂ | 35-45 mmHg | 升高：通气不足；降低：过度通气、心输出量下降 |
| 潮气量 | 8-10 mL/kg | 不足：调整呼吸机参数 |

### 体温

| 指标 | 正常范围 | 异常处理 |
|------|---------|---------|
| 体温 | 37.5-39.0℃ | 低于37.5：复温；低于36：积极复温；高于39.5：排查恶性高热 |

### 麻醉深度

| 指标 | 正常表现 | 异常处理 |
|------|---------|---------|
| 眼睑反射 | 消失 | 存在：麻醉过浅 |
| 眼球位置 | 居中 | 偏转：麻醉过浅或过深 |
| 角膜反射 | 存在（浅麻醉）或消失（深麻醉） | 消失：麻醉过深 |
| 瞳孔 | 中等大小 | 散大：麻醉过深或疼痛 |
| 肌肉张力 | 松弛 | 紧张：麻醉过浅 |


## 术中常见并发症处理

| 并发症 | 表现 | 处理 |
|--------|------|------|
| 低血压 | 收缩压小于90 mmHg | 输液（晶体或胶体）、减浅麻醉、升压药（多巴胺） |
| 高血压 | 收缩压大于160 mmHg | 加深麻醉、镇痛、降压药（必要时） |
| 心动过缓 | 心率小于60次/分（犬） | 阿托品、减浅麻醉、排查高血钾 |
| 心动过速 | 心率大于160次/分（犬） | 加深麻醉、镇痛、排查低血容量 |
| 呼吸抑制 | 呼吸频率小于8次/分 | 辅助通气、减浅麻醉、纳洛酮（阿片类） |
| 低氧血症 | SpO₂小于90% | 检查插管、吸痰、提高氧浓度、PEEP |
| 高碳酸血症 | EtCO₂大于50 mmHg | 增加通气量、检查呼吸回路 |
| 低体温 | 体温小于37℃ | 复温（热风毯、加温输液） |
| 恶性高热 | 体温急剧升高、肌肉僵直 | 停止麻醉、降温、丹曲林 |
| 心律失常 | 心律不齐 | 评估原因、利多卡因（室性） |


## 苏醒期监护

### 苏醒期监测指标

| 指标 | 正常表现 | 异常处理 |
|------|---------|---------|
| 意识 | 逐步恢复 | 延迟苏醒：排查低体温、低血糖、麻醉过深 |
| 呼吸 | 自主呼吸恢复 | 呼吸抑制：辅助通气、纳洛酮 |
| 吞咽反射 | 恢复 | 未恢复：暂不拔管 |
| 体温 | 逐步恢复 | 低体温：复温 |
| 疼痛 | 无或轻度 | 中重度疼痛：给予镇痛药 |

### 拔管指征

| 指征 | 说明 |
|------|------|
| 吞咽反射恢复 | 能吞咽分泌物 |
| 自主呼吸恢复 | 呼吸频率和深度正常 |
| 意识恢复 | 有抬头动作 |
| SpO₂正常 | 大于等于95% |

## 客户沟通要点

### 解释麻醉风险时
- 麻醉前我们会做全面评估，包括血液检查、心肺检查，确保麻醉安全。
- 麻醉过程中我们会全程监测心率、血压、呼吸、体温等指标。
- 老年动物或有心肺疾病的动物，麻醉风险会相对较高，我们会制定个体化方案。

### 告知麻醉过程时
- 麻醉分为术前用药、诱导、维持、苏醒四个阶段。
- 术中我们会使用监护设备持续监测生命体征。
- 苏醒期我们会密切观察，直到动物完全清醒。

### 出院指导
- 麻醉后24小时内避免剧烈运动。
- 麻醉后可能出现轻微呕吐或食欲下降，通常1-2天恢复。
- 如果出现持续呕吐、精神萎靡或呼吸异常，立即复诊。
