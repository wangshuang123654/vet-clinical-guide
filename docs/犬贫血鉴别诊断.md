# 🐶 犬贫血鉴别诊断 · 临床思维导图

> 执业兽医师临床决策工具 | 更新日期：2026年9月3日


## 🔑 贫血快速鉴别三步法

| 步骤 | 判断 | 结论 |
|------|------|------|
| **第一步** | 网织红细胞↑ | → 再生性 → 走向失血/溶血 |
| | 网织红细胞不↑ | → 非再生性 → 走向骨髓/慢性病 |
| **第二步** | 有出血点/黑便/创伤 | → 失血 |
| （再生性） | 有黄疸/酱油色尿/红细胞凝集 | → 溶血 |
| **第三步** | BUN/Crea↑ | → 肾性贫血 |
| （非再生性） | 有长期炎症 | → 炎症性贫血 |
| | 全血细胞↓ | → 骨髓问题 |


## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 失血性贫血 | CBC、凝血功能（PT/APTT） | X光/B超排查出血点 |
| IMHA | 红细胞凝集、Coombs试验 | 血涂片、生化 |
| 巴贝斯虫/支原体 | 血涂片、PCR | 血清学检查 |
| 慢性肾病 | 生化（BUN/Crea/SDMA） | 尿检、B超 |
| 炎症性贫血 | CRP、血清铁、铁蛋白 | 排查原发病灶 |
| 骨髓疾病 | 全血细胞计数 | 骨髓穿刺、活检 |
| 营养性贫血 | 血清铁/B12/叶酸 | 问诊（饮食史） |
| 灭鼠药中毒 | PT/APTT | 详细问诊（接触史） |


## 🐾 客户沟通要点

### 接诊时
- "狗狗最近有没有出现虚弱、牙龈发白、或者精神变差的情况？"
- "有没有拉黑便、吐咖啡渣样的东西？"
- "最近有没有接触过洋葱、大蒜、灭鼠药？"
- "有没有被蜱虫叮咬过？有没有定期驱虫？"
- "有没有多饮多尿的情况？"

### 解释检查时
- "贫血不是一种病，是很多病的共同表现。我们要找到根源才能对症治疗。"
- "查网织红细胞，可以判断骨髓有没有在制造新的红细胞。"

### 告知风险时
- "贫血严重时（HCT < 20%）可能需要输血，输血前要做血型鉴定和交叉配血。"
- "免疫介导性溶血是自身免疫系统攻击自己的红细胞，需要吃免疫抑制剂。"
- "凝血功能障碍可能是吃了老鼠药，需要打维生素K₁。"

### 出院指导
- "按时服药，定期复查血常规。"
- "避免接触已知毒素（洋葱、大蒜、灭鼠药等）。"
- "如果出现虚弱加重、牙龈发白、呼吸急促，立即来医院。"


## 📌 用药参考（犬）

| 药物 | 剂量 | 用途 |
|------|------|------|
| 泼尼松龙 | 2-4 mg/kg PO SID | IMHA（免疫抑制） |
| 维生素K₁ | 2.5-5 mg/kg SC/IM | 灭鼠药中毒 |
| 奥美拉唑 | 0.7-1 mg/kg PO/IV SID | 胃溃疡止血 |
| 硫糖铝 | 0.5-1 g/犬 PO BID-TID | 胃黏膜保护剂 |
| 咪多卡 | 6.6 mg/kg IM | 巴贝斯虫 |
| 多西环素 | 5-10 mg/kg PO BID | 支原体 |
| EPO | 50-100 U/kg SC | 肾性贫血 |

> ⚠️ 用药前请结合患犬具体体重、肝肾功能及有无用药禁忌再执行。
