# 犬猫急诊超声速查

> 执业兽医师临床决策工具 | 快速扫查、关键切面、急诊决策 | 更新日期：2026年9月12日


## 急诊超声核心原则

| 原则 | 说明 |
|------|------|
| 快速 | 每个切面不超过1-2分钟，总扫查时间控制在5-10分钟内 |
| 聚焦 | 只关注急诊相关问题：有无积液、有无气胸、有无心包积液 |
| 重复 | 病情变化时重复扫查，动态评估 |
| 不干扰抢救 | 超声检查不应中断CPR或急救操作 |
| 结合临床 | 超声结果需结合病史、体检、化验综合判断 |


## 急诊超声标准切面

### 胸部快速扫查

#### 胸骨旁长轴切面

| 项目 | 内容 |
|------|------|
| 探头位置 | 右侧胸骨旁，第4-5肋间 |
| 观察内容 | 心脏形态、心包积液、心室收缩功能 |
| 正常表现 | 心脏结构清晰，无积液，心室壁运动协调 |
| 异常表现 | 心包积液、心室扩张、室壁运动减弱 |

#### 胸骨旁短轴切面

| 项目 | 内容 |
|------|------|
| 探头位置 | 右侧胸骨旁，第4-5肋间 |
| 观察内容 | 心室对称性、心室壁厚度、心腔大小 |
| 正常表现 | 左右心室对称，室壁厚度正常 |
| 异常表现 | 心室不对称、室壁增厚（HCM）、心腔扩张 |

#### 胸腔积液扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 两侧胸壁，第7-9肋间 |
| 观察内容 | 胸腔内有无无回声区（积液） |
| 正常表现 | 肺滑动征阳性，无积液 |
| 异常表现 | 无回声区、肺叶漂浮（胸腔积液） |

#### 肺滑动征

| 项目 | 内容 |
|------|------|
| 探头位置 | 两侧胸壁，第4-6肋间 |
| 观察内容 | 肺表面与胸壁的滑动 |
| 正常表现 | 肺滑动征阳性（肺随呼吸滑动） |
| 异常表现 | 肺滑动征消失（气胸） |

### 腹部快速扫查

#### 腹腔积液扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 腹部四个象限（右上、左上、右下、左下） |
| 观察内容 | 腹腔内有无无回声区（积液） |
| 正常表现 | 无积液 |
| 异常表现 | 无回声区、肠管漂浮（腹腔积液） |

#### 膀胱扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 腹中线，耻骨前缘 |
| 观察内容 | 膀胱充盈度、膀胱壁、有无结石 |
| 正常表现 | 膀胱壁光滑，无结石，无积液 |
| 异常表现 | 膀胱充盈、膀胱壁增厚、结石、血凝块 |

#### 肝胆扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 右侧肋弓下 |
| 观察内容 | 肝脏形态、回声、胆囊、胆管 |
| 正常表现 | 肝脏回声均匀，胆囊无扩张 |
| 异常表现 | 肝脏回声增强或减弱、胆囊扩张、胆泥、胆结石 |

#### 脾脏扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 左侧肋弓下 |
| 观察内容 | 脾脏形态、回声、有无结节 |
| 正常表现 | 脾脏回声均匀，无结节 |
| 异常表现 | 脾脏肿大、结节、团块（血管肉瘤） |

#### 胃肠道扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 腹中部 |
| 观察内容 | 胃壁、肠壁厚度、蠕动、有无异物 |
| 正常表现 | 胃壁厚度小于5mm，肠壁厚度小于4mm |
| 异常表现 | 胃壁或肠壁增厚、异物、肠套叠、肠梗阻 |

### 心脏快速扫查（急诊重点）

#### 心包积液扫查

| 项目 | 内容 |
|------|------|
| 探头位置 | 右侧胸骨旁，第4-5肋间 |
| 观察内容 | 心包腔内有无无回声区 |
| 正常表现 | 无心包积液 |
| 异常表现 | 心包腔内无回声区（心包积液） |

#### 左心房与主动脉比值（LA/Ao）

| 项目 | 内容 |
|------|------|
| 探头位置 | 右侧胸骨旁短轴切面 |
| 观察内容 | 左心房与主动脉直径比值 |
| 正常表现 | LA/Ao 小于1.5 |
| 异常表现 | LA/Ao 大于1.5（左心房增大，提示心衰） |


## 急诊超声快速决策流程

### 呼吸困难

呼吸困难
    |
    ▼
胸腔积液扫查
    ├── 有积液 -> 胸腔穿刺 -> 积液分析
    └── 无积液 -> 肺滑动征扫查
        ├── 肺滑动征消失 -> 气胸 -> 胸腔穿刺排气
        └── 肺滑动征阳性 -> 心脏扫查
            ├── 心包积液 -> 心包穿刺
            └── 无积液 -> 心超评估心功能

### 休克或低血压

休克或低血压
    |
    ▼
腹腔积液扫查
    ├── 有积液 -> 腹腔穿刺 -> 积液分析
    └── 无积液 -> 心脏扫查
        ├── 心包积液 -> 心包穿刺
        └── 无积液 -> 膀胱扫查
            ├── 膀胱充盈 -> 尿路梗阻 -> 导尿
            └── 膀胱空虚 -> 评估血容量 -> 输液试验

### 腹部疼痛

腹部疼痛
    |
    ▼
腹腔积液扫查
    ├── 有积液 -> 腹腔穿刺 -> 积液分析
    └── 无积液 -> 肝胆脾扫查
        ├── 脾脏异常 -> 脾脏病变（血管肉瘤、扭转）
        └── 肝胆异常 -> 肝胆病变（胆囊炎、胆结石）

### 创伤

创伤
    |
    ▼
腹腔积液扫查（FAST）
    ├── 有积液 -> 腹腔穿刺 -> 出血
    └── 无积液 -> 胸腔积液扫查
        ├── 有积液 -> 胸腔穿刺 -> 血胸
        └── 无积液 -> 肺滑动征扫查
            ├── 肺滑动征消失 -> 气胸 -> 胸腔穿刺排气
            └── 肺滑动征阳性 -> 心包积液扫查
                ├── 有心包积液 -> 心包穿刺
                └── 无心包积液 -> 继续监测


## 急诊超声操作规范

### 探头选择

| 检查部位 | 推荐探头 | 频率 |
|---------|---------|------|
| 心脏 | 相控阵探头 | 3-5 MHz |
| 腹部 | 凸阵探头 | 5-8 MHz |
| 胸腔 | 凸阵或相控阵探头 | 5-8 MHz |
| 浅表结构 | 线阵探头 | 8-12 MHz |

### 扫查技巧

| 技巧 | 说明 |
|------|------|
| 充分剃毛 | 急诊时可快速剃毛，减少干扰 |
| 耦合剂 | 使用足量耦合剂，确保图像清晰 |
| 多切面 | 每个器官至少扫查2个切面 |
| 动态观察 | 观察器官运动（心脏搏动、肠蠕动） |
| 对比扫查 | 左右对称扫查，对比异常 |

### 扫查时间控制

| 检查项目 | 时间限制 |
|---------|---------|
| 胸腔积液扫查 | 1分钟 |
| 腹腔积液扫查 | 1分钟 |
| 心包积液扫查 | 1分钟 |
| 膀胱扫查 | 1分钟 |
| 肝胆脾扫查 | 2-3分钟 |
| 总扫查时间 | 5-10分钟 |


## 急诊超声常见异常表现

| 异常表现 | 可能原因 | 临床意义 |
|---------|---------|---------|
| 胸腔无回声区 | 胸腔积液 | 心衰、FIP、脓胸、乳糜胸 |
| 腹腔无回声区 | 腹腔积液 | FIP、肝衰、低蛋白、出血 |
| 心包无回声区 | 心包积液 | 心包炎、心衰、肿瘤 |
| 肺滑动征消失 | 气胸 | 外伤、术后 |
| 膀胱充盈 | 尿路梗阻 | 结石、栓子、肿瘤 |
| 脾脏结节 | 脾脏肿瘤 | 血管肉瘤、肥大细胞瘤 |
| 胆囊扩张 | 胆道梗阻 | 胆结石、胆囊炎、胰腺炎 |
| 肠壁增厚 | 肠炎 | IBD、淋巴瘤、感染 |
| 胃壁增厚 | 胃炎 | 胃炎、肿瘤、溃疡 |
| 左心房增大 | 心衰 | HCM、二尖瓣病 |


## 急诊超声局限性

| 局限性 | 说明 |
|--------|------|
| 气体干扰 | 肠道气体、皮下气肿可干扰图像 |
| 肥胖动物 | 脂肪层厚，图像质量下降 |
| 操作者依赖 | 超声诊断依赖操作者经验 |
| 不能替代完整检查 | 急诊超声是快速筛查，不能替代完整超声检查 |
| 需结合临床 | 超声结果需结合病史、体检、化验综合判断 |


## 客户沟通要点

### 解释急诊超声时
- 急诊超声是快速检查，可以在几分钟内判断有无积液、气胸或心包积液。
- 检查过程无创，通常不需要镇静。

### 告知超声结果时
- 超声显示有胸腔积液，需要做胸腔穿刺，进一步确定积液性质。
- 超声显示心脏周围有积液，需要做心包穿刺，缓解心脏压迫。
- 超声显示膀胱充盈，可能存在尿路梗阻，需要导尿。

### 告知超声局限性时
- 急诊超声是快速筛查，如果发现问题，可能还需要进一步做完整超声检查。
- 超声结果需要结合其他检查综合判断。
