# 猫慢性肾病（CKD）管理速查

> 执业兽医师临床决策工具 | IRIS分期、管理方案、监测 | 更新日期：2026年9月15日


## 疾病概述

| 项目 | 内容 |
|------|------|
| 定义 | 肾脏结构或功能异常持续超过3个月 |
| 易感动物 | 老年猫（大于10岁高发） |
| 发病率 | 老年猫中约30-50% |
| 病因 | 年龄、遗传、感染、免疫介导、毒素 |
| 特点 | 不可逆、进行性、需长期管理 |


## IRIS分期

| 分级 | 血肌酐（mg/dL） | 临床意义 | 治疗重点 |
|------|----------------|---------|---------|
| 1级 | 小于1.6 | 肾功能正常，但有肾损伤证据 | 监测、去除病因 |
| 2级 | 1.6-2.8 | 轻度肾功能下降 | 饮食管理、监测 |
| 3级 | 2.9-5.0 | 中度肾功能下降 | 综合管理、补液 |
| 4级 | 大于5.0 | 重度肾功能下降 | 积极支持、姑息治疗 |

### 蛋白尿分级（UP/C）

| 分级 | UP/C | 临床意义 |
|------|------|---------|
| 非蛋白尿 | 小于0.2 | 正常 |
| 临界蛋白尿 | 0.2-0.4 | 需监测 |
| 蛋白尿 | 大于0.4 | 需治疗 |

### 血压分级

| 分级 | 收缩压（mmHg） | 临床意义 |
|------|---------------|---------|
| 正常 | 小于150 | 正常 |
| 临界 | 150-159 | 需监测 |
| 高血压 | 160-179 | 需治疗 |
| 严重高血压 | 大于等于180 | 需积极治疗 |


## 诊断要点

### 临床线索

| 线索 | 说明 |
|------|------|
| 多饮多尿 | 最早出现的症状 |
| 体重下降 | 进行性消瘦 |
| 食欲减退 | 晚期出现 |
| 口腔溃疡 | 尿毒症表现 |
| 被毛粗乱 | 营养状态下降 |
| 呕吐 | 尿毒症性胃炎 |
| 精神沉郁 | 晚期表现 |

### 实验室检查

| 检查 | 支持CKD的结果 |
|------|--------------|
| 生化 | BUN/Crea升高、SDMA升高、磷升高 |
| 尿检 | 尿比重下降（小于1.035）、蛋白尿 |
| 血常规 | 贫血（非再生性） |
| 电解质 | 钾降低、磷升高 |
| 血压 | 升高 |
| 超声 | 肾脏缩小、皮质回声增强、结构异常 |

### 诊断要点

| 步骤 | 内容 |
|------|------|
| 1 | 临床症状（多饮多尿、体重下降） |
| 2 | 生化（BUN/Crea升高、SDMA升高） |
| 3 | 尿检（尿比重下降、蛋白尿） |
| 4 | 血压测量 |
| 5 | 超声（肾脏形态） |
| 6 | IRIS分期 |


## 管理方案

### 饮食管理

| 项目 | 管理 |
|------|------|
| 处方粮 | 肾脏处方粮（限磷、限蛋白、补充Omega-3） |
| 磷限制 | 磷小于4.5 mg/dL（3级以下），小于5.0 mg/dL（4级） |
| 蛋白限制 | 优质蛋白，避免过量 |
| 钾补充 | 钾小于3.5 mEq/L时补充 |
| 水分 | 增加湿粮、流动水、多个水碗 |

### 补液

| 脱水程度 | 补液量 | 频率 |
|---------|--------|------|
| 轻度 | 50-100 mL/次 | 每周2-3次 |
| 中度 | 100-150 mL/次 | 每天或隔天 |
| 重度 | 150-200 mL/次 | 每天 |

> 皮下补液是CKD猫最常用的补液方式，可在家进行。

### 药物治疗

| 药物 | 剂量 | 用途 |
|------|------|------|
| 氨氯地平 | 0.125-0.25 mg/kg PO SID | 高血压 |
| 贝那普利 | 0.25-0.5 mg/kg PO SID | 蛋白尿 |
| 碳酸钙 | 按产品说明 | 磷结合剂 |
| 氢氧化铝 | 按产品说明 | 磷结合剂 |
| 钾补充剂 | 按产品说明 | 低钾血症 |
| EPO | 50-100 U/kg SC 每周2-3次 | 贫血 |
| 铁剂 | 按产品说明 | 贫血 |
| 马罗匹坦 | 1 mg/kg IV/SC SID | 止吐 |
| 米氮平 | 1.88 mg/猫 PO 隔日 | 促进食欲 |

### 并发症管理

| 并发症 | 管理 |
|--------|------|
| 高血压 | 氨氯地平 |
| 蛋白尿 | 贝那普利 |
| 贫血 | EPO、铁剂 |
| 高磷血症 | 磷结合剂、肾脏处方粮 |
| 低钾血症 | 钾补充剂 |
| 代谢性酸中毒 | 碳酸氢钠 |
| 呕吐 | 马罗匹坦 |
| 厌食 | 米氮平、食道饲管 |


## 监测与随访

### 监测频率

| 分期 | 监测频率 |
|------|---------|
| 1级 | 每6-12个月 |
| 2级 | 每3-6个月 |
| 3级 | 每2-3个月 |
| 4级 | 每1-2个月 |

### 监测项目

| 项目 | 目标 |
|------|------|
| 体重 | 稳定或增加 |
| 血肌酐 | 稳定或缓慢上升 |
| SDMA | 稳定或缓慢上升 |
| 磷 | 小于4.5 mg/dL |
| 钾 | 3.5-5.5 mEq/L |
| 血压 | 小于160 mmHg |
| UP/C | 小于0.4 |
| HCT | 大于25% |


## 预后因素

| 因素 | 预后良好 | 预后不良 |
|------|---------|---------|
| 分期 | 1-2级 | 3-4级 |
| 蛋白尿 | UP/C小于0.2 | UP/C大于0.4 |
| 血压 | 正常 | 严重高血压 |
| 贫血 | 无或轻度 | 中度至重度 |
| 体重 | 稳定 | 持续下降 |
| 食欲 | 正常 | 厌食 |


## 客户沟通要点

### 解释CKD时
- CKD是老年猫常见的慢性病，不可逆，但可以通过管理延缓进展。
- 早期发现、早期管理可以显著延长寿命。
- 饮食管理和补液是CKD管理的核心。

### 解释治疗方案时
- 肾脏处方粮是CKD管理的基础，需要长期坚持。
- 皮下补液可以在家进行，需要学习操作。
- 定期复查是调整治疗方案的关键。

### 出院指导
- 按医嘱用药，不要随意停药。
- 坚持肾脏处方粮，不要喂其他食物。
- 定期复查，监测肾功能和电解质。
- 如果出现厌食、呕吐、精神变差或抽搐，立即复诊。
