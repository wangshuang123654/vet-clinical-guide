# 猫甲状腺功能亢进速查

> 执业兽医师临床决策工具 | 诊断要点、治疗方案、监测 | 更新日期：2026年9月15日


## 疾病概述

| 项目 | 内容 |
|------|------|
| 病因 | 甲状腺腺瘤（多数良性，约95-98%） |
| 易感动物 | 中老年猫（大于8岁，高发年龄10-13岁） |
| 发病率 | 猫最常见的内分泌疾病之一 |
| 临床表现 | 多饮多尿、食欲亢进但体重下降、心悸、呕吐、腹泻 |


## 临床分型

| 类型 | 特点 |
|------|------|
| 单侧腺瘤 | 约70%，一侧甲状腺肿大 |
| 双侧腺瘤 | 约30%，两侧甲状腺肿大 |
| 甲状腺癌 | 约2-5%，恶性，侵袭性强 |


## 诊断要点

### 临床线索

| 线索 | 说明 |
|------|------|
| 食欲亢进 | 食欲明显增加，但体重持续下降 |
| 多饮多尿 | 继发于多尿 |
| 呕吐/腹泻 | 胃肠道蠕动加快 |
| 心悸/心动过速 | 心率大于240次/分 |
| 甲状腺肿大 | 颈部触诊可及 |
| 被毛粗乱 | 被毛油腻、不整洁 |
| 活动增加 | 烦躁、夜间嚎叫 |
| 体重下降 | 进行性消瘦 |

### 实验室检查

| 检查 | 支持甲亢的结果 |
|------|--------------|
| T4 | 升高（大于4.0 μg/dL） |
| fT4 | 升高 |
| TSH | 降低 |
| 血常规 | 红细胞增多、白细胞应激性变化 |
| 生化 | ALT/ALP升高、BUN/Crea可能降低 |
| 心电图 | 心动过速、心律失常 |

### 诊断要点

| 步骤 | 内容 |
|------|------|
| 1 | 临床症状（食欲亢进+体重下降+甲状腺肿大） |
| 2 | 触诊甲状腺（单侧或双侧肿大） |
| 3 | T4检测（大于4.0 μg/dL可确诊） |
| 4 | fT4检测（T4正常但高度怀疑时） |
| 5 | 甲状腺闪烁扫描（疑似异位甲状腺） |
| 6 | 心超、血压（评估心脏并发症） |

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|---------|
| 慢性肾病 | 多饮多尿，但食欲减退、体重下降 |
| 糖尿病 | 多饮多尿、食欲亢进，但血糖升高 |
| IBD | 呕吐腹泻，但食欲不定、体重下降 |
| 肿瘤 | 体重下降，但食欲减退 |


## 治疗方案

### 治疗方案选择

| 方案 | 优点 | 缺点 | 适用情况 |
|------|------|------|---------|
| 甲巯咪唑 | 方便、可逆、费用低 | 需终身用药、副作用 | 所有猫，尤其老年猫 |
| 放射性碘治疗 | 可治愈、一次治疗 | 需专科医院、费用高 | 年轻猫、无肾脏问题 |
| 手术切除 | 可治愈、费用中等 | 麻醉风险、可能损伤甲状旁腺 | 单侧腺瘤、无心脏问题 |
| 处方粮 | 无创 | 需严格饮食控制、效果有限 | 轻度甲亢、不能用药的猫 |

### 甲巯咪唑用药方案

| 项目 | 说明 |
|------|------|
| 起始剂量 | 2.5-5 mg/猫 PO BID |
| 调整剂量 | 根据T4水平调整，每2-4周 |
| 维持剂量 | 2.5-5 mg/猫 PO BID（个体化） |
| 给药方式 | 口服片剂、经皮凝胶 |
| 监测 | 用药后2-4周复查T4 |

### 放射性碘治疗

| 项目 | 说明 |
|------|------|
| 原理 | 放射性碘被甲状腺吸收，破坏腺瘤组织 |
| 适应症 | 无肾脏问题、可隔离的猫 |
| 疗效 | 约95%可治愈 |
| 副作用 | 甲状腺功能减退（需补充甲状腺素） |
| 隔离期 | 需住院隔离数天至数周 |

### 手术治疗

| 项目 | 说明 |
|------|------|
| 适应症 | 单侧腺瘤、无心脏问题 |
| 术前准备 | 甲巯咪唑控制甲状腺功能2-4周 |
| 并发症 | 甲状旁腺损伤（低钙）、喉返神经损伤 |
| 术后监测 | 血钙、T4 |


## 监测与随访

### 甲巯咪唑治疗监测

| 时间 | 监测项目 |
|------|---------|
| 用药前 | T4、血常规、生化、心电图 |
| 用药后2周 | T4、血常规、生化 |
| 用药后4周 | T4、血常规、生化 |
| 稳定后 | 每3-6个月复查T4、血常规、生化 |

### 甲巯咪唑副作用

| 副作用 | 发生率 | 处理 |
|--------|--------|------|
| 呕吐、厌食 | 约10-15% | 减量、换用经皮凝胶 |
| 嗜睡 | 约10% | 减量 |
| 血细胞减少 | 约5% | 停药、换方案 |
| 肝毒性 | 约5% | 停药、换方案 |
| 面部瘙痒 | 约5% | 换用经皮凝胶 |

### 放射性碘治疗后监测

| 时间 | 监测项目 |
|------|---------|
| 治疗后1个月 | T4 |
| 治疗后3个月 | T4 |
| 治疗后6个月 | T4 |
| 之后 | 每6个月复查T4 |


## 甲亢危象处理

| 项目 | 内容 |
|------|------|
| 诱因 | 应激、手术、感染 |
| 临床表现 | 高热、心动过速、烦躁、呕吐、腹泻 |
| 处理 | 甲巯咪唑、β受体阻滞剂（普萘洛尔）、补液、降温 |
| 预后 | 及时处理预后较好，延误可致死亡 |


## 并发症管理

| 并发症 | 管理 |
|--------|------|
| 肥厚型心肌病 | β受体阻滞剂、心超监测 |
| 高血压 | 氨氯地平 |
| 慢性肾病 | 甲亢控制后可能显现，需监测肾功能 |
| 视网膜病变 | 眼科检查、控制血压 |


## 客户沟通要点

### 解释甲亢时
- 甲亢是猫最常见的内分泌疾病，多数是良性腺瘤。
- 如果不治疗，会导致心脏问题、高血压、体重持续下降。
- 治疗方案有四种，需要根据猫的具体情况选择。

### 解释治疗方案时
- 甲巯咪唑：方便、可逆，但需终身用药，可能有副作用。
- 放射性碘：可治愈，但需要专科医院，费用较高。
- 手术：可治愈，但有麻醉风险和并发症。
- 处方粮：无创，但需要严格饮食控制。

### 出院指导
- 按时用药，不要随意停药。
- 定期复查T4和血常规。
- 如果出现呕吐、厌食、嗜睡或皮肤发黄，立即复诊。
- 控制应激，减少环境变化。
