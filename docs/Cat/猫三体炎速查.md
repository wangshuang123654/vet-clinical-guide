# 猫三体炎速查

> 执业兽医师临床决策工具 | 胆管肝炎、胰腺炎、IBD三联诊疗 | 更新日期：2026年9月15日


## 疾病概述

| 项目 | 内容 |
|------|------|
| 定义 | 猫胆管肝炎、胰腺炎、炎性肠病（IBD）三者同时发生 |
| 解剖基础 | 猫的胆管和胰管共同开口于十二指肠，炎症容易相互蔓延 |
| 易感动物 | 中老年猫 |
| 特点 | 三者互为因果，形成恶性循环，需综合治疗 |


## 三体炎之间的关系

| 关系 | 说明 |
|------|------|
| 胆管肝炎→胰腺炎 | 胆管炎症蔓延至胰腺 |
| 胰腺炎→IBD | 胰腺炎症影响肠道 |
| IBD→胆管肝炎 | 肠道细菌上行感染胆管 |
| 三者互相影响 | 形成恶性循环，需同时治疗 |


## 诊断要点

### 临床线索

| 线索 | 说明 |
|------|------|
| 黄疸 | 胆管肝炎的表现 |
| 发热 | 炎症反应 |
| 腹痛 | 胰腺炎、胆管肝炎 |
| 呕吐 | 胰腺炎、IBD |
| 腹泻 | IBD |
| 食欲下降 | 三者共有 |
| 体重下降 | 慢性病程 |


### 实验室检查

| 检查 | 支持三体炎的结果 |
|------|----------------|
| 生化 | ALT/AST升高、ALP升高、胆红素升高 |
| fPL | 升高（胰腺炎） |
| 血常规 | 白细胞升高或降低、淋巴细胞减少 |
| 球蛋白 | 升高 |
| B超 | 胆管扩张、胰腺肿大、肠壁增厚 |
| 胆汁培养 | 细菌阳性 |


### 诊断标准

| 疾病 | 诊断依据 |
|------|---------|
| 胆管肝炎 | ALT/AST升高、胆红素升高、B超胆管异常、胆汁培养阳性 |
| 胰腺炎 | fPL升高、B超胰腺肿大 |
| IBD | 慢性呕吐腹泻、B超肠壁增厚、活检 |


## 治疗方案

### 综合治疗原则

| 原则 | 说明 |
|------|------|
| 同时治疗 | 三者需同时治疗，不能只治一个 |
| 抗生素 | 覆盖肠道细菌（胆管肝炎） |
| 免疫抑制 | 控制IBD和胰腺炎 |
| 保肝 | 保护肝功能 |
| 营养支持 | 早期营养支持是关键 |
| 对症支持 | 止吐、止痛、补液 |

### 抗生素治疗

| 药物 | 剂量 | 用途 |
|------|------|------|
| 阿莫西林克拉维酸钾 | 12.5-25 mg/kg PO BID | 胆管肝炎 |
| 甲硝唑 | 10-15 mg/kg PO BID | 厌氧菌 |
| 恩诺沙星 | 5 mg/kg PO SID | 革兰阴性菌 |
| 头孢曲松 | 20-30 mg/kg IV/SC SID | 严重感染 |

> 抗生素疗程通常4-6周，根据胆汁培养和药敏调整。

### 免疫抑制治疗

| 药物 | 剂量 | 用途 |
|------|------|------|
| 泼尼松龙 | 1-2 mg/kg PO SID | IBD、胰腺炎 |
| 布地奈德 | 1-2 mg/猫 PO SID | IBD（局部作用） |
| 环孢素 | 5 mg/kg PO SID | IBD |
| 苯丁酸氮芥 | 2-4 mg/m² PO 每2周 | 难治性IBD |

### 保肝治疗

| 药物 | 剂量 | 用途 |
|------|------|------|
| SAMe | 20-40 mg/kg PO SID | 保肝 |
| 水飞蓟 | 20-50 mg/kg PO SID | 抗氧化 |
| 熊去氧胆酸 | 10-15 mg/kg PO SID | 利胆 |
| 维生素E | 10-20 IU/kg PO SID | 抗氧化 |

### 对症支持

| 症状 | 处理 |
|------|------|
| 呕吐 | 马罗匹坦 1 mg/kg IV/SC SID |
| 腹痛 | 丁丙诺啡 0.01-0.03 mg/kg IV/SC |
| 脱水 | 补液（LRS或0.9% NaCl） |
| 厌食 | 米氮平 1.88 mg/猫 PO 隔日 |
| 营养支持 | 食道饲管、鼻饲管 |
| 低钾 | 补钾 |
| 低蛋白 | 胶体液 |

### 饮食管理

| 方案 | 说明 |
|------|------|
| 低敏粮 | 水解蛋白或新型蛋白 |
| 低脂粮 | 胰腺炎管理 |
| 易消化 | 减少胃肠道负担 |
| 少量多餐 | 减少胰腺刺激 |
| 食道饲管 | 厌食猫的营养支持 |


## 监测与随访

### 监测项目

| 项目 | 频率 | 目标 |
|------|------|------|
| 体重 | 每周 | 稳定或增加 |
| 生化 | 每2-4周 | ALT/AST/胆红素下降 |
| fPL | 每2-4周 | 下降 |
| 血常规 | 每2-4周 | 白细胞正常 |
| B超 | 每4-8周 | 胆管、胰腺、肠道改善 |
| 食欲 | 每天 | 恢复 |

### 治疗调整

| 情况 | 调整 |
|------|------|
| ALT/AST下降 | 继续保肝治疗 |
| 胆红素下降 | 继续抗生素 |
| fPL下降 | 继续免疫抑制 |
| 呕吐腹泻改善 | 继续IBD治疗 |
| 症状无改善 | 调整方案、重新评估 |


## 预后因素

| 因素 | 预后良好 | 预后不良 |
|------|---------|---------|
| 早期诊断 | 是 | 否 |
| 及时治疗 | 是 | 否 |
| 营养支持 | 早期 | 晚期 |
| 黄疸程度 | 轻度 | 重度 |
| 胰腺炎严重度 | 轻度 | 重度 |
| 治疗依从性 | 好 | 差 |


## 客户沟通要点

### 解释三体炎时
- 三体炎是胆管肝炎、胰腺炎和IBD同时发生，三者互相影响。
- 需要同时治疗三种疾病，不能只治一个。
- 治疗周期较长，需要耐心和坚持。

### 解释治疗方案时
- 抗生素控制胆管感染。
- 免疫抑制控制IBD和胰腺炎。
- 保肝药物保护肝功能。
- 营养支持是治疗的关键，厌食猫需要食道饲管。

### 出院指导
- 按时用药，不要随意停药。
- 坚持饮食管理，低敏低脂。
- 定期复查，监测生化指标。
- 如果出现黄疸加重、呕吐、腹痛或厌食，立即复诊。
