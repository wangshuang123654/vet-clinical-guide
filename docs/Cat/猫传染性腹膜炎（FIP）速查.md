# 猫传染性腹膜炎（FIP）速查

> 执业兽医师临床决策工具 | 诊断要点、GS-441524治疗方案、监测 | 更新日期：2026年9月15日


## 疾病概述

| 项目 | 内容 |
|------|------|
| 病原 | 猫冠状病毒（FCoV）突变株 |
| 易感动物 | 幼猫（小于2岁）、老年猫、免疫抑制猫 |
| 传播途径 | 粪-口传播（冠状病毒），突变后发病 |
| 潜伏期 | 数周至数月 |
| 发病率 | 群养猫中约5-10%的冠状病毒携带猫会发展为FIP |


## 临床分型

| 类型 | 主要表现 | 常见症状 |
|------|---------|---------|
| 湿性（渗出型） | 体腔积液 | 胸腔积液、腹腔积液、呼吸困难、腹部膨大 |
| 干性（非渗出型） | 肉芽肿性病变 | 发热、体重下降、神经症状、眼部病变、腹腔肿块 |
| 混合型 | 两者兼有 | 以上症状可同时出现 |


## 诊断要点

### 临床线索（符合越多越可疑）

| 线索 | 说明 |
|------|------|
| 发热 | 大于39.5℃，顽固不退，抗生素无效 |
| 淋巴细胞减少 | 小于1.0×10⁹/L |
| 白球比（A/G） | 小于0.8（高度怀疑），小于0.6（高度提示） |
| 球蛋白升高 | 大于5.0 g/dL |
| SAA/CRP升高 | 炎症标志物显著升高 |
| 冠状病毒PCR | 可阴性（FIP是突变株，PCR不一定能抓到） |
| 抗生素治疗无效 | 发热持续 |

### 实验室检查

| 检查 | 支持FIP的结果 |
|------|--------------|
| 血常规 | 淋巴细胞减少、中性粒细胞正常或轻度升高 |
| 生化 | 球蛋白升高、白蛋白降低、A/G小于0.8、胆红素升高 |
| 积液分析 | 渗出液（蛋白高、细胞少）、RT-PCR阳性 |
| 超声 | 髓质环征、淋巴结肿大、少量积液、肉芽肿 |
| 眼部检查 | 葡萄膜炎、角膜后沉着物 |

### 确诊手段

| 方法 | 敏感度 | 说明 |
|------|--------|------|
| 积液RT-PCR | 高 | 金标准（湿性FIP） |
| 组织活检 | 高 | 肉芽肿性炎症（干性FIP） |
| 免疫组化 | 高 | 组织内病毒抗原 |
| 白球比 | 中 | 筛查指标 |
| 超声 | 中 | 辅助诊断 |


## GS-441524治疗方案

### 剂量方案

| FIP类型 | 剂量 | 给药途径 | 频率 |
|---------|------|---------|------|
| 湿性FIP | 4-6 mg/kg | SC | SID |
| 干性FIP | 6-8 mg/kg | SC | SID |
| 神经型FIP | 8-10 mg/kg | SC | SID |
| 眼部FIP | 8-10 mg/kg | SC | SID |

### 疗程

| 阶段 | 时间 | 说明 |
|------|------|------|
| 诱导期 | 至少12周 | 持续用药，不可中断 |
| 巩固期 | 12周后评估 | 根据白球比、球蛋白、症状决定是否停药 |
| 停药标准 | 白球比正常、球蛋白正常、症状消失、持续2-4周 | 需综合评估 |

### 监测指标

| 指标 | 频率 | 目标 |
|------|------|------|
| 体重 | 每周 | 稳定或增加 |
| 白球比 | 每2-4周 | 逐渐升高至正常 |
| 球蛋白 | 每2-4周 | 逐渐下降至正常 |
| 血常规 | 每2-4周 | 淋巴细胞恢复正常 |
| 超声 | 每4-8周 | 积液减少、淋巴结缩小 |
| 神经症状 | 每次复查 | 逐渐改善 |

### 停药后随访

| 时间 | 监测 |
|------|------|
| 停药后1个月 | 白球比、球蛋白、血常规 |
| 停药后3个月 | 白球比、球蛋白、血常规、超声 |
| 停药后6个月 | 全面复查 |
| 停药后12个月 | 全面复查 |


## 支持治疗

| 项目 | 处理 |
|------|------|
| 积液 | 胸腔穿刺、腹腔穿刺（缓解呼吸困难） |
| 发热 | 物理降温、退热药（慎用NSAIDs） |
| 厌食 | 米氮平、食道饲管 |
| 脱水 | 补液 |
| 神经症状 | 甘露醇、糖皮质激素 |
| 眼部病变 | 局部糖皮质激素、散瞳 |
| 继发感染 | 抗生素 |


## 预后因素

| 因素 | 预后良好 | 预后不良 |
|------|---------|---------|
| 年龄 | 年轻猫 | 老年猫 |
| 分型 | 湿性FIP | 神经型FIP |
| 白球比 | 大于0.6 | 小于0.4 |
| 球蛋白 | 小于6.0 g/dL | 大于8.0 g/dL |
| 治疗时机 | 早期治疗 | 晚期治疗 |
| 治疗依从性 | 按时用药 | 中断用药 |


## 鉴别诊断

| 疾病 | 鉴别要点 |
|------|---------|
| 细菌性腹膜炎 | 积液涂片可见细菌、培养阳性 |
| 心源性积液 | 心超可见心脏病变、NT-proBNP升高 |
| 肿瘤性积液 | 积液细胞学可见肿瘤细胞 |
| 低蛋白性积液 | 白蛋白极低、无发热 |
| 脓胸 | 积液脓性、细菌培养阳性 |


## 客户沟通要点

### 解释FIP时
- FIP是猫冠状病毒突变引起的，不是所有冠状病毒都会变成FIP。
- FIP过去被认为是不治之症，现在GS-441524可以治愈。
- 治疗需要持续12周以上，不能中断。
- 治疗费用较高，需要提前告知。

### 告知治疗方案时
- GS-441524需要每天皮下注射，持续12周以上。
- 治疗期间需要定期复查白球比、球蛋白和超声。
- 停药后仍需随访，防止复发。
- 神经型FIP治疗难度更大，预后相对较差。

### 出院指导
- 按时用药，不要中断。
- 定期复查，监测白球比和球蛋白。
- 如果出现神经症状或呼吸困难，立即复诊。
- 减少应激，避免群养。
