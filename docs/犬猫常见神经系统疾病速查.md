## 神经系统检查基础

### 神经学检查流程

| 步骤 | 内容 |
|------|------|
| 1 | 意识状态评估 |
| 2 | 姿势和步态观察 |
| 3 | 颅神经检查（I-XII） |
| 4 | 脊髓反射检查 |
| 5 | 痛觉检查（深痛、浅痛） |
| 6 | 触诊（脊柱、肌肉） |
| 7 | 神经定位 |

### 神经定位分级

| 定位 | 病变部位 | 常见疾病 |
|------|---------|---------|
| 前脑 | 大脑 | 肿瘤、炎症、中毒 |
| 脑干 | 中脑、脑桥、延髓 | 肿瘤、炎症、血管 |
| 小脑 | 小脑 | 发育异常、炎症 |
| C1-C5 | 颈部脊髓 | IVDD、骨折、肿瘤 |
| C6-T2 | 颈胸段脊髓 | IVDD、骨折、肿瘤 |
| T3-L3 | 胸腰段脊髓 | IVDD、骨折、肿瘤 |
| L4-S3 | 腰骶段脊髓 | IVDD、骨折、肿瘤 |
| 外周神经 | 神经根、神经 | 多发性神经病 |
| 神经肌肉 | 神经肌肉接头 | 重症肌无力 |


## 常见神经系统疾病

### 癫痫

| 项目 | 内容 |
|------|------|
| 病因 | 特发性、结构性（肿瘤、炎症）、代谢性 |
| 临床表现 | 全身性抽搐、意识丧失、流涎、尿失禁 |
| 诊断 | 病史、体检、血常规、生化、MRI |
| 治疗 | 苯巴比妥、溴化钾、左乙拉西坦 |
| 监测 | 血药浓度、发作频率 |
| 预后 | 多数可控制，部分难治性 |

### 椎间盘疾病（IVDD）

| 项目 | 内容 |
|------|------|
| 病因 | 椎间盘退变、突出 |
| 临床表现 | 背痛、后肢无力、瘫痪、尿失禁 |
| 诊断 | 神经学检查、X光、MRI |
| 治疗 | 保守（笼养、止痛）、手术（减压） |
| 预后 | 取决于神经损伤程度 |

### 前庭综合征

| 项目 | 内容 |
|------|------|
| 病因 | 外周性（中耳炎、特发性）、中枢性（肿瘤、炎症） |
| 临床表现 | 斜头、眼球震颤、转圈、跌倒 |
| 诊断 | 神经学检查、X光、MRI |
| 治疗 | 对症支持、治疗原发病 |
| 预后 | 外周性多数可恢复，中枢性取决于原发病 |

### 脊髓损伤

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、骨折、脱位、FCE |
| 临床表现 | 瘫痪、感觉丧失、尿失禁 |
| 诊断 | 神经学检查、X光、MRI |
| 治疗 | 固定、手术、康复 |
| 预后 | 取决于损伤程度和及时性 |

### 脑炎

| 项目 | 内容 |
|------|------|
| 病因 | 感染（病毒、细菌、真菌）、免疫介导 |
| 临床表现 | 抽搐、意识改变、转圈、行为异常 |
| 诊断 | MRI、脑脊液分析 |
| 治疗 | 免疫抑制、抗感染 |
| 预后 | 取决于病因和严重程度 |

### 脑肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 原发性或转移性 |
| 临床表现 | 抽搐、行为改变、转圈、偏瘫 |
| 诊断 | MRI、CT、活检 |
| 治疗 | 手术、放疗、化疗 |
| 预后 | 取决于肿瘤类型和位置 |

### 重症肌无力

| 项目 | 内容 |
|------|------|
| 病因 | 自身抗体攻击乙酰胆碱受体 |
| 临床表现 | 运动不耐受、巨食道、吞咽困难 |
| 诊断 | 乙酰胆碱受体抗体、腾喜龙试验 |
| 治疗 | 吡啶斯的明、免疫抑制 |
| 预后 | 多数可控制，部分可缓解 |


## 神经系统急诊处理

| 情况 | 处理 |
|------|------|
| 癫痫持续状态 | 地西泮、苯巴比妥、补液 |
| 急性瘫痪 | 固定、止痛、MRI |
| 颅内压升高 | 甘露醇、糖皮质激素 |
| 脊髓损伤 | 固定、手术 |
| 前庭危象 | 对症支持、止吐 |
| 重症肌无力危象 | 吡啶斯的明、呼吸支持 |

## 客户沟通要点

### 解释神经系统疾病时
- 神经系统疾病诊断需要MRI或CT，才能确定病变位置和性质。
- 神经系统疾病治疗周期长，需要耐心和坚持。
- 部分神经系统疾病可能无法完全恢复，需要长期管理。

### 出院指导
- 按医嘱用药，不要随意停药。
- 定期复查，监测病情变化。
- 康复训练是神经系统疾病管理的重要部分。
- 如果出现症状加重或新症状，立即复诊。
