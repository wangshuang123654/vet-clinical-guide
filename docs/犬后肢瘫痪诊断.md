# 🐶 犬后肢瘫痪鉴别诊断 · 临床思维导图

> 执业兽医师临床决策工具 | ⚠️ 急症提示：突发瘫痪伴剧烈疼痛——尤其腊肠/京巴等品种——必须立刻排查IVDD，手术窗口期极短 | 更新日期：2026年9月3日


## 🚨 瘫痪快速定位流程图

| 步骤 | 判断 | 结论 |
|------|------|------|
| **第一步** | 有外伤史 | → 骨折/脱位/脊柱骨折 |
| | 无外伤史 | → 进入第二步 |
| **第二步** | 有疼痛（触诊脊柱/按压背侧） | → IVDD > 椎间盘炎 > 肿瘤 |
| | 无疼痛 | → 进入第三步 |
| **第三步** | 数分钟内发病 | → FCE |
| | 数小时/天 | → IVDD早期 / 蜱瘫痪 |
| | 数周/月 | → DM / 肿瘤 / 多发性神经病 |
| **第四步** | 有系统症状（发热/多饮/呕吐） | → 椎间盘炎 / 艾迪森 / 代谢性 |
| | 无系统症状 | → 继续神经定位 |


## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| IVDD | 神经学检查、X光（脊柱） | MRI/CT（首选影像） |
| FCE | MRI（排除IVDD后） | 神经学检查、脑脊液分析 |
| 椎体骨折/脱位 | X光（脊柱）、神经学检查 | CT、MRI |
| 椎间盘炎/椎体骨髓炎 | X光、血常规/生化 | MRI、血培养 |
| 脊柱肿瘤 | X光、MRI/CT | 活检、脑脊液分析 |
| 退行性脊髓病（DM） | 神经学检查、遗传检测 | MRI（排除其他） |
| 多发性神经病 | 肌电图、神经传导 | 神经肌肉活检 |
| 重症肌无力 | 乙酰胆碱受体抗体检测 | 腾喜龙试验 |
| 髋关节发育不良/脱位 | X光（髋关节） | CT、关节镜检查 |
| 十字韧带断裂 | 抽屉试验、X光 | MRI/关节镜 |
| 股骨头坏死 | X光（髋关节） | CT |
| 骨折/骨肿瘤 | X光 | CT、活检 |
| 低血糖/低钾血症 | 血糖、电解质 | 胰岛素检测（低血糖时） |
| 艾迪森危象 | 电解质（血钾↑/血钠↓） | ACTH刺激试验 |
| 蜱瘫痪 | 仔细全身排查蜱虫 | 支持治疗观察反应 |


## 🐾 客户沟通要点

### 接诊时
- "后肢瘫痪是突然发生的还是慢慢加重的？有没有摔倒或外伤史？"
- "触摸狗狗的背部或颈部时，它有没有疼痛反应？"
- "除了后肢站不起来，精神、食欲、大小便情况怎么样？"
- "有没有接触到蜱虫？最近有没有外出活动？"

### 解释检查和方案
- "IVDD在腊肠、京巴这类品种中非常常见，需要做MRI才能确定椎间盘突出的具体位置和程度。"
- "FCE的典型表现——突然就站不起来了，但没有明显疼痛。"
- "退行性脊髓病在德牧中很常见，它不疼但会慢慢加重，目前没有特效药，重点是康复和支持。"

### 告知风险和预后
- "IVDD预后取决于神经损伤的等级——1-2级保守治疗往往有效，4-5级（深痛消失）则需要尽快手术。"
- "FCE大多数能在数周到数月内部分恢复，但很少能完全恢复。"
- "DM的病程通常较长，但最终会影响行走、排尿和排便，需要提前做好心理和生活准备。"

### 出院指导
- "严格笼养，限制活动范围，避免上下楼梯和跳跃。"
- "注意排尿和排便情况，如果尿闭超过12小时，需立即来医院处理。"
- "定期复查神经学状态和影像学变化。"
- "如果出现疼痛加重、瘫痪程度加重或大小便失禁，立即来医院。"
