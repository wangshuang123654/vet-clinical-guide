# 犬猫输血疗法速查

> 执业兽医师临床决策工具 | 血型、配血、输血速度、反应处理 | 更新日期：2026年9月12日


## 犬猫血型系统

### 犬血型系统（DEA）

| 血型 | 抗原 | 临床意义 |
|------|------|---------|
| DEA 1.1 | A1抗原 | 最强免疫原性，输血前必须配型 |
| DEA 1.2 | A2抗原 | 较弱免疫原性 |
| DEA 3 | B抗原 | 可产生同种抗体 |
| DEA 4 | C抗原 | 大多数犬为阳性，免疫原性弱 |
| DEA 5 | D抗原 | 可产生同种抗体 |
| DEA 6 | F抗原 | 免疫原性弱 |
| DEA 7 | G抗原 | 可产生同种抗体 |
| DEA 8 | H抗原 | 免疫原性弱 |

**犬输血原则：**
- DEA 1.1阴性犬是理想供血犬
- 首次输血前必须做DEA 1.1配型
- 首次输血可不做交叉配血，但再次输血必须做交叉配血
- DEA 1.1阴性犬接受DEA 1.1阳性血后，可产生抗DEA 1.1抗体，再次输血可致严重溶血反应

### 猫血型系统（AB）

| 血型 | 抗原 | 临床意义 |
|------|------|---------|
| A型 | A抗原 | 最常见（约95%以上） |
| B型 | B抗原 | 较少见，某些品种高发（如布偶猫、英国短毛猫） |
| AB型 | A和B抗原 | 极罕见 |

**猫输血原则：**
- A型猫有抗B抗体（弱），B型猫有抗A抗体（强）
- B型猫接受A型血可致严重溶血反应，甚至致死
- 输血前必须做血型鉴定和交叉配血
- 猫首次输血也必须配型


## 供血犬猫选择标准

| 项目 | 犬 | 猫 |
|------|-------|-------|
| 体重 | 大于20kg | 大于4kg |
| 年龄 | 1-8岁 | 1-8岁 |
| 健康状况 | 健康，无传染病 | 健康，无传染病 |
| 疫苗接种 | 已完成核心疫苗 | 已完成核心疫苗 |
| 血型 | DEA 1.1阴性 | A型（理想） |
| PCV | 大于40% | 大于30% |
| 献血间隔 | 每3个月一次 | 每3个月一次 |
| 献血量 | 10-15 mL/kg | 8-10 mL/kg |


## 输血前检查

### 血型鉴定

| 方法 | 说明 |
|------|------|
| 快速检测板 | 快速、简便，适用于急诊 |
| 实验室血型鉴定 | 更准确，适用于复杂病例 |
| 基因检测 | 确定血型基因型，适用于育种 |

### 交叉配血

| 方法 | 说明 |
|------|------|
| 主侧配血 | 供血红细胞加受血血清 |
| 副侧配血 | 受血红细胞加供血血清 |
| 结果判读 | 无凝集、无溶血为配血相合 |


## 输血速度与剂量

### 输血剂量

| 动物 | 输血量 | 预期效果 |
|------|--------|---------|
| 犬 | 10-20 mL/kg | 提高PCV约10% |
| 猫 | 10-15 mL/kg | 提高PCV约10% |

### 输血速度

| 阶段 | 速度 | 说明 |
|------|------|------|
| 前15分钟 | 0.5-1 mL/kg/h | 观察有无输血反应 |
| 15-30分钟 | 2-5 mL/kg/h | 逐步加快 |
| 30分钟后 | 5-10 mL/kg/h | 维持速度 |
| 心衰动物 | 1-2 mL/kg/h | 减慢速度，监测呼吸 |
| 休克动物 | 5-10 mL/kg/h | 可适当加快 |

### 输血时间限制

| 项目 | 要求 |
|------|------|
| 开始输血 | 血液取出后30分钟内开始 |
| 输血完成 | 4小时内输完 |
| 血液保存 | 犬：1-6℃保存21-35天；猫：1-6℃保存21-30天 |


## 输血反应识别与处理

### 急性输血反应

| 类型 | 表现 | 处理 |
|------|------|------|
| 溶血反应 | 发热、寒战、血红蛋白尿、低血压、休克 | 立即停止输血、输液、利尿、抗休克 |
| 过敏反应 | 荨麻疹、面部水肿、瘙痒、呼吸困难 | 停止输血、抗组胺药、糖皮质激素 |
| 发热反应 | 体温升高、寒战 | 停止输血、退热、抗组胺药 |
| 细菌污染 | 高热、寒战、休克 | 停止输血、抗生素、抗休克 |
| 循环过负荷 | 呼吸急促、肺水肿、咳嗽 | 停止输血、利尿、吸氧 |

### 迟发性输血反应

| 类型 | 表现 | 处理 |
|------|------|------|
| 迟发性溶血 | 输血后数天出现黄疸、贫血 | 支持治疗、监测血常规 |
| 输血相关急性肺损伤 | 输血后数小时出现呼吸窘迫 | 吸氧、机械通气 |
| 传染病传播 | 输血后数周出现相应症状 | 对症治疗 |


## 输血操作规范

### 输血前准备

| 步骤 | 操作 |
|------|------|
| 1 | 确认血型鉴定和交叉配血结果 |
| 2 | 检查血袋：有无溶血、凝块、变色 |
| 3 | 准备输血器（带滤网） |
| 4 | 建立静脉通路（留置针） |
| 5 | 准备抢救药物（肾上腺素、地塞米松） |

### 输血中监测

| 时间 | 监测项目 |
|------|---------|
| 输血前 | 体温、心率、呼吸、血压、PCV |
| 输血后15分钟 | 体温、心率、呼吸、血压 |
| 输血后30分钟 | 体温、心率、呼吸、血压 |
| 输血后1小时 | 体温、心率、呼吸、血压、PCV |
| 输血后4小时 | 体温、心率、呼吸、血压、PCV |
| 输血后24小时 | 体温、心率、呼吸、血压、PCV |

### 输血后护理

| 项目 | 说明 |
|------|------|
| 监测 | 继续监测生命体征24小时 |
| 复查 | 输血后24小时复查PCV |
| 记录 | 记录输血量、输血反应、处理措施 |
| 补液 | 必要时继续输液支持 |


## 输血替代方案

| 方案 | 适用情况 | 说明 |
|------|---------|------|
| 晶体液 | 轻度贫血、血容量不足 | 补充血容量，不提高携氧能力 |
| 胶体液 | 低蛋白血症、休克 | 扩充血容量，维持胶体渗透压 |
| 促红细胞生成素 | 慢性肾性贫血 | 刺激红细胞生成 |
| 铁剂 | 缺铁性贫血 | 补充铁元素 |
| 维生素B12 | B12缺乏性贫血 | 补充B12 |


## 客户沟通要点

### 解释输血必要性时
- 输血是抢救严重贫血或失血动物的必要手段，可以快速补充红细胞，改善携氧能力。
- 输血前需要做血型鉴定和交叉配血，确保输血安全。

### 告知输血风险时
- 输血可能出现过敏反应、发热反应或溶血反应，我们会密切监测。
- 输血有传播传染病的风险，但正规血源经过严格筛查，风险很低。

### 出院指导
- 输血后24小时内避免剧烈运动。
- 如果出现发热、黄疸、精神变差或呼吸困难，立即复诊。
- 输血后1周复查血常规，评估治疗效果。
