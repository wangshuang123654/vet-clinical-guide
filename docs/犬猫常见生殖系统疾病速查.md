# 犬猫常见生殖系统疾病速查

## 母犬猫常见生殖系统疾病

### 子宫蓄脓

| 项目 | 内容 |
|------|------|
| 病因 | 发情后黄体期孕酮升高、细菌感染 |
| 临床表现 | 多饮多尿、呕吐、腹部膨大、阴道分泌物（开放型）、精神沉郁 |
| 诊断 | 血常规（白细胞升高）、B超（子宫积液）、X光 |
| 治疗 | 手术（卵巢子宫切除）、抗生素、补液 |
| 预后 | 及时手术预后良好，延误可致败血症 |

### 难产

| 项目 | 内容 |
|------|------|
| 病因 | 胎儿过大、胎位异常、产道狭窄、子宫收缩无力 |
| 临床表现 | 努责超过30分钟无胎儿产出、产程延长 |
| 诊断 | 触诊、X光、B超 |
| 治疗 | 催产素、助产、剖腹产 |
| 预后 | 及时处理预后良好 |

### 卵巢囊肿

| 项目 | 内容 |
|------|------|
| 病因 | 卵巢滤泡囊肿、黄体囊肿 |
| 临床表现 | 持续发情、发情间期缩短、不孕 |
| 诊断 | B超、激素检测 |
| 治疗 | 手术切除、激素治疗 |
| 预后 | 手术预后良好 |

### 子宫内膜炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌感染、交配感染 |
| 临床表现 | 阴道分泌物、不孕、发情异常 |
| 诊断 | 细胞学、培养、B超 |
| 治疗 | 抗生素、子宫冲洗 |
| 预后 | 及时治疗预后良好 |

### 乳腺肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 激素相关、年龄 |
| 临床表现 | 乳腺肿块、可能溃疡 |
| 诊断 | 细针穿刺、活检 |
| 治疗 | 手术切除（乳腺切除） |
| 预后 | 犬约50%恶性，猫约90%恶性 |


## 公犬猫常见生殖系统疾病

### 前列腺疾病

| 疾病 | 病因 | 临床表现 | 诊断 | 治疗 |
|------|------|---------|------|------|
| 良性前列腺增生 | 激素相关 | 排便困难、血尿 | 触诊、B超 | 绝育、非那雄胺 |
| 前列腺炎 | 细菌感染 | 发热、疼痛、血尿 | 触诊、B超、培养 | 抗生素 |
| 前列腺囊肿 | 先天或后天 | 排尿困难、便秘 | B超、CT | 手术引流 |
| 前列腺肿瘤 | 恶性 | 排尿困难、疼痛 | 活检、CT | 手术、化疗 |

### 睾丸肿瘤

| 项目 | 内容 |
|------|------|
| 病因 | 隐睾、年龄 |
| 临床表现 | 睾丸肿大、不对称、可能女性化 |
| 诊断 | 触诊、B超、活检 |
| 治疗 | 绝育、手术切除 |
| 预后 | 多数良性，恶性者预后取决于分期 |

### 包皮炎

| 项目 | 内容 |
|------|------|
| 病因 | 细菌感染、外伤 |
| 临床表现 | 包皮红肿、分泌物、舔舐 |
| 诊断 | 细胞学、培养 |
| 治疗 | 抗生素、局部清洁 |
| 预后 | 多数预后良好 |

### 隐睾

| 项目 | 内容 |
|------|------|
| 病因 | 先天性睾丸未降 |
| 临床表现 | 单侧或双侧睾丸缺失 |
| 诊断 | 触诊、B超 |
| 治疗 | 绝育（隐睾切除） |
| 预后 | 手术预后良好，未切除者肿瘤风险高 |

### 阴茎损伤

| 项目 | 内容 |
|------|------|
| 病因 | 外伤、交配损伤 |
| 临床表现 | 出血、肿胀、疼痛 |
| 诊断 | 视诊、触诊 |
| 治疗 | 止血、抗生素、手术 |
| 预后 | 取决于损伤程度 |


## 生殖系统急诊处理

| 情况 | 处理 |
|------|------|
| 子宫蓄脓 | 补液、抗生素、紧急手术 |
| 难产 | 评估产程、助产或剖腹产 |
| 前列腺炎急性发作 | 抗生素、补液、止痛 |
| 睾丸扭转 | 紧急手术 |
| 阴道脱出 | 复位、固定、手术 |

## 客户沟通要点

### 解释生殖系统疾病时
- 子宫蓄脓是急症，需要紧急手术，否则可能危及生命。
- 绝育可以预防子宫蓄脓、卵巢肿瘤和乳腺肿瘤。
- 前列腺疾病在未绝育公犬中常见，绝育是重要的预防措施。

### 出院指导
- 术后严格限制活动，按医嘱复查。
- 按医嘱用药，不要随意停药。
- 考虑绝育，预防生殖系统疾病。
- 如果出现呕吐、发热、腹部膨大或阴道分泌物，立即复诊。
