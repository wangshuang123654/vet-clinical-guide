# 🐱 猫咳嗽鉴别诊断 · 临床思维导图

## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 猫哮喘 | 胸部X光（支气管征） | 支气管镜、BALF、过敏原排查 |
| 肺炎 | 胸部X光、血常规 | BALF培养、PCR |
| 肺线虫 | 粪便漂浮/贝尔曼法 | 胸部X光、PCR |
| 肺肿瘤 | 胸部X光、CT | 活检、BALF |
| 心源性肺水肿 | 胸部X光、心超 | 心电图、血压 |
| 心丝虫病 | 心丝虫抗原/微丝蚴检测 | X光、心超 |
| 疱疹病毒/杯状病毒 | 呼吸道PCR | 血常规、X光 |
| 衣原体/支原体 | 呼吸道PCR | 结膜拭子、X光 |
| 鼻炎/鼻窦炎 | 鼻腔镜、X光 | CT、细菌培养 |
| 胸腔积液 | 胸部X光、胸腔穿刺 | 积液分析、心超 |
| 膈疝 | 胸部X光 | CT、B超 |

## 🐾 客户沟通要点

### 接诊时
- "猫咪咳嗽多久了？是干咳还是有痰？什么时候咳得比较厉害？"
- "有没有打喷嚏、流鼻涕、眼部分泌物？精神怎么样？还吃东西吗？"
- "家里有没有别的猫？最近有没有接触过外面的猫？疫苗都打齐了吗？"
- "有没有定期驱虫？是室内猫还是室外猫？"

### 解释检查时
- "猫的咳嗽原因很多，我们建议先拍个X光，看看是气管、肺部还是心脏的问题。"
- "如果怀疑是病毒感染，需要做呼吸道PCR检测，结果可以确定具体病原。"

### 告知风险时
- "猫哮喘虽然不能根治，但可以通过药物和环境管理来控制，大多数猫可以正常生活。"
- "心丝虫病在猫的治疗风险比狗高，预防永远比治疗更重要。"

### 出院指导
- "使用猫砂时选择无粉尘的，保持环境通风，避免烟雾和香水等刺激物。"
- "按时驱虫和疫苗，避免接触不明来源的猫。"
- "如果出现呼吸急促、张口呼吸或咳血，立即来医院。"

## 📌 用药参考（猫）

| 药物 | 剂量 | 用途 |
|------|------|------|
| 布托啡诺 | 0.1-0.2 mg/kg IV/SC | 镇咳 |
| 泼尼松龙 | 0.5-1 mg/kg PO SID | 猫哮喘/过敏 |
| 支气管扩张剂 | 按具体品种剂量 | 猫哮喘/过敏 |
| 呋塞米 | 1-2 mg/kg PO/IV BID-TID | 心源性肺水肿 |
| 多西环素 | 5-10 mg/kg PO SID-BID | 衣原体/支原体 |
| 泛昔洛韦 | 62.5-125 mg/猫 PO BID | 疱疹病毒 |
| 芬苯达唑 | 50 mg/kg PO SID ×3-5天 | 肺线虫 |
| 依维菌素 | 0.2 mg/kg PO/SC | 肺线虫/心丝虫预防 |

> ⚠️ 用药前请结合患猫具体体重、肝肾功能及有无用药禁忌再执行。
