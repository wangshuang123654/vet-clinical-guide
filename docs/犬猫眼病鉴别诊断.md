## 🔴 结膜/眼表疾病

### 结膜炎（细菌性/病毒性/过敏性）
**诊断线索**
- 结膜充血、分泌物（浆液性/黏液性/脓性）
- 眼睑痉挛、猫疱疹病毒（FHV-1）常伴呼吸道症状
- 过敏性：双侧、瘙痒、嗜酸性粒细胞浸润

**治疗思路**
- 区分病因 → 局部抗生素/抗病毒/抗过敏
- 对症清洁 → 猫FHV-1加泛昔洛韦


### 角结膜干燥症（干眼症）
**诊断线索**
- 黏液性分泌物、结膜充血
- 角膜色素沉着/新生血管
- Schirmer泪液试验＜15mm/min

**治疗思路**
- 环孢素/他克莫司滴眼 → 人工泪液
- 严重时手术（腮腺管移植）


### 角膜溃疡/损伤
**诊断线索**
- 眼睑痉挛、畏光、角膜水肿/缺损
- 荧光素染色+
- 猫疱疹病毒常见诱因

**治疗思路**
- 抗生素滴眼（防感染）→ 止痛（阿托品）
- 角膜保护剂 → 严重时手术（角膜瓣/结膜瓣）


### 眼睑异常（内翻/外翻/睫毛异常）
**诊断线索**
- 眼睑内翻/外翻、睫毛刺激角膜
- 继发性结膜炎/角膜溃疡
- 特定品种多发（沙皮/斗牛）

**治疗思路**
- 手术矫正（睑内翻/外翻矫正术）
- 拔除异常睫毛 → 对症支持


## 🟡 葡萄膜/内部结构疾病

### 葡萄膜炎（前/后/全葡萄膜炎）
**诊断线索**
- 眼红、瞳孔缩小、前房浮游物
- 前房积脓/积血、低眼压
- 房水闪辉（+）

**治疗思路**
- 查找原发病（感染/免疫/肿瘤）
- 局部/全身糖皮质激素 → 散瞳（阿托品）
- 控制继发性青光眼


### 青光眼
**诊断线索**
- 角膜水肿、瞳孔散大
- 眼压↑（正常 10-20 mmHg）
- 视力下降/失明、疼痛表现

**治疗思路**
- 紧急降眼压（甘露醇）
- 药物（多佐胺/噻吗洛尔）
- 手术（睫状体冷冻/光凝）→ 疼痛管理


### 白内障
**诊断线索**
- 晶状体混浊、视力下降
- 眼底反射消失
- 糖尿病犬常见

**治疗思路**
- 查找原发病（糖尿病控制）
- 手术（超声乳化）→ 术后抗炎


### 晶状体脱位
**诊断线索**
- 晶状体移位（前脱位→继发性青光眼）
- 震颤虹膜
- 特定品种多发（梗犬）

**治疗思路**
- 手术摘除晶状体
- 控制继发性青光眼 → 药物降眼压


## 🟢 眼眶/眼球后疾病

### 眼球突出（球后脓肿/肿瘤）
**诊断线索**
- 突发/缓慢眼球突出、眼球运动受限
- 疼痛、B超/CT可确诊

**治疗思路**
- 球后脓肿→手术引流+抗生素
- 球后肿瘤→手术切除+化疗/放疗


### 眼眶蜂窝织炎
**诊断线索**
- 眼睑肿胀、眼球突出、发热
- 疼痛、血象↑

**治疗思路**
- 抗生素（静脉/口服）→ 抗炎
- 手术引流（脓肿形成时）


### 眼球萎缩
**诊断线索**
- 眼球缩小、角膜浑浊、视力丧失
- 慢性葡萄膜炎/外伤病史

**治疗思路**
- 无功能性眼球 → 对症控制炎症
- 美容性义眼手术


## 🔵 全身性疾病相关眼病

### 高血压性视网膜病变（猫）
**诊断线索**
- 视力下降/失明、瞳孔散大
- 眼底出血/视网膜脱离
- 收缩压＞160mmHg

**治疗思路**
- 降压（氨氯地平）
- 控制原发病（肾病/甲亢）→ 监测血压


### 糖尿病性白内障（犬）
**诊断线索**
- 糖尿病史、晶状体混浊
- 视力下降、血糖控制不佳

**治疗思路**
- 稳定血糖（胰岛素）
- 手术（超声乳化）→ 术后抗炎


### 传染性疾病（犬瘟热/猫疱疹/FIP）
**诊断线索**
- 结膜炎/葡萄膜炎
- 全身症状（发热/呼吸道/神经症状）
- PCR/抗体检测+

**治疗思路**
- 治疗原发病 → 对症眼药
- 全身支持


### 免疫介导性（巩膜炎/干燥综合征）
**诊断线索**
- 巩膜充血/结节、疼痛、眼干
- 可能伴发全身免疫病

**治疗思路**
- 免疫抑制（泼尼松/环孢素）
- 局部抗炎 → 治疗全身原发病

## 🐾 临床参考

### 📌 正常眼压值
| 物种 | 正常眼压（mmHg） | 提示青光眼（mmHg） |
|------|-----------------|-------------------|
| 犬 | 10-20 | > 25-30 |
| 猫 | 10-20 | > 25-30 |
> ⚠️ 单侧眼压比另一侧高 10-15 mmHg 时，即使双侧都在正常范围内，也应警惕青光眼可能。

### 📌 Schirmer泪液试验（STT）参考值
| 物种 | 正常值（mm/min） | 提示干眼症（mm/min） |
|------|-----------------|---------------------|
| 犬 | > 15 | < 10 |
| 猫 | > 10 | < 5 |
> ⚠️ 部分品种（如北京犬、西施犬）基础泪液分泌偏低，需结合临床症状综合判断。

### 📌 常见品种眼病易感性
| 品种 | 易发眼病 |
|------|---------|
| 腊肠犬 | 晶状体脱位 |
| 波士顿梗 | 白内障、青光眼 |
| 北京犬 | 干眼症、角膜溃疡 |
| 斗牛犬 | 睑内翻、角膜溃疡 |
| 沙皮犬 | 睑内翻、青光眼 |
| 西施犬 | 干眼症、角膜溃疡 |
| 贵宾犬 | 白内障、进行性视网膜萎缩 |
| 暹罗猫 | 进行性视网膜萎缩 |
| 波斯猫 | 角膜溃疡、继发性青光眼（慢性葡萄膜炎） |
| 缅甸猫 | 青光眼（原发性） |

## 🐾 客户沟通要点

### 接诊时
- "眼睛的问题什么时候开始出现的？是突然还是慢慢加重的？"
- "有没有疼痛表现（眯眼、流泪、抓挠）？"
- "最近有没有接触其他动物、有没有受伤？"
- "有没有全身症状（精神不好、食欲下降、咳嗽打喷嚏）？"
- "有没有糖尿病、肾病或高血压病史（尤其是老年犬猫）？"

### 解释检查和方案
- "角膜溃疡需要做荧光素染色，可以判断角膜缺损的范围和深度。"
- "干眼症需要做泪液测试，可以确定眼泪分泌是否正常。"
- "青光眼的诊断需要测量眼压，正常眼压通常在 10-20 mmHg。"

### 告知风险和预后
- "角膜深层溃疡有穿孔风险，一旦穿孔，眼球可能保不住。"
- "青光眼如果不及时处理，高眼压会损伤视神经，导致不可逆的失明。"
- "白内障手术成功率很高，但需要术前评估视网膜和全身健康状况。"
- "猫的视网膜脱离通常是高血压引起的，控制血压是最关键的治疗。"

### 出院指导
- "按时滴眼药，不要漏滴，滴眼药前先洗手。"
- "戴伊丽莎白圈，防止抓挠眼睛。"
- "定期复查——角膜溃疡每 2-3 天复查一次，青光眼定期监测眼压。"
- "如果出现疼痛加重、分泌物增多或视力变差，立即复诊。"
