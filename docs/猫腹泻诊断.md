# 🐱 猫腹泻鉴别诊断 · 临床思维导图

## 🐾 辅助检查建议

| 怀疑方向 | 首选检查 | 次要/补充检查 |
|---------|---------|--------------|
| 急性胃肠炎 | 粪检、基本生化 | 腹部X光 |
| 异物梗阻 | 腹部X光（正侧位） | B超、钡餐 |
| 炎性肠病（IBD） | 腹部B超（肠壁厚度） | 活检、叶酸/B12 |
| 胰腺炎 | 猫胰腺脂肪酶（fPL） | 腹部B超 |
| 三体炎 | 生化（ALT/AST/胆红素）、fPL | 腹部B超 |
| 猫瘟（FPV） | 病毒抗原检测 | 血常规、生化 |
| 寄生虫/三毛滴虫 | 粪便漂浮、直接镜检、PCR | 广谱驱虫药、罗硝唑 |
| 甲状腺功能亢进 | T4、fT4 | 血压、SDMA |
| 慢性肾病 | 生化（BUN/Crea）、SDMA | 尿检、B超 |
| 糖尿病 | 血糖、果糖胺 | 尿酮体 |
| 肝病 | 生化（ALT/AST/胆红素） | B超、胆汁酸 |
| 细菌性肠炎 | 粪便培养+药敏 | 血常规 |
| 百合花中毒 | 详细问诊（接触史）、生化 | 尿检 |

## 🐾 客户沟通要点

### 接诊时
- "猫咪腹泻多久了？一天拉几次？是水样还是带血/带黏液？"
- "最近有没有换粮、喂新零食、或者家里养了百合花？"
- "精神怎么样？还主动吃东西喝水吗？"
- "疫苗都打齐了吗？有没有按时驱虫？"

### 解释检查时
- "猫瘟在未接种的小猫中很常见，我们建议查一下抗原。"
- "如果怀疑是三毛滴虫感染，可能需要做专门的PCR检测。"

### 告知风险时
- "猫瘟在幼猫中死亡率很高，但只要及时住院治疗，还是有希望的。"
- "猫不能接触百合花，整株都有毒，会导致急性肾衰竭。"

### 出院指导
- "回去先喂容易消化的食物，少食多餐。"
- "如果再次腹泻或精神变差，随时联系我们。"

## 📌 用药参考（猫）

| 药物 | 剂量 | 用途 |
|------|------|------|
| 蒙脱石散 | 0.5-1 g/猫 PO BID-TID | 止泻 |
| 益生菌 | 按产品说明 | 调节肠道菌群 |
| 马罗匹坦 | 1 mg/kg IV/SC SID | 止吐 |
| 甲硝唑 | 10-15 mg/kg PO BID | 厌氧菌/原虫 |
| 罗硝唑 | 30-50 mg/kg PO SID ×14天 | 三毛滴虫 |
| 驱虫药 | 按具体品种剂量 | 寄生虫感染 |
| 甲巯咪唑 | 2.5-5 mg/猫 PO BID | 甲亢 |

> ⚠️ 用药前请结合患猫具体体重、肝肾功能及有无用药禁忌再执行。
