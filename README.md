## 🩺 犬呕吐鉴别诊断 · 临床思维导图

> 更新日期：2026年9月1日

### 消化系统疾病

#### 1. 急性胃肠炎
- **诊断线索**：突然呕吐/腹泻、通常与饮食有关、精神状态尚可
- **治疗思路**：禁食12-24小时 → 止吐（马罗匹坦）→ 益生菌 → 清淡饮食

#### 2. 异物梗阻
- **诊断线索**：频繁呕吐、腹部触诊敏感、X光/钡餐可见异物
- **治疗思路**：X光/B超确诊 → 内镜取出或手术

#### 3. 胰腺炎 ⚠️
- **诊断线索**：腹痛弓背、脂肪酶↑、淀粉酶↑、CRP↑
- **治疗思路**：对症治疗（输液、止痛、止吐）→ 低脂饮食长期管理

#### 4. 胃扩张扭转（GDV）🚨 急症
- **诊断线索**：大型/深胸犬、干呕、腹胀、呼吸困难
- **治疗思路**：紧急手术！先胃减压 → 立即手术复位固定

#### 5. 炎性肠病（IBD）
- **诊断线索**：慢性间歇性呕吐/腹泻、体重下降、对饮食变化有反应
- **治疗思路**：排除其他病因 → 饮食管理 → 免疫抑制剂（如泼尼松龙）

#### 6. 胃溃疡
- **诊断线索**：呕吐物带血/咖啡渣样、黑便、腹痛
- **治疗思路**：抑酸（奥美拉唑）→ 保护胃黏膜（硫糖铝）→ 排查NSAIDs使用史

### 感染性疾病

#### 1. 病毒性（如细小病毒）
- **诊断线索**：未接种幼犬、血便恶臭、严重脱水、白细胞↓
- **治疗思路**：住院隔离 → 输液支持 → 抗病毒/抗生素 → 监测血常规

#### 2. 细菌性（如沙门氏菌）
- **诊断线索**：发热、急性水样腹泻、可能有生食史
- **治疗思路**：粪便培养+药敏 → 根据药敏选抗生素

#### 3. 寄生虫（如蛔虫、钩虫）
- **诊断线索**：幼犬多发、腹围增大、粪便可见虫体或虫卵
- **治疗思路**：粪便漂浮检查 → 广谱驱虫药 → 环境消毒

### 代谢/内分泌疾病

#### 1. 肾衰竭
- **诊断线索**：多饮多尿、体重下降、BUN/Crea↑、贫血
- **治疗思路**：补液 → 肾脏处方粮 → 控制血压 → 监测SDMA

#### 2. 糖尿病
- **诊断线索**：多饮多尿、体重下降但食欲亢进、果糖胺↑、高血糖
- **治疗思路**：胰岛素治疗 → 稳定血糖曲线 → 高纤低脂处方粮

#### 3. 肾上腺问题（库欣/阿迪森）
- **诊断线索**：库欣→多饮多尿、腹部膨大、脱毛对称；阿迪森→虚弱、休克、电解质异常
- **治疗思路**：ACTH刺激试验 → 库欣用曲洛斯坦 / 阿迪森用泼尼松+氟氢可的松

### 中毒

#### 1. 巧克力（甲基黄嘌呤）
- **诊断线索**：有食入史、兴奋/震颤、心动过速、呕吐
- **治疗思路**：催吐/洗胃 → 活性炭 → 对症（控制心律、镇静）

#### 2. 洋葱/大蒜（溶血）
- **诊断线索**：食入史、虚弱、黏膜苍白、尿液呈红棕色（血红蛋白尿）
- **治疗思路**：停用诱因 → 抗氧化（维生素E）→ 严重时输血

#### 3. 灭鼠药（华法林类）
- **诊断线索**：食入史、出血倾向（牙龈出血/瘀斑/血便）
- **治疗思路**：维生素K₁注射 → 监测凝血功能 → 严重时输血

#### 4. 葡萄/提子（肾毒性）
- **诊断线索**：食入史、呕吐、少尿/无尿、BUN/Crea↑
- **治疗思路**：催吐/洗胃 → 静脉输液（利尿）→ 监测肾功能

#### 5. 木糖醇（低血糖）
- **诊断线索**：食入史（无糖食品/牙膏）、虚弱、共济失调、低血糖
- **治疗思路**：静脉补糖 → 监测血糖 → 保肝治疗

---

> 📌 **使用说明**：遇到犬呕吐病例时，按四大类逐一对照“诊断线索”，快速锁定可能病因，然后执行对应的“治疗思路”。
